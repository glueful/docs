# File Uploads to S3 in 15 Minutes

This tutorial demonstrates how to implement secure file uploads using Glueful's built-in FileUploader class with S3 storage. You'll learn to handle file validation, metadata storage, and both local and cloud storage configurations.

## What You'll Build

A complete file upload system with:
- ✅ Secure file validation and processing
- ✅ S3 and local storage support
- ✅ File metadata with BlobRepository
- ✅ Signed URLs for private files
- ✅ Image optimization and thumbnails
- ✅ Upload progress and error handling

## Prerequisites

- Glueful project setup
- Understanding of [CRUD with Validation tutorial](./3.crud-validation-repository.md)
- AWS S3 bucket (optional - can use local storage)
- For S3 support: `composer require league/flysystem-aws-s3-v3`

## Step 1: Configure Storage

Set up your storage configuration for both local and S3:

### Environment Variables

```bash
# .env

# Local storage (default)
STORAGE_DEFAULT_DISK=uploads

# OR S3 storage
STORAGE_DEFAULT_DISK=s3
S3_ACCESS_KEY_ID=your_access_key
S3_SECRET_ACCESS_KEY=your_secret_key
S3_REGION=us-east-1
S3_BUCKET=your-bucket-name
S3_ENDPOINT=https://s3.amazonaws.com
S3_CDN_BASE_URL=https://cdn.yourdomain.com
S3_ACL=private
S3_SIGNED_URLS=true
S3_SIGNED_URL_TTL=3600
```

```php
    ],
```

## Step 2: Create Upload Controller

Build a controller using Glueful's FileUploader:

```php
<?php
// app/Controllers/FileUploadController.php

declare(strict_types=1);

namespace App\Controllers;

use Glueful\Uploader\FileUploader;
use Glueful\Repository\BlobRepository;
use Glueful\Http\Request;
use Glueful\Http\Response;
use Glueful\Helpers\Utils;

class FileUploadController
{
    public function __construct(
        private FileUploader $fileUploader,
        private BlobRepository $blobRepository
    ) {}
    
    /**
     * Handle file upload with validation
     */
    public function upload(Request $request): Response
    {
        // Generate secure token for this upload
        $token = Utils::generateUuid();
        
        // Prepare GET parameters (metadata) - user_id is required by FileUploader
        $getParams = [
            'user_id' => $request->get('user_id') ?? '1', // Required parameter
            'folder' => $request->get('folder', 'uploads'), // Storage folder
            'visibility' => $request->get('visibility', 'private'), // File visibility
        ];
        
        // Get uploaded files - FileUploader expects $_FILES format
        $fileParams = $request->files->all();
        $fileKey = $request->get('key', 'file'); // Default file input name
        
        // Pass the file directly or use key to specify which file
        if (isset($fileParams[$fileKey])) {
            $result = $this->fileUploader->handleUpload($token, $getParams, $fileParams[$fileKey]);
        } else {
            return Response::json(['error' => 'No file provided'], 400);
        }
        
        if (isset($result['error'])) {
            return Response::json($result, $result['code'] ?? 500);
        }
        
        return Response::json([
            'success' => true,
            'uuid' => $result['uuid'],
            'url' => $result['url'],
            'file' => $result
        ], 201);
    }
    
    /**
     * Get file information by UUID
     */
    public function show(Request $request): Response
    {
        $uuid = $request->route('uuid');
        $blob = $this->blobRepository->findByUuid($uuid);
        
        if (!$blob) {
            return Response::json(['error' => 'File not found'], 404);
        }
        
        // Generate signed URL for private files if using S3
        $signedUrl = null;
        if (isset($blob['path']) && $this->isS3Storage()) {
            $signedUrl = $this->generateSignedUrl($blob['path']);
        }
        
        return Response::json([
            'file' => $this->formatFileResponse($blob, $signedUrl)
        ]);
    }
    
    /**
     * List uploaded files with pagination
     */
    public function index(Request $request): Response
    {
        $limit = (int) ($request->get('limit', 20));
        $offset = (int) ($request->get('offset', 0));
        $userId = $request->get('user_id');
        $mimeType = $request->get('mime_type');
        
        $filters = [];
        if ($userId) {
            $filters['user_id'] = $userId;
        }
        if ($mimeType) {
            $filters['mime_type'] = $mimeType;
        }
        
        $files = $this->blobRepository->findWhere($filters, $limit, $offset, ['created_at' => 'DESC']);
        
        return Response::json([
            'files' => array_map([$this, 'formatFileResponse'], $files),
            'pagination' => [
                'limit' => $limit,
                'offset' => $offset
            ]
        ]);
    }
    
    /**
     * Delete file
     */
    public function destroy(Request $request): Response
    {
        $uuid = $request->route('uuid');
        $blob = $this->blobRepository->findByUuid($uuid);
        
        if (!$blob) {
            return Response::json(['error' => 'File not found'], 404);
        }
        
        try {
            // Delete from storage
            $storage = $this->fileUploader->getStorage();
            $storage->delete($blob['path']);
            
            // Delete from database
            $this->blobRepository->delete($uuid);
            
            return Response::json(['message' => 'File deleted successfully']);
        } catch (\Exception $e) {
            error_log("File deletion error: " . $e->getMessage());
            return Response::json(['error' => 'Failed to delete file'], 500);
        }
    }
    
    /**
     * Upload multiple files
     */
    public function uploadMultiple(Request $request): Response
    {
        $files = $request->files->all();
        $folder = $request->get('folder', 'uploads');
        $userId = $request->get('user_id') ?? '1';
        
        if (empty($files)) {
            return Response::json(['error' => 'No files provided'], 400);
        }
        
        $results = [];
        $errors = [];
        
        foreach ($files as $key => $file) {
            $token = Utils::generateUuid();
            $getParams = [
                'user_id' => $userId,
                'folder' => $folder,
                'visibility' => 'private',
            ];
            
            $result = $this->fileUploader->handleUpload($token, $getParams, $file);
            
            if (isset($result['error'])) {
                $errors[$key] = $result['error'];
            } else {
                $results[$key] = $result;
            }
        }
        
        $response = [
            'success' => count($results) > 0,
            'uploaded' => $results,
            'failed' => $errors,
            'summary' => [
                'total' => count($files),
                'successful' => count($results),
                'failed' => count($errors)
            ]
        ];
        
        return Response::json($response, count($errors) > 0 ? 207 : 201);
    }
    
    /**
     * Generate signed URL for private files
     */
    private function generateSignedUrl(string $path): ?string
    {
        try {
            // Use storage manager to get signed URL for S3
            $storageManager = app(\Glueful\Storage\StorageManager::class);
            $disk = $storageManager->disk(); // Uses default disk from config
            
            // Only S3 supports signed URLs - check if we're using S3
            if ($this->isS3Storage()) {
                return $disk->getSignedUrl($path, 3600); // 1 hour expiry
            }
            
            return null;
        } catch (\Exception $e) {
            error_log("Signed URL generation error: " . $e->getMessage());
            return null;
        }
    }
    
    /**
     * Check if we're using S3 storage
     */
    private function isS3Storage(): bool
    {
        $defaultDisk = config('storage.default', 'uploads');
        $diskConfig = config("storage.disks.{$defaultDisk}", []);
        return ($diskConfig['driver'] ?? '') === 's3';
    }
    
    /**
     * Format file response data
     * @param array<string, mixed> $blob
     * @param string|null $signedUrl
     * @return array<string, mixed>
     */
    private function formatFileResponse(array $blob, ?string $signedUrl = null): array
    {
        return [
            'uuid' => $blob['uuid'],
            'name' => $blob['name'],
            'mime_type' => $blob['mime_type'],
            'size' => $blob['size'],
            'url' => $blob['url'],
            'signed_url' => $signedUrl,
            'status' => $blob['status'],
            'created_at' => $blob['created_at']
        ];
    }
}
```

## Step 3: Use Built-in Image Processing

Glueful includes a powerful `ImageProcessor` with the `image()` helper function. Here's how to process uploaded images:

```php
<?php
// app/Services/ImageProcessingService.php

declare(strict_types=1);

namespace App\Services;

use Glueful\Repository\BlobRepository;
use Glueful\Services\ImageProcessorInterface;

class ImageProcessingService
{
    public function __construct(
        private BlobRepository $blobRepository,
        private ImageProcessorInterface $imageProcessor
    ) {}
    
    /**
     * Generate thumbnails for uploaded image using built-in processor
     */
    public function generateThumbnails(string $blobUuid): array
    {
        $blob = $this->blobRepository->findByUuid($blobUuid);
        
        if (!$blob || !$this->isImage($blob['mime_type'])) {
            throw new \InvalidArgumentException('Invalid image file');
        }
        
        $originalPath = $blob['url']; // Use the URL or local path
        $thumbnails = [];
        
        // Standard thumbnail sizes
        $sizes = [
            'thumb' => ['width' => 150, 'height' => 150],
            'medium' => ['width' => 400, 'height' => 400],
            'large' => ['width' => 800, 'height' => 600]
        ];
        
        foreach ($sizes as $size => $dimensions) {
            try {
                // Use Glueful's image() helper function for processing
                $processedData = image($originalPath)
                    ->fit($dimensions['width'], $dimensions['height'])
                    ->quality(85)
                    ->cached("thumbnail-{$blobUuid}-{$size}", 86400)
                    ->getImageData();
                    
                // Generate filename for thumbnail
                $pathInfo = pathinfo($blob['name']);
                $filename = $pathInfo['filename'] . "_{$size}." . ($pathInfo['extension'] ?? 'jpg');
                
                // Store the processed thumbnail
                $storageManager = app(\Glueful\Storage\StorageManager::class);
                $thumbnailPath = "thumbnails/{$filename}";
                $storageManager->disk()->write($thumbnailPath, $processedData);
                
                // Create blob record for thumbnail
                $thumbnailBlob = [
                    'name' => $filename,
                    'mime_type' => $blob['mime_type'],
                    'size' => strlen($processedData),
                    'url' => $thumbnailPath,
                    'status' => 'active',
                    'created_at' => date('Y-m-d H:i:s'),
                    'created_by' => $blob['created_by']
                ];
                
                $thumbnailUuid = $this->blobRepository->create($thumbnailBlob);
                $thumbnails[$size] = [
                    'uuid' => $thumbnailUuid,
                    'url' => $storageManager->disk()->url($thumbnailPath),
                    'size' => strlen($processedData)
                ];
                
            } catch (\Exception $e) {
                error_log("Thumbnail generation failed for size {$size}: " . $e->getMessage());
                continue;
            }
        }
        
        return $thumbnails;
    }
    
    /**
     * Resize image using built-in processor
     */
    public function resizeImage(string $blobUuid, int $width, int $height, int $quality = 85): array
    {
        $blob = $this->blobRepository->findByUuid($blobUuid);
        
        if (!$blob || !$this->isImage($blob['mime_type'])) {
            throw new \InvalidArgumentException('Invalid image file');
        }
        
        try {
            // Process image with built-in processor
            $processedData = image($blob['url'])
                ->resize($width, $height)
                ->quality($quality)
                ->cached("resized-{$blobUuid}-{$width}x{$height}", 3600)
                ->getImageData();
                
            return [
                'success' => true,
                'data' => base64_encode($processedData),
                'size' => strlen($processedData),
                'dimensions' => ['width' => $width, 'height' => $height]
            ];
            
        } catch (\Exception $e) {
            return [
                'success' => false,
                'error' => $e->getMessage()
            ];
        }
    }
    
    /**
     * Check if file is an image
     */
    private function isImage(string $mimeType): bool
    {
        return in_array($mimeType, [
            'image/jpeg',
            'image/png',
            'image/gif',
            'image/webp'
        ]);
    }
}
```

## Step 4: Register Routes

Add file upload routes in `routes/api.php`. The framework provides a `$router` instance in route files:

```php
<?php
// routes/api.php

use App\Controllers\FileUploadController;

// File upload route group
$router->group(['prefix' => '/files'], function($router) {
    // Single file upload
    $router->post('/upload', [FileUploadController::class, 'upload']);
    
    // Multiple file upload
    $router->post('/upload-multiple', [FileUploadController::class, 'uploadMultiple']);
    
    // List files with optional filtering
    $router->get('/', [FileUploadController::class, 'index']);
    
    // Get specific file details by UUID
    $router->get('/{uuid}', [FileUploadController::class, 'show'])
        ->where('uuid', '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}');
    
    // Delete file by UUID
    $router->delete('/{uuid}', [FileUploadController::class, 'destroy'])
        ->where('uuid', '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}');
});

// Alternatively, with middleware for authentication
$router->group([
    'prefix' => '/files',
    'middleware' => ['auth'] // Add auth middleware if needed
], function($router) {
    $router->post('/upload', [FileUploadController::class, 'upload']);
    $router->post('/upload-multiple', [FileUploadController::class, 'uploadMultiple']);
    $router->get('/', [FileUploadController::class, 'index']);
    $router->get('/{uuid}', [FileUploadController::class, 'show'])
        ->where('uuid', '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}');
    $router->delete('/{uuid}', [FileUploadController::class, 'destroy'])
        ->where('uuid', '[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}');
});
```

## Step 5: Frontend Upload Component

Create a simple upload interface:

```html
<!-- public/upload.html -->
<!DOCTYPE html>
<html>
<head>
    <title>File Upload Test</title>
    <style>
        .upload-container { max-width: 600px; margin: 20px auto; padding: 20px; }
        .drop-zone { border: 2px dashed #ccc; padding: 40px; text-align: center; margin: 20px 0; }
        .drop-zone.dragover { border-color: #007cba; background-color: #f0f8ff; }
        .progress-bar { width: 100%; height: 20px; background-color: #f0f0f0; margin: 10px 0; }
        .progress-fill { height: 100%; background-color: #007cba; transition: width 0.3s; }
        .file-list { margin: 20px 0; }
        .file-item { padding: 10px; border: 1px solid #ddd; margin: 5px 0; }
    </style>
</head>
<body>
    <div class="upload-container">
        <h1>File Upload Test</h1>
        
        <!-- Single file upload -->
        <div class="drop-zone" id="dropZone">
            <p>Drop files here or <input type="file" id="fileInput" multiple></p>
        </div>
        
        <div class="progress-bar" id="progressBar" style="display: none;">
            <div class="progress-fill" id="progressFill" style="width: 0%;"></div>
        </div>
        
        <div class="file-list" id="fileList"></div>
    </div>

    <script>
        const dropZone = document.getElementById('dropZone');
        const fileInput = document.getElementById('fileInput');
        const progressBar = document.getElementById('progressBar');
        const progressFill = document.getElementById('progressFill');
        const fileList = document.getElementById('fileList');

        // Drag and drop functionality
        dropZone.addEventListener('dragover', (e) => {
            e.preventDefault();
            dropZone.classList.add('dragover');
        });

        dropZone.addEventListener('dragleave', () => {
            dropZone.classList.remove('dragover');
        });

        dropZone.addEventListener('drop', (e) => {
            e.preventDefault();
            dropZone.classList.remove('dragover');
            const files = Array.from(e.dataTransfer.files);
            uploadFiles(files);
        });

        fileInput.addEventListener('change', (e) => {
            const files = Array.from(e.target.files);
            uploadFiles(files);
        });

        async function uploadFiles(files) {
            if (files.length === 1) {
                await uploadSingleFile(files[0]);
            } else {
                await uploadMultipleFiles(files);
            }
        }

        async function uploadSingleFile(file) {
            const formData = new FormData();
            formData.append('file', file);
            formData.append('folder', 'test-uploads');

            try {
                progressBar.style.display = 'block';
                
                const response = await fetch('/files/upload', {
                    method: 'POST',
                    body: formData
                });

                const result = await response.json();

                if (result.success) {
                    addFileToList(result.file);
                } else {
                    alert('Upload failed: ' + result.error);
                }
            } catch (error) {
                alert('Upload error: ' + error.message);
            } finally {
                progressBar.style.display = 'none';
                progressFill.style.width = '0%';
            }
        }

        async function uploadMultipleFiles(files) {
            const formData = new FormData();
            files.forEach((file, index) => {
                formData.append(`files[${index}]`, file);
            });
            formData.append('folder', 'test-uploads');

            try {
                progressBar.style.display = 'block';
                
                const response = await fetch('/files/upload-multiple', {
                    method: 'POST',
                    body: formData
                });

                const result = await response.json();

                if (result.success) {
                    Object.values(result.uploaded).forEach(addFileToList);
                    
                    if (Object.keys(result.failed).length > 0) {
                        alert('Some files failed to upload: ' + JSON.stringify(result.failed));
                    }
                } else {
                    alert('Upload failed');
                }
            } catch (error) {
                alert('Upload error: ' + error.message);
            } finally {
                progressBar.style.display = 'none';
            }
        }

        function addFileToList(file) {
            const fileItem = document.createElement('div');
            fileItem.className = 'file-item';
            fileItem.innerHTML = `
                <strong>${file.filename}</strong> (${file.mime_type})
                <br>Size: ${formatFileSize(file.size)}
                <br>UUID: ${file.uuid}
                <br><a href="/files/${file.uuid}" target="_blank">View Details</a>
            `;
            fileList.appendChild(fileItem);
        }

        function formatFileSize(bytes) {
            if (bytes === 0) return '0 Bytes';
            const k = 1024;
            const sizes = ['Bytes', 'KB', 'MB', 'GB'];
            const i = Math.floor(Math.log(bytes) / Math.log(k));
            return parseFloat((bytes / Math.pow(k, i)).toFixed(2)) + ' ' + sizes[i];
        }
    </script>
</body>
</html>
```

## Key Framework Features Used

### 1. FileUploader Class
- **Built-in Validation**: File type, size, and security checks using config
- **Multiple Storage Drivers**: Local, S3 via FlysystemStorage wrapper  
- **Secure File Handling**: Virus scanning, path traversal protection, MIME validation
- **BlobRepository Integration**: Automatic metadata storage with UUIDs

### 2. BlobRepository  
- **File Metadata**: Stores file information with UUID-based lookup
- **Relationships**: Link files to users via created_by field
- **Search & Filtering**: Query files by type, date, size, user
- **Status Management**: Active/inactive status tracking

### 3. Storage System (StorageManager + FlysystemStorage)
- **Driver Abstraction**: Switch between local/S3 via config
- **S3 Package Required**: Must install `league/flysystem-aws-s3-v3` for S3 support
- **URL Generation**: Automatic URL generation with CDN support
- **Path Management**: Secure path handling with PathGuard

### 4. Image Processing (Built-in)
- **ImageProcessor Service**: Use `image()` helper function for processing
- **Intervention Image v3**: Modern, cached image transformations
- **Multiple Formats**: JPEG, PNG, GIF, WebP support
- **Caching Built-in**: Automatic caching of processed images

## Pro Tips

1. **Install S3 package first**: `composer require league/flysystem-aws-s3-v3` for S3 support
2. **Use proper environment variables**: Set `STORAGE_DEFAULT_DISK=s3` for S3 storage
3. **FileUploader requires user_id**: Always provide user_id in getParams
4. **Use built-in image processing**: Leverage `image()` helper instead of custom code
5. **Configure file validation**: Set `FILE_ALLOWED_EXTENSIONS` and `MAX_FILE_UPLOAD_SIZE`
6. **Enable file scanning**: Keep `filesystem.security.scan_uploads=true` for security
7. **Use BlobRepository correctly**: Files are stored with UUID-based lookup system
