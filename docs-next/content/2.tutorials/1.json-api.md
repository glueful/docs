# Build a JSON API in 15 Minutes

Glueful provides **automatic CRUD APIs** for any database table! This tutorial shows you how to leverage the built-in system and customize it when needed. No controllers to create, no routes to define - just add a table and get a full REST API.

## What's Already Available

Out of the box, Glueful provides:
- ✅ **Automatic CRUD endpoints** for any table (`/{table}/*`)
- ✅ **Complete database schema** (users, notifications, audit logs, etc.)
- ✅ **Built-in validation** and error handling
- ✅ **Pagination and filtering** for all endpoints
- ✅ **Rate limiting** and security features
- ✅ **UUID-based identification** for all resources

## Prerequisites

- Glueful project setup ([installation guide](../1.start/2.installation.md))
- Basic understanding of REST APIs
- 10 minutes to explore the system

## Step 2: Create a Custom Table

Let's create a `tasks` table to demonstrate the automatic API generation:

### Create Migration

Create a migration using the actual framework interface:

```bash
php glueful migrate:create CreateTasksTable
```

Edit the migration file in `database/migrations/`:

```php
<?php

namespace Glueful\Database\Migrations;

use Glueful\Database\Migrations\MigrationInterface;
use Glueful\Database\Schema\Interfaces\SchemaBuilderInterface;

/**
 * Create Tasks Table Migration
 * 
 * Creates the tasks table following framework patterns:
 * - Both id (auto-increment primary) and uuid (external API) fields
 * - Proper foreign key relationships
 * - Performance indexes
 * - Timestamp tracking
 */
class CreateTasksTable implements MigrationInterface
{
    public function up(SchemaBuilderInterface $schema): void
    {
        $schema->createTable('tasks', function ($table) {
            $table->bigInteger('id')->primary()->autoIncrement();
            $table->string('uuid', 12);
            $table->string('title', 255);
            $table->text('description')->nullable();
            $table->boolean('completed')->default(false);
            $table->string('priority', 20)->default('medium'); // low, medium, high
            $table->timestamp('due_date')->nullable();
            $table->string('created_by', 12)->nullable();
            $table->string('status', 20)->default('active');
            $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
            $table->timestamp('updated_at')->nullable();
            $table->timestamp('deleted_at')->nullable();
            
            // Add indexes
            $table->unique('uuid');
            $table->index('completed');
            $table->index('priority');
            $table->index('due_date');
            $table->index('created_by');
            $table->index('status');
            
            // Foreign key to users table
            $table->foreign('created_by')
                ->references('uuid')
                ->on('users')
                ->nullOnDelete();
        });
    }

    public function down(SchemaBuilderInterface $schema): void
    {
        $schema->dropTable('tasks');
    }
}
```

### Run Migration

```bash
php glueful migrate:run
```

**That's it!** Your tasks table now has a complete REST API automatically:

- `GET /tasks` - List all tasks (with pagination, filtering)
- `GET /tasks/{uuid}` - Get single task by UUID
- `POST /tasks` - Create new task
- `PUT /tasks/{uuid}` - Update task by UUID
- `DELETE /tasks/{uuid}` - Delete task by UUID

**Note**: The API uses the `uuid` field for external identification, while `id` is used internally.

### Understanding the Dual ID System

Glueful uses both `id` and `uuid` fields for different purposes:

- **`id`**: Auto-incrementing integer primary key for internal database operations and performance
- **`uuid`**: 12-character unique string identifier used for external API endpoints and references

This design provides:
- **Performance**: Fast integer joins and indexing internally
- **Security**: Non-enumerable external identifiers (can't guess other resource IDs)
- **Scalability**: UUIDs work across distributed systems
- **Consistency**: All tables follow the same pattern

## Step 4: When to Customize

The built-in CRUD API handles most use cases, but you might want to customize when you need:

### Custom Business Logic

Create a custom controller that extends `ResourceController`:

Create `app/Controllers/TaskController.php`:

```php
<?php

declare(strict_types=1);

namespace App\Controllers;

use Glueful\Controllers\ResourceController;
use Glueful\Http\Response;
use Glueful\Auth\UserIdentity;
use Glueful\Helpers\Utils;

class TaskController extends ResourceController
{
    /**
     * Override post method to add business logic
     */
    public function post(array $params, array $data): Response
    {
        // Get current user from auth context
        $userIdentity = UserIdentity::fromGlobals();
        
        // Add created_by field automatically
        $data['created_by'] = $userIdentity->getUuid();
        
        // Add UUID if not provided
        if (!isset($data['uuid'])) {
            $data['uuid'] = Utils::generateUuid();
        }
        
        // Custom validation
        if (empty($data['title'])) {
            return Response::error('Title is required', 400);
        }
        
        if (strlen($data['title']) > 255) {
            return Response::error('Title must be less than 255 characters', 400);
        }
        
        // Call parent method with enhanced data
        return parent::post($params, $data);
    }
    
    /**
     * Override get method to add user filtering
     */
    public function get(array $params, array $queryParams): Response
    {
        $userIdentity = UserIdentity::fromGlobals();
        
        // Only show user's own tasks unless admin
        if (!$userIdentity->isAdmin()) {
            $queryParams['created_by'] = $userIdentity->getUuid();
        }
        
        return parent::get($params, $queryParams);
    }
}
```

### Register Custom Routes

Add to `routes/api.php`:

```php
<?php

use App\Controllers\TaskController;
use Glueful\Routing\Router;

/** @var Router $router */

// Custom task routes (override default resource routes)
$router->group(['prefix' => '/tasks', 'middleware' => ['auth']], function(Router $router) {
    $router->get('/', [TaskController::class, 'get']);
    $router->post('/', [TaskController::class, 'post']);
    $router->get('/{uuid}', [TaskController::class, 'getSingle']);
    $router->put('/{uuid}', [TaskController::class, 'put']);
    $router->delete('/{uuid}', [TaskController::class, 'delete']);
});

// Add custom endpoint for task statistics
$router->get('/tasks/stats', function() {
    // Custom logic here
    return Response::success([
        'total_tasks' => 150,
        'completed_tasks' => 89,
        'pending_tasks' => 61,
        'completion_rate' => '59.3%'
    ]);
})->middleware(['auth']);
```

### Custom Validation

Add validation rules to your custom controller:

```php
public function post(array $params, array $data): Response
{
    // Custom validation rules
    $errors = [];
    
    if (empty($data['title'])) {
        $errors['title'] = 'Title is required';
    }
    
    if (isset($data['due_date']) && strtotime($data['due_date']) < time()) {
        $errors['due_date'] = 'Due date must be in the future';
    }
    
    if (!empty($errors)) {
        return Response::error('Validation failed', 422, ['errors' => $errors]);
    }
    
    return parent::post($params, $data);
}
```

## Configuration Options

Customize the ResourceController behavior in `config/resource.php`:

```php
<?php

return [
    'security' => [
        'bulk_operations' => false, // Enable bulk delete/update
        'table_access_control' => true, // Restrict sensitive tables
        'field_permissions' => false, // Hide sensitive fields
        'query_restrictions' => false, // Limit query parameters
        'ownership_validation' => true, // User-specific data access
    ],
    
    'pagination' => [
        'default_per_page' => 20,
        'max_per_page' => 100,
    ],
    
    'rate_limiting' => [
        'reads_per_minute' => 100,
        'writes_per_minute' => 50,
        'deletes_per_minute' => 20,

```

## Troubleshooting

**API returns 401 Unauthorized?**
- Make sure you're including a valid JWT token in the Authorization header
- Check the [JWT Authentication Tutorial](./2.jwt-auth-10min.md) for login instructions

**Migration fails?**
- Ensure you're using the correct `MigrationInterface` and `SchemaBuilderInterface`
- Check database connectivity with `php glueful db:status`

**Custom controller not working?**
- Verify your routes are registered correctly in `routes/api.php`
- Make sure your controller extends `ResourceController`

**Need to debug API responses?**
- Check logs in `storage/logs/`
- Use `php glueful serve
