# Production Hardening Checklist

Prepare your Glueful application for production with comprehensive security hardening, performance optimization, and deployment best practices. This checklist ensures your application is secure, performant, and maintainable in production.

## What You'll Accomplish

In this tutorial, you'll implement production-ready configurations for:

- **Security Hardening**: JWT secrets, CORS, headers, rate limiting
- **Performance Optimization**: Caching, session management, autoloader optimization
- **Environment Configuration**: Production-safe settings and secret management  
- **Monitoring & Logging**: Audit trails, error tracking, health monitoring
- **Deployment Preparation**: Database optimization, backup strategies
- **Emergency Procedures**: Lockdown systems and incident response

**Time:** ~45 minutes  
**Level:** Advanced  
**Topics:** Security hardening, Performance optimization, Production deployment, Monitoring

## Prerequisites

- Glueful application ready for deployment
- Production server access or cloud platform account
- Database configured and accessible
- Basic understanding of server administration
- SSL certificate ready for deployment

## Overview

We'll secure and optimize your application through:

1. Security configuration and secret management
2. Performance optimization and caching
3. Production environment setup
4. Monitoring and audit configuration
5. Deployment automation and health checks
6. Emergency procedures and backup strategies

### Web Server Configuration

#### Nginx Configuration

```nginx
# /etc/nginx/sites-available/your-app
server {
    listen 80;
    server_name yourdomain.com;
    return 301 https://$server_name$request_uri; # Force HTTPS
}

server {
    listen 443 ssl http2;
    server_name yourdomain.com;
    root /var/www/your-app/public;
    index index.php;

    # SSL Configuration
    ssl_certificate /path/to/your/certificate.crt;
    ssl_certificate_key /path/to/your/private.key;
    ssl_protocols TLSv1.2 TLSv1.3;
    ssl_ciphers HIGH:!aNULL:!MD5;
    ssl_prefer_server_ciphers on;

    # Security headers
    add_header X-Frame-Options DENY always;
    add_header X-Content-Type-Options nosniff always;
    add_header X-XSS-Protection "1; mode=block" always;
    add_header Strict-Transport-Security "max-age=31536000; includeSubDomains" always;

    # Hide server version
    server_tokens off;

    # Rate limiting
    limit_req_zone $binary_remote_addr zone=api:10m rate=10r/s;
    limit_req zone=api burst=20 nodelay;

    # PHP-FPM configuration
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_index index.php;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;

        # Security
        fastcgi_param HTTP_PROXY "";
    }

    # Static file caching
    location ~* \.(jpg|jpeg|png|gif|ico|css|js)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Hide sensitive files
    location ~ /\. {
        deny all;
    }

    location ~ /(config|storage|vendor) {
        deny all;
    }
}
```

### Health Monitoring Setup

```php
<?php
// app/Services/ProductionHealthService.php

namespace App\Services;

use Glueful\Services\HealthService;
use Glueful\Http\Response;

class ProductionHealthService extends HealthService
{
    /**
     * Production health checks with detailed monitoring
     */
    public function getDetailedHealth(): array
    {
        $checks = [];

        // Database health with connection pool monitoring
        $checks['database'] = $this->checkDatabaseHealth();
        
        // Redis/Cache health
        $checks['cache'] = $this->checkCacheHealth();
        
        // Queue system health
        $checks['queue'] = $this->checkQueueHealth();
        
        // Disk space monitoring
        $checks['disk'] = $this->checkDiskSpace();
        
        // Memory usage monitoring
        $checks['memory'] = $this->checkMemoryUsage();
        
        // Log file monitoring
        $checks['logs'] = $this->checkLogFiles();

        return [
            'status' => $this->determineOverallHealth($checks),
            'timestamp' => date('c'),
            'checks' => $checks,
            'version' => env('API_VERSION_FULL', '1.0.0'),
            'environment' => env('APP_ENV'),
        ];
    }

    private function checkDatabaseHealth(): array
    {
        try {
            $start = microtime(true);
            $this->repositoryFactory->executeRawQuery('SELECT 1');
            $responseTime = round((microtime(true) - $start) * 1000, 2);

            return [
                'status' => 'healthy',
                'response_time_ms' => $responseTime,
                'message' => 'Database connection successful',
            ];
        } catch (\Exception $e) {
            return [
                'status' => 'unhealthy',
                'message' => 'Database connection failed: ' . $e->getMessage(),
            ];
        }
    }

    private function checkCacheHealth(): array
    {
        try {
            $testKey = 'health_check_' . time();
            $testValue = 'test_value';
            
            // Test cache write/read
            cache()->put($testKey, $testValue, 10);
            $retrieved = cache()->get($testKey);
            cache()->forget($testKey);

            if ($retrieved === $testValue) {
                return [
                    'status' => 'healthy', 
                    'message' => 'Cache read/write successful',
                ];
            }

            return [
                'status' => 'degraded',
                'message' => 'Cache write/read inconsistent',
            ];
        } catch (\Exception $e) {
            return [
                'status' => 'unhealthy',
                'message' => 'Cache failed: ' . $e->getMessage(),
            ];
        }
    }

    private function checkDiskSpace(): array
    {
        $freeBytes = disk_free_space('/');
        $totalBytes = disk_total_space('/');
        $usedPercent = round((($totalBytes - $freeBytes) / $totalBytes) * 100, 2);

        $status = match (true) {
            $usedPercent > 90 => 'critical',
            $usedPercent > 80 => 'warning',
            default => 'healthy'
        };

        return [
            'status' => $status,
            'used_percent' => $usedPercent,
            'free_gb' => round($freeBytes / 1024 / 1024 / 1024, 2),
            'message' => "Disk usage: {$usedPercent}%",
        ];
    }

    private function checkMemoryUsage(): array
    {
        $memoryUsage = memory_get_usage(true);
        $peakMemory = memory_get_peak_usage(true);
        $memoryLimit = $this->parseMemoryLimit(ini_get('memory_limit'));

        $usedPercent = round(($peakMemory / $memoryLimit) * 100, 2);

        $status = match (true) {
            $usedPercent > 90 => 'critical',
            $usedPercent > 80 => 'warning', 
            default => 'healthy'
        };

        return [
            'status' => $status,
            'used_mb' => round($memoryUsage / 1024 / 1024, 2),
            'peak_mb' => round($peakMemory / 1024 / 1024, 2),
            'limit_mb' => round($memoryLimit / 1024 / 1024, 2),
            'used_percent' => $usedPercent,
        ];
    }

    private function parseMemoryLimit(string $limit): int
    {
        $unit = strtolower(substr($limit, -1));
        $value = (int) $limit;

        return match ($unit) {
            'g' => $value * 1024 * 1024 * 1024,
            'm' => $value * 1024 * 1024,
            'k' => $value * 1024,
            default => $value
        };
    }

    private function determineOverallHealth(array $checks): string
    {
        $statuses = array_column($checks, 'status');

        if (in_array('critical', $statuses)) return 'critical';
        if (in_array('unhealthy', $statuses)) return 'unhealthy'; 
        if (in_array('warning', $statuses)) return 'warning';
        if (in_array('degraded', $statuses)) return 'degraded';

        return 'healthy';
    }
}
```

### Incident Response Playbook

```php
<?php
// app/Services/IncidentResponseService.php

namespace App\Services;

use Glueful\Logging\LogManager;
use Glueful\Notifications\NotificationManager;

class IncidentResponseService
{
    public function __construct(
        private LogManager $logger,
        private NotificationManager $notifications
    ) {}

    /**
     * Handle security incidents with automated response
     */
    public function handleSecurityIncident(string $type, array $context = []): void
    {
        $incidentId = $this->generateIncidentId();
        
        // Log incident with full context
        $this->logger->channel('security')->critical("Security incident: {$type}", [
            'incident_id' => $incidentId,
            'type' => $type,
            'context' => $context,
            'timestamp' => date('c'),
            'server' => gethostname(),
            'ip' => $_SERVER['REMOTE_ADDR'] ?? 'unknown',
        ]);

        // Determine response level
        $responseLevel = $this->determineResponseLevel($type);

        // Execute automated response
        $this->executeResponse($responseLevel, $incidentId, $type, $context);

        // Alert administrators
        $this->alertAdministrators($incidentId, $type, $responseLevel, $context);
    }

    private function determineResponseLevel(string $type): string
    {
        return match ($type) {
            'brute_force_attack', 'sql_injection', 'xss_attempt' => 'medium',
            'data_breach', 'unauthorized_access', 'system_compromise' => 'critical',
            'suspicious_activity', 'rate_limit_exceeded' => 'low',
            default => 'medium'
        };
    }

    private function executeResponse(string $level, string $incidentId, string $type, array $context): void
    {
        switch ($level) {
            case 'critical':
                // Immediate lockdown
                exec('php glueful security:lockdown --enable --force --reason="Critical security incident: ' . $type . '"');
                break;

            case 'medium':
                // Enhanced monitoring and rate limiting
                exec('php glueful security:lockdown --enable --force --reason="Security incident: ' . $type . '"');
                break;

            case 'low':
                // Increased logging only
                $this->enableEnhancedLogging($incidentId);
                break;
        }
    }

    private function alertAdministrators(string $incidentId, string $type, string $level, array $context): void
    {
        $message = "🚨 Security Incident Alert\n\n";
        $message .= "Incident ID: {$incidentId}\n";
        $message .= "Type: {$type}\n"; 
        $message .= "Severity: {$level}\n";
        $message .= "Time: " . date('Y-m-d H:i:s T') . "\n";
        $message .= "Server: " . gethostname() . "\n\n";
        $message .= "Context: " . json_encode($context, JSON_PRETTY_PRINT);

        // Send alerts via configured channels
        $this->notifications->send('security_alert', [
            'message' => $message,
            'incident_id' => $incidentId,
            'severity' => $level,
        ]);
    }

    private function generateIncidentId(): string
    {
        return 'INC-' . date('Ymd') . '-' . strtoupper(substr(md5(uniqid()), 0, 8));
    }
}

#!/bin/bash
# scripts/backup-production.sh

set -e

APP_NAME="your-app"
BACKUP_DIR="/var/backups/${APP_NAME}"
DATE=$(date +%Y%m%d_%H%M%S)
LOG_FILE="/var/log/${APP_NAME}/backup.log"

log() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') - $1" | tee -a "$LOG_FILE"
}

# Create backup directory
mkdir -p "$BACKUP_DIR"

log "Starting backup process"

# Database backup
log "Backing up database"
mysqldump --single-transaction --routines --triggers \
    --user="$DB_USERNAME" --password="$DB_PASSWORD" \
    --host="$DB_HOST" "$DB_DATABASE" | \
    gzip > "$BACKUP_DIR/database_${DATE}.sql.gz"

# File backup  
log "Backing up files"
tar -czf "$BACKUP_DIR/files_${DATE}.tar.gz" \
    --exclude='storage/cache/*' \
    --exclude='storage/logs/*' \
    --exclude='vendor' \
    /var/www/"$APP_NAME"/

# Configuration backup
log "Backing up configuration"
tar -czf "$BACKUP_DIR/config_${DATE}.tar.gz" \
    /var/www/"$APP_NAME"/config/ \
    /etc/nginx/sites-available/"$APP_NAME" \
    /etc/php/8.2/fpm/pool.d/"$APP_NAME".conf

# Upload to S3 (optional)
if [ "$BACKUP_S3_BUCKET" != "" ]; then
    log "Uploading to S3"
    aws s3 sync "$BACKUP_DIR" "s3://$BACKUP_S3_BUCKET/backups/" \
        --exclude "*.tmp" --exclude "*.log"
fi

# Cleanup old backups (keep 30 days)
log "Cleaning up old backups"
find "$BACKUP_DIR" -name "*.gz" -mtime +30 -delete

log "Backup completed successfully"

# Verify backup integrity
log "Verifying database backup"
gunzip -t "$BACKUP_DIR/database_${DATE}.sql.gz" && \
    log "Database backup verified" || \
    log "ERROR: Database backup verification failed"

log "Backup process finished"
```
