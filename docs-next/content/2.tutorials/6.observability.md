# Observability in an Hour

Build a comprehensive observability stack for your Glueful application with structured logging, metrics collection, health monitoring, and performance tracking. Learn to monitor your application's behavior in production.

## What You'll Build

In this tutorial, you'll implement a complete observability solution featuring:

- **Structured Logging**: Centralized logging with contextual information
- **Metrics Collection**: Request metrics, business metrics, and system health
- **Health Monitoring**: Liveness and readiness endpoints with dependency checks
- **Performance Tracking**: Response times, database queries, and resource usage
- **Error Tracking**: Exception monitoring and failure analysis
- **Dashboard**: Real-time observability dashboard

**Time:** ~60 minutes  
**Level:** Advanced  
**Topics:** Logging, Metrics, Tracing, Monitoring, Performance analysis

## Prerequisites

- Glueful installed and configured
- Database connection configured
- Basic understanding of observability concepts
- Redis (optional, for advanced caching)

## Overview

We'll implement observability through:

1. Enhanced structured logging with context
2. API metrics collection and reporting
3. Health check endpoints with dependency validation  
4. Performance monitoring and profiling
5. Error tracking and alerting
6. Admin dashboard for monitoring

## Step 2: Implement Metrics Collection

Build a comprehensive metrics system for tracking application performance and business metrics.

### Metrics Middleware

```php
<?php
// app/Middleware/MetricsMiddleware.php

namespace App\Middleware;

use Glueful\Http\Response;
use Glueful\Routing\RouteMiddleware;
use Glueful\Services\ApiMetricsService;
use Symfony\Component\HttpFoundation\Request;

class MetricsMiddleware implements RouteMiddleware
{
    public function __construct(private ApiMetricsService $metrics)
    {
    }

    public function handle(Request $request, callable $next, mixed ...$params): mixed
    {
        $start = microtime(true);
        $result = $next($request);

        try {
            $durationMs = (int) round((microtime(true) - $start) * 1000);
            $status = 200;
            if (is_object($result) && method_exists($result, 'getStatusCode')) {
                /** @var int $status */
                $status = (int) $result->getStatusCode();
            }

            $this->metrics->recordMetricAsync([
                'endpoint' => $request->getPathInfo(),
                'method' => $request->getMethod(),
                'response_time' => $durationMs,
                'status_code' => $status,
                'ip' => $request->getClientIp(),
                'timestamp' => time(),
                'request_id' => function_exists('request_id') ? request_id() : null,
            ]);
        } catch (\Throwable) {
            // Never let metrics impact the request
        }

        // Normalize non-standard return types to Glueful Response for consistency
        if (is_string($result)) {
            return new Response(['message' => $result]);
        }

        return $result;
    }
}
```

## Step 3: Enhanced Health Monitoring

Create comprehensive health checks that validate all system dependencies.

### Health Check Controller

The framework provides a built-in `HealthController` that you can extend or reference. Here's how to use it:

```php
<?php
// app/Controllers/HealthController.php

namespace App\Controllers;

use Glueful\Http\Response;
use Glueful\Controllers\HealthController as BaseHealthController;
use Glueful\Services\HealthService;
use Glueful\Repository\RepositoryFactory;
use Glueful\Auth\AuthenticationManager;
use Symfony\Component\HttpFoundation\Request;

class HealthController extends BaseHealthController
{
    public function __construct(
        ?RepositoryFactory $repositoryFactory = null,
        ?AuthenticationManager $authManager = null,
        ?Request $request = null
    ) {
        parent::__construct($repositoryFactory, $authManager, $request);
    }

    /**
     * Get overall system health status
     * Uses the framework's built-in health service
     */
    public function index()
    {
        // The parent class handles rate limiting and caching automatically
        return parent::index();
    }

    /**
     * Custom readiness check for your application
     * Extends the framework's readiness probe
     */
    public function readiness(): Response
    {
        // Use framework's built-in readiness check
        $response = parent::readiness();
        
        // Add custom application-specific checks if needed
        $responseData = json_decode($response->getContent(), true);
        
        // Add your custom checks here
        $responseData['checks']['custom_service'] = $this->checkCustomService();
        
        return Response::json($responseData, $response->getStatusCode());
    }

    /**
     * Add custom service health checks
     */
    private function checkCustomService(): array
    {
        try {
            // Your custom health check logic
            return [
                'status' => 'healthy',
                'message' => 'Custom service operational',
                'last_check' => date('c')
            ];
        } catch (\Exception $e) {
            return [
                'status' => 'unhealthy',
                'message' => 'Custom service error: ' . $e->getMessage(),
                'last_check' => date('c')
            ];
        }
    }
}
```

The framework's `HealthController` provides:
- **Built-in rate limiting** for health endpoints
- **Response caching** to prevent health check abuse
- **Database health checks** using `HealthService::checkDatabase()`
- **Cache health checks** using `HealthService::checkCache()`
- **Configuration validation** using `HealthService::checkConfiguration()`
- **Kubernetes-ready** liveness and readiness probes

## Step 4: Performance Tracking Service

Track and analyze application performance patterns.

### Performance Monitor Service

```php
<?php
// app/Services/PerformanceMonitorService.php

namespace App\Services;

use Glueful\Logging\LogManager;
use Glueful\Services\ApiMetricsService;

class PerformanceMonitorService
{
    private array $timers = [];
    private array $counters = [];
    
    public function __construct(
        private LogManager $logger,
        private ApiMetricsService $metrics
    ) {}
    
    /**
     * Start a performance timer
     */
    public function startTimer(string $name, array $context = []): string
    {
        $timerId = $name . '_' . uniqid();
        
        $this->timers[$timerId] = [
            'name' => $name,
            'start_time' => microtime(true),
            'start_memory' => memory_get_usage(true),
            'context' => $context
        ];
        
        return $timerId;
    }
    
    /**
     * End a performance timer and record metrics
     */
    public function endTimer(string $timerId): ?float
    {
        if (!isset($this->timers[$timerId])) {
            return null;
        }
        
        $timer = $this->timers[$timerId];
        $endTime = microtime(true);
        $endMemory = memory_get_usage(true);
        
        $duration = $endTime - $timer['start_time'];
        $memoryDelta = $endMemory - $timer['start_memory'];
        
        // Record performance metric
        $this->metrics->recordMetricAsync([
            'metric_type' => 'performance',
            'operation' => $timer['name'],
            'duration_ms' => round($duration * 1000, 2),
            'memory_used_bytes' => $memoryDelta,
            'timestamp' => time(),
            'context' => $timer['context']
        ]);
        
        // Log performance if it's slow
        if ($duration > 1.0) { // Log operations taking more than 1 second
            $this->logger->channel('performance')->warning('Slow operation detected', [
                'operation' => $timer['name'],
                'duration_ms' => round($duration * 1000, 2),
                'memory_used_mb' => round($memoryDelta / 1024 / 1024, 2),
                'context' => $timer['context']
            ]);
        }
        
        unset($this->timers[$timerId]);
        
        return $duration;
    }
    
    /**
     * Increment a counter
     */
    public function incrementCounter(string $name, int $value = 1, array $tags = []): void
    {
        if (!isset($this->counters[$name])) {
            $this->counters[$name] = 0;
        }
        
        $this->counters[$name] += $value;
        
        $this->metrics->recordMetricAsync([
            'metric_type' => 'counter',
            'counter_name' => $name,
            'value' => $value,
            'total' => $this->counters[$name],
            'tags' => $tags,
            'timestamp' => time()
        ]);
    }
    
    /**
     * Record a gauge metric (point-in-time value)
     */
    public function recordGauge(string $name, float $value, array $tags = []): void
    {
        $this->metrics->recordMetricAsync([
            'metric_type' => 'gauge',
            'gauge_name' => $name,
            'value' => $value,
            'tags' => $tags,
            'timestamp' => time()
        ]);
    }
    
    /**
     * Track database query performance
     */
    public function trackDatabaseQuery(string $query, float $duration, array $params = []): void
    {
        $this->metrics->recordMetricAsync([
            'metric_type' => 'database_query',
            'query_hash' => md5($query),
            'duration_ms' => round($duration * 1000, 2),
            'param_count' => count($params),
            'timestamp' => time()
        ]);
        
        // Log slow queries
        if ($duration > 0.5) {
            $this->logger->channel('performance')->warning('Slow database query', [
                'query' => substr($query, 0, 200) . (strlen($query) > 200 ? '...' : ''),
                'duration_ms' => round($duration * 1000, 2),
                'params' => $params
            ]);
        }
    }
    
    /**
     * Get current performance statistics
     */
    public function getStats(): array
    {
        return [
            'active_timers' => count($this->timers),
            'counters' => $this->counters,
            'memory_usage_mb' => round(memory_get_usage(true) / 1024 / 1024, 2),
            'peak_memory_mb' => round(memory_get_peak_usage(true) / 1024 / 1024, 2)
        ];
    }
}
```

## Step 5: Error Tracking and Alerting

Implement comprehensive error tracking with context and alerting capabilities.

### Error Tracking Service

```php
<?php
// app/Services/ErrorTrackingService.php

namespace App\Services;

use Glueful\Logging\LogManager;
use Glueful\Services\ApiMetricsService;
use Throwable;

class ErrorTrackingService
{
    private array $errorCounts = [];
    
    public function __construct(
        private LogManager $logger,
        private ApiMetricsService $metrics
    ) {}
    
    /**
     * Track and analyze an error
     */
    public function trackError(Throwable $error, array $context = []): string
    {
        $errorId = $this->generateErrorId($error);
        $errorType = get_class($error);
        
        // Increment error count
        if (!isset($this->errorCounts[$errorType])) {
            $this->errorCounts[$errorType] = 0;
        }
        $this->errorCounts[$errorType]++;
        
        // Extract meaningful context
        $errorContext = [
            'error_id' => $errorId,
            'error_type' => $errorType,
            'message' => $error->getMessage(),
            'file' => $error->getFile(),
            'line' => $error->getLine(),
            'trace' => $this->formatStackTrace($error),
            'context' => $context,
            'occurrence_count' => $this->errorCounts[$errorType]
        ];
        
        // Log error with full context
        $this->logger->channel('error')->error('Application error tracked', $errorContext);
        
        // Record error metric
        $this->metrics->recordMetricAsync([
            'metric_type' => 'error',
            'error_id' => $errorId,
            'error_type' => $errorType,
            'error_message' => $error->getMessage(),
            'file' => basename($error->getFile()),
            'line' => $error->getLine(),
            'severity' => $this->determineSeverity($error),
            'timestamp' => time(),
            'context' => $context
        ]);
        
        // Check if this error requires alerting
        if ($this->shouldAlert($error)) {
            $this->sendAlert($error, $errorContext);
        }
        
        return $errorId;
    }
    
    /**
     * Track a custom error event
     */
    public function trackCustomError(string $type, string $message, array $context = []): void
    {
        $this->logger->channel('error')->error("Custom error: {$type}", [
            'message' => $message,
            'context' => $context
        ]);
        
        $this->metrics->recordMetricAsync([
            'metric_type' => 'custom_error',
            'error_type' => $type,
            'error_message' => $message,
            'timestamp' => time(),
            'context' => $context
        ]);
    }
    
    /**
     * Get error statistics
     */
    public function getErrorStats(): array
    {
        return [
            'total_errors' => array_sum($this->errorCounts),
            'error_types' => $this->errorCounts,
            'most_frequent' => $this->getMostFrequentError(),
            'timestamp' => date('c')
        ];
    }
    
    private function generateErrorId(Throwable $error): string
    {
        $signature = $error->getFile() . ':' . $error->getLine() . ':' . get_class($error);
        return substr(md5($signature), 0, 12);
    }
    
    private function formatStackTrace(Throwable $error): array
    {
        $trace = [];
        foreach ($error->getTrace() as $i => $frame) {
            $trace[] = [
                'file' => $frame['file'] ?? 'unknown',
                'line' => $frame['line'] ?? 0,
                'function' => ($frame['class'] ?? '') . ($frame['type'] ?? '') . ($frame['function'] ?? ''),
                'args' => $this->sanitizeArgs($frame['args'] ?? [])
            ];
            
            // Limit trace depth
            if ($i >= 10) break;
        }
        
        return $trace;
    }
    
    private function sanitizeArgs(array $args): array
    {
        // Remove sensitive data from arguments
        return array_map(function ($arg) {
            if (is_string($arg) && strlen($arg) > 100) {
                return substr($arg, 0, 100) . '...';
            }
            if (is_object($arg)) {
                return get_class($arg);
            }
            if (is_array($arg)) {
                return '[Array with ' . count($arg) . ' elements]';
            }
            return $arg;
        }, array_slice($args, 0, 5)); // Limit to first 5 args
    }
    
    private function determineSeverity(Throwable $error): string
    {
        // Determine error severity based on type
        $errorType = get_class($error);
        
        return match (true) {
            str_contains($errorType, 'Fatal') => 'critical',
            str_contains($errorType, 'Error') => 'error',
            str_contains($errorType, 'Warning') => 'warning',
            str_contains($errorType, 'Notice') => 'info',
            default => 'error'
        };
    }
    
    private function shouldAlert(Throwable $error): bool
    {
        $errorType = get_class($error);
        
        // Alert on critical errors or high frequency
        return $this->determineSeverity($error) === 'critical' 
            || $this->errorCounts[$errorType] > 10;
    }
    
    private function sendAlert(Throwable $error, array $context): void
    {
        // Implement alerting mechanism (email, Slack, etc.)
        $this->logger->channel('alert')->critical('Error alert triggered', [
            'error_type' => get_class($error),
            'message' => $error->getMessage(),
            'file' => $error->getFile(),
            'line' => $error->getLine(),
            'context' => $context
        ]);
    }
    
    private function getMostFrequentError(): ?array
    {
        if (empty($this->errorCounts)) {
            return null;
        }
        
        $mostFrequent = array_keys($this->errorCounts, max($this->errorCounts))[0];
        
        return [
            'type' => $mostFrequent,
            'count' => $this->errorCounts[$mostFrequent]
        ];
    }
}
```

### Applying Middleware to Routes

In the Glueful framework, middleware is applied directly to routes using the `->middleware()` method or within route groups. Here are examples:

```php
<?php
// routes/api.php - Examples of middleware usage

use App\Controllers\UserController;
use App\Controllers\ObservabilityController;

// Apply middleware to individual routes
$router->get('/users', [UserController::class, 'index'])
    ->middleware('auth'); // Single middleware

$router->post('/users', [UserController::class, 'store'])
    ->middleware('auth', 'metrics'); // Multiple middleware

// Apply middleware with parameters
$router->get('/api/limited', function () {
    return ['message' => 'Rate limited endpoint'];
})->middleware('rate_limit:10,60'); // 10 requests per 60 seconds

// Apply middleware to route groups
$router->group(['middleware' => ['auth', 'metrics']], function($router) {
    $router->get('/profile', [UserController::class, 'profile']);
    $router->put('/profile', [UserController::class, 'updateProfile']);
    
    // Admin routes with additional middleware
    $router->group(['prefix' => '/admin', 'middleware' => ['admin']], function($router) {
        $router->get('/observability/dashboard', [ObservabilityController::class, 'dashboard']);
        $router->get('/observability/data', [ObservabilityController::class, 'dashboardData']);
    });
});
```

The framework includes built-in middleware that can be referenced by string aliases:
- `rate_limit` - Built-in rate limiting (see health routes for examples)
- Custom middleware classes are referenced by their full class name
