# Tutorials

Learn Glueful by building real applications and features. These guided tutorials take you through complete implementations with working code, explanations, and best practices.

## Getting Started Tutorials

Perfect for developers new to Glueful who want hands-on experience building real features.

### [Build a JSON API in 15 Minutes](/tutorials/json-api-15min)
Create a complete REST API with CRUD operations, validation, and database integration.

**What you'll build:** A task management API with create, read, update, and delete operations
**Time:** ~15 minutes  
**Level:** Beginner
**Topics:** Routing, Controllers, Database, Validation, JSON responses

### [JWT Authentication in 10 Minutes](/tutorials/jwt-auth-10min)
Implement secure JWT-based authentication with login, registration, and protected routes.

**What you'll build:** User authentication system with JWT tokens
**Time:** ~10 minutes
**Level:** Beginner  
**Topics:** Authentication, JWT, Middleware, Security, User management

## Tutorial Format

Each tutorial follows a consistent structure:

- **Overview** - What you'll build and learn
- **Prerequisites** - Required knowledge and setup
- **Step-by-step implementation** - Code with explanations
- **Testing** - How to verify it works
- **Next steps** - Related concepts and improvements
- **Full source code** - Complete working examples

## Prerequisites

All tutorials assume you have:

- PHP 8.2+ installed
- Composer installed  
- Basic PHP and API development knowledge
- Glueful installed (follow the [installation guide](/start/installation))
