# Routing

Glueful's router delivers O(1) static route lookup, optimized dynamic bucketing, ordered middleware pipelines, attribute-based route declarations, field selection integration, and route caching for production. This guide shows how to build a clean, maintainable HTTP surface.

## Quick Start

In route files (e.g. `routes/api.php`) a `$router` variable is injected:

```php
use Glueful\Http\Response;
use Glueful\Routing\Router;
/** @var Router $router Router instance injected by RouteManifest::load() */

$router->get('/health', fn () => new Response(['status' => 'healthy', 'timestamp' => date('c')]));
```

## Defining Routes

Supported HTTP method helpers: `get`, `post`, `put`, `delete`, `head`.

```php
$router->get('/users', [UserController::class, 'index']);
$router->post('/users', [UserController::class, 'store']);
$router->put('/users/{id}', [UserController::class, 'update']);
$router->delete('/users/{id}', [UserController::class, 'destroy']);
```

Returns from handlers may be `Glueful\Http\Response`, Symfony responses (`JsonResponse`, `StreamedResponse`, etc.) or raw values normalized by higher layers (see Requests & Responses guide).

## Route Parameters

Parameters use `{param}` syntax. Values are injected into handler arguments by position/name & can be type‑hinted.

```php
$router->get('/users/{id}', function (int $id) {
	return new Response(['user_id' => $id]);
});
```

### Constraints

Constrain parameters with `where()` for fast failure & safety:

```php
$router->get('/users/{id}', [UserController::class, 'show'])
	->where('id', '\d+');

$router->get('/posts/{year}/{month}/{slug}', [PostController::class, 'show'])
	->where([
		'year' => '\d{4}',
		'month' => '\d{2}',
		'slug' => '[a-z0-9-]+'
	]);
```

## Dependency Injection in Handlers

Constructor/services are auto-resolved from the container when type‑hinted:

```php
use Psr\Log\LoggerInterface;

$router->get('/users/{id}', function (int $id, LoggerInterface $logger, UserService $service) {
	$logger->info('Fetch user', ['id' => $id]);
	return new Response(['user' => $service->find($id)]);
});
```

## Route Groups

Apply shared `prefix` and `middleware` attributes:

```php
$router->group(['prefix' => '/api/v1', 'middleware' => ['auth']], function (\Glueful\Routing\Router $router) {
	$router->get('/profile', [ProfileController::class, 'show']);
	$router->put('/profile', [ProfileController::class, 'update']);
});
```

Nested groups merge prefixes and middleware stacks (outer first, inner appended).

## Middleware

Attach middleware inline or through groups. Parameterized middleware uses colon syntax:

```php
$router->get('/dashboard', [DashboardController::class, 'index'])
	->middleware('rate_limit:60,60'); // maxAttempts, windowSeconds

$router->group(['middleware' => ['auth', 'cors']], function ($router) {
	$router->get('/secure', [SecureController::class, 'index']);
});
```

Register middleware identifiers in a service provider/container for resolution.

## Attribute-Based Routing

Define routes directly on controller classes/methods using PHP 8 attributes.

```php
use Glueful\Routing\Attributes\{Controller, Get, Post, Put, Delete, Middleware, Fields};
use Glueful\Http\Response;

#[Controller(prefix: '/api/users', middleware: ['auth'])]
class UserController
{
	#[Get('/', name: 'users.index')]
	public function index(): Response
	{ return new Response(['users' => []]); }

	#[Get('/{id}', where: ['id' => '\\d+'], name: 'users.show')]
	#[Fields(allowed: ['id','name','email','posts','posts.comments'])]
	public function show(int $id): Response
	{ return new Response(['user' => ['id' => $id]]); }

	#[Post('/', middleware: ['validate:user'])]
	public function store(Request $request): Response
	{ return new Response(['created' => true], 201); }
}
```

Load attribute routes (e.g. bootstrap/service provider):

```php
$loader = new \Glueful\Routing\AttributeRouteLoader($container);
$loader->load(['App\\Controllers\\' => base_path('app/Controllers')]);
```

## Field Selection (Projection)

Optional field selection prevents over‑fetching.

```php
use Glueful\Support\FieldSelection\FieldSelector;
use Glueful\Routing\Attributes\{Get, Fields};

class ProfileController
{
	#[Get('/users/{id}')]
	#[Fields(allowed: ['id','name','email','posts','posts.comments'], strict: true)]
	public function show(int $id, FieldSelector $selector): array
	{
		$user = $this->users->findAsArray($id);
		if ($selector->requested('posts')) {
			$user['posts'] = $this->posts->findByUser($id);
			if ($selector->requested('posts.comments')) {
				// batch load comments ...
			}
		}
		return $user; // Projection middleware trims fields
	}
}
```

Enable via middleware group: `field_selection`.

Example requests:

```
GET /users/123?fields=id,name,email&expand=posts.title
GET /users/123?fields=user(id,name,posts(title,comments(text)))
```

## Named Routes & URL Generation

Name routes for reuse and URL building:

```php
$router->get('/users/{id}', [UserController::class, 'show'])
	->where('id', '\d+')
	->name('users.show');

$url = router()->url('users.show', ['id' => 42]); // /users/42
```

## Rate Limiting Patterns

Use stricter limits for auth & destructive operations; generous for health checks.

```php
$router->post('/auth/login', [AuthController::class, 'login'])
	->middleware('rate_limit:5,60');
$router->delete('/users/{id}', [UserController::class, 'destroy'])
	->middleware(['auth','rate_limit:10,60']);
```

## Route Caching

Production boots with compiled route cache automatically. Development invalidates on file change—no manual command normally required. (CLI utilities may expose `route:list`, `route:match`, `route:clear`).

## Performance Techniques

1. Prefer explicit static routes (`/users/popular`) before dynamic (`/users/{id}`) — bucketing already optimizes but clarity helps.
2. Apply tight regex constraints to fail fast.
3. Group by feature & version to reduce duplication.
4. Keep middleware lists short & purpose‑specific.
5. Avoid heavy I/O before authentication & rate limiting.

## Best Practices

- Organize by domain (`routes/auth.php`, `routes/health.php`).
- Use route names for links & version negotiation.
- Keep controllers thin: delegate to services.
- Return consistent JSON (`success`, `message`, `data`).
- Rate limit login/OTP more aggressively than reads.
- Add CORS and security headers via middleware groups.
