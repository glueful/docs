Glueful provides comprehensive edge caching capabilities through its pluggable CDN adapter system. This enables integration with Content Delivery Networks (CDNs) like Cloudflare, AWS CloudFront, and other providers to cache content at edge locations globally.

## Overview

The Edge Cache system consists of:

- **CDN Adapter Interface** - Standardized interface for CDN providers
- **Cloudflare Adapter** - Built-in Cloudflare integration extension
- **Edge Cache Service** - Core service for managing edge caching
- **Cache Control Middleware** - Automatic HTTP cache header management
- **CLI Commands** - Command-line tools for cache management

## Configuration

### Basic Configuration

Configure edge caching in `config/cache.php`:

```php
'edge' => [
    'enabled' => env('EDGE_CACHE_ENABLED', false),
    'provider' => env('EDGE_CACHE_PROVIDER', 'cloudflare'),
    'default_ttl' => env('EDGE_CACHE_TTL', 3600),
    'rules' => [
        // Route-specific cache rules
        'GET /api/users' => ['ttl' => 300],
        'GET /api/content/*' => ['ttl' => 1800],
        'GET /static/*' => ['ttl' => 86400], // 24 hours
    ],
],
```

### Environment Variables

Set up your environment variables:

```bash
# Enable edge caching
EDGE_CACHE_ENABLED=true
EDGE_CACHE_PROVIDER=cloudflare
EDGE_CACHE_TTL=3600

# Cloudflare configuration
CLOUDFLARE_API_TOKEN=your_api_token_here
CLOUDFLARE_ZONE_ID=your_zone_id_here
```

## Cloudflare Integration

### Installation

The Cloudflare adapter comes as a built-in extension. Enable it through the extensions system:

```bash
# Enable the Cloudflare adapter extension
php glueful extensions:enable CloudflareAdapter
```

### Configuration

Configure the Cloudflare adapter with your API credentials:

```php
// In config/cache.php or extension configuration
'cloudflare' => [
    'api_token' => env('CLOUDFLARE_API_TOKEN'),
    'zone_id' => env('CLOUDFLARE_ZONE_ID'),
    'default_ttl' => 3600,
    'route_config' => [
        'GET /api/users' => [
            'ttl' => 300,
            'vary_by' => ['Authorization', 'Accept-Language']
        ],
        'GET /images/*' => [
            'ttl' => 86400,
            'immutable' => true
        ],
    ],
],
```

### Testing Connection

Verify your Cloudflare integration:

```bash
# Test Cloudflare API connection
curl "http://your-app.com/api/extensions/CloudflareAdapter?action=test_connection"
```

## Using Edge Cache Service

### Basic Usage

```php
use Glueful\Cache\EdgeCacheService;

// Initialize edge cache service
$edgeCache = new EdgeCacheService();

// Generate cache headers for a route
$headers = $edgeCache->generateCacheHeaders('/api/users', 'application/json');

// Check if content is cacheable
$isCacheable = $edgeCache->isCacheable($request, $response);

// Get cache statistics
$stats = $edgeCache->getStats();
```

### Cache Headers Generation

The service automatically generates appropriate cache headers:

```php
// For API endpoint /api/users
$headers = $edgeCache->generateCacheHeaders('/api/users');

// Result:
[
    'Cache-Control' => 'public, max-age=300',
    'X-Cache-Provider' => 'cloudflare',
    'Vary' => 'Authorization, Accept-Language'
]
```

### Route-Specific Configuration

Configure different caching rules for different routes:

```php
'route_config' => [
    // Short cache for dynamic content
    'GET /api/users' => [
        'ttl' => 300,
        'vary_by' => ['Authorization']
    ],

    // Long cache for static resources
    'GET /images/*' => [
        'ttl' => 86400,
        'immutable' => true
    ],

    // No cache for sensitive endpoints
    'GET /admin/*' => [
        'ttl' => 0,
        'private' => true
    ],
],
```

## Cache Purging

### CLI Commands

Use CLI commands to manage edge cache:

```bash
# Purge all cached content
php glueful edge:purge --all

# Purge specific URL
php glueful edge:purge --url=https://example.com/api/users

# Purge by cache tag
php glueful edge:purge --tag=users

# Purge multiple URLs
php glueful edge:purge --urls=/api/users,/api/posts,/api/content
```

### Programmatic Purging

Purge cache programmatically:

```php
use Glueful\Cache\EdgeCacheService;

$edgeCache = new EdgeCacheService();

// Purge specific URL
$success = $edgeCache->purgeUrl('https://example.com/api/users');

// Purge by cache tag
$success = $edgeCache->purgeByTag('users');

// Purge all cache
$success = $edgeCache->purgeAll();
```

### API Endpoints

Use HTTP API for cache management:

```bash
# Purge all cache
curl -X POST "http://your-app.com/api/extensions/CloudflareAdapter?action=purge_cache&purge_all=true"

# Purge specific URL
curl -X POST "http://your-app.com/api/extensions/CloudflareAdapter?action=purge_cache" \
     -H "Content-Type: application/json" \
     -d '{"url": "https://example.com/api/users"}'

# Purge by tag
curl -X POST "http://your-app.com/api/extensions/CloudflareAdapter?action=purge_cache" \
     -H "Content-Type: application/json" \
     -d '{"tag": "users"}'
```

## Cache Tags

### Using Cache Tags

Cache tags enable granular cache invalidation:

```php
use Glueful\Cache\CacheTaggingService;

// Tag cache entries
CacheTaggingService::tagCache('user:profile:123', ['users', 'profiles']);
CacheTaggingService::tagCache('post:456', ['posts', 'content']);

// Invalidate by tag
$result = CacheTaggingService::invalidateByTag('users');
```

### Response Tagging

Automatically tag responses based on content:

```php
// In your controller or middleware
$response->headers->set('Cache-Tag', 'users,profiles');

// Or programmatically
$edgeCache->tagResponse($response, ['users', 'profiles']);
```

## HTTP Cache Control Middleware

### Basic Setup

The Cache Control Middleware automatically manages HTTP cache headers:

```php
use Glueful\Http\Middleware\CacheControlMiddleware;
use Glueful\Http\Router;

// Add cache middleware
Router::addMiddleware(new CacheControlMiddleware([
    'public' => true,
    'max_age' => 3600,
    'routes' => [
        'GET /api/users' => ['max_age' => 300],
        'GET /static/*' => ['max_age' => 86400, 'immutable' => true],
    ],
    'content_types' => [
        'image/*' => ['max_age' => 86400, 'immutable' => true],
        'application/json' => ['max_age' => 300],
    ],
]));
```

### Configuration Options

```php
[
    'public' => true,                     // Public or private cache
    'max_age' => 3600,                    // Default max age in seconds
    's_maxage' => 7200,                   // Shared cache max age (CDN)
    'must_revalidate' => true,            // Force revalidation when stale
    'immutable' => false,                 // Content never changes
    'etag' => true,                       // Generate ETags

    'methods' => [                        // HTTP method defaults
        'GET' => true,
        'HEAD' => true,
        'POST' => false,
        'PUT' => false,
        'DELETE' => false,
    ],

    'routes' => [                         // Route-specific overrides
        'GET /users' => ['max_age' => 300],
        'GET /blobs/*' => ['max_age' => 86400],
    ],

    'content_types' => [                  // Content-type specific settings
        'image/*' => ['max_age' => 86400, 'immutable' => true],
        'application/pdf' => ['max_age' => 86400],
        'text/css' => ['max_age' => 86400, 'immutable' => true],
        'application/javascript' => ['max_age' => 86400, 'immutable' => true],
    ],
]
```

## Creating Custom CDN Adapters

### Implementing CDN Adapter Interface

Create a custom adapter for your CDN provider:

```php
<?php

namespace MyApp\CDN;

use Glueful\Cache\CDN\AbstractCDNAdapter;

class CustomCDNAdapter extends AbstractCDNAdapter
{
    /**
     * Purge specific URL from cache
     */
    public function purgeUrl(string $url): bool
    {
        // Implement your CDN's URL purge API
        $result = $this->makeApiRequest('/purge/url', [
            'url' => $url
        ]);

        return $result['success'] ?? false;
    }

    /**
     * Purge content by cache tag
     */
    public function purgeByTag(string $tag): bool
    {
        // Implement your CDN's tag-based purge API
        $result = $this->makeApiRequest('/purge/tag', [
            'tag' => $tag
        ]);

        return $result['success'] ?? false;
    }

    /**
     * Purge all cached content
     */
    public function purgeAll(): bool
    {
        // Implement your CDN's full cache purge API
        $result = $this->makeApiRequest('/purge/all');

        return $result['success'] ?? false;
    }

    /**
     * Get CDN provider name
     */
    public function getProviderName(): string
    {
        return 'custom';
    }

    /**
     * Get cache statistics
     */
    public function getStats(): array
    {
        // Implement stats retrieval from your CDN
        return [
            'provider' => 'custom',
            'status' => 'connected',
            'cache_hit_ratio' => 0.90,
        ];
    }

    /**
     * Check connection status
     */
    public function getStatus(): array
    {
        // Test connection to your CDN API
        try {
            $this->makeApiRequest('/status');
            return ['status' => 'connected'];
        } catch (\Exception $e) {
            return ['status' => 'error', 'message' => $e->getMessage()];
        }
    }

    /**
     * Make API request to CDN provider
     */
    private function makeApiRequest(string $endpoint, array $data = []): array
    {
        // Implement HTTP client logic for your CDN's API
        // Return parsed response as array
    }
}
```

### Creating CDN Adapter Extension

Create an extension to register your custom adapter:

```php
<?php

namespace MyApp\Extensions;

use Glueful\Extensions;
use MyApp\CDN\CustomCDNAdapter;

class CustomCDNExtension extends Extensions
{
    public static function registerServices(): void
    {
        // Register the adapter with configuration
        $config = config('cdn.custom', []);
        $adapter = new CustomCDNAdapter($config);

        // Register with the edge cache service
        app()->singleton('cdn.custom', function() use ($adapter) {
            return $adapter;
        });
    }
}
```

## Troubleshooting

### Common Issues

**Cache not being purged:**

- Verify API credentials are correct
- Check network connectivity to CDN provider
- Ensure proper permissions for purge operations

**Headers not being set:**

- Verify middleware is properly registered
- Check route configuration matches actual routes
- Ensure content types are correctly specified

**Performance issues:**

- Monitor cache hit ratios
- Review TTL settings for different content types
- Check for cache stampede scenarios

### Debug Mode

Enable debug logging for edge cache operations:

```php
// In your configuration
'edge' => [
    'enabled' => true,
    'debug' => env('EDGE_CACHE_DEBUG', false),
    'log_channel' => 'edge_cache',
],
```

```bash
# Test purge functionality

```

## Best Practices

### Cache Strategy Design

- **Static Assets**: Use long TTLs (24+ hours) with immutable flag
- **API Responses**: Use shorter TTLs (5-30 minutes) based on data volatility
- **User-Specific Content**: Use private cache or no cache
- **Images/Media**: Use very long TTLs with proper versioning

### Cache Invalidation

- **Use Cache Tags**: Group related content for efficient invalidation
- **Granular Purging**: Prefer tag-based or URL-specific purging over full purges
- **Event-Driven**: Automatically purge cache when content changes
- **Batch Operations**: Group multiple purge operations when possible

### Performance Optimization

- **Monitor Hit Ratios**: Aim for 80%+ cache hit ratios
- **Configure Vary Headers**: Only vary on necessary headers
- **Use Compression**: Enable gzip/brotli compression at CDN level
- **Optimize TTLs**: Balance freshness with performance

### Security Considerations

- **Sensitive Data**: Never cache sensitive user information
- **Authentication**: Use private cache for authenticated content
- **API Keys**: Secure CDN API credentials properly
- **Rate Limiting**: Implement rate limiting for purge operations
