Glueful provides comprehensive memory management capabilities designed for high-performance applications and long-running processes. The system includes real-time monitoring, automated optimization, intelligent alerting, and memory-efficient data processing utilities.

## Overview

The Glueful Memory Management System offers:

- **Real-time Monitoring** - CLI tools and middleware for continuous memory tracking
- **Intelligent Alerting** - Multi-channel alerts with rate limiting and context awareness
- **Memory Optimization** - Object pooling, garbage collection, and efficient iterators
- **Production Ready** - Configurable thresholds, sampling, and automated responses
- **Performance Analytics** - Detailed memory usage reporting and CSV logging
- **Memory-efficient Processing** - Streaming iterators and chunk-based processing

## Quick Start

### Basic Memory Monitoring

```bash
# Monitor current process memory usage
php glueful memory:monitor

# Monitor another command's memory usage
php glueful memory:monitor php your-script.php

# Monitor with custom threshold and logging
php glueful memory:monitor --threshold=50 --log --csv=memory-stats.csv
```

### Programmatic Memory Management

```php
use Glueful\Performance\MemoryManager;

// Initialize memory manager
$memoryManager = new MemoryManager();

// Get current memory usage
$usage = $memoryManager->getCurrentUsage();
echo "Current: {$usage['formatted']['current']}";
echo "Peak: {$usage['formatted']['peak']}";
echo "Limit: {$usage['formatted']['limit']}";
echo "Usage: " . round($usage['percentage'] * 100, 2) . "%";

// Monitor with automatic actions
$usage = $memoryManager->monitor();

// Force garbage collection
if ($memoryManager->isMemoryHighUsage()) {
    $memoryManager->forceGarbageCollection();
}
```

### Threshold Management

Configure and check memory thresholds:

```php
// Environment configuration
// .env
MEMORY_ALERT_THRESHOLD=0.8     // 80% for warnings
MEMORY_CRITICAL_THRESHOLD=0.9  // 90% for critical alerts

// Check thresholds programmatically
if ($memoryManager->isMemoryHighUsage()) {
    // Memory usage above 80%
    logger()->warning('High memory usage detected');
    $memoryManager->forceGarbageCollection();
}

if ($memoryManager->isMemoryCritical()) {
    // Memory usage above 90%
    logger()->error('Critical memory usage detected');
    // Emergency cleanup procedures
}
```

## Memory Pool

### Object Pooling

The `MemoryPool` class provides efficient object reuse:

```php
use Glueful\Performance\MemoryPool;

// Initialize pool with custom size
$pool = new MemoryPool(maxSize: 500);

// Store objects in the pool
$expensiveObject = new ExpensiveCalculator();
$pool->add('calculator_1', $expensiveObject);

// Retrieve objects from the pool
$calculator = $pool->get('calculator_1');
if ($calculator) {
    $result = $calculator->calculate($data);
}

// Check pool statistics
$stats = $pool->getStats();
/*
Returns:
[
    'current_size' => 150,
    'max_size' => 500,
    'usage_percentage' => 30.0,
    'keys' => 150
]
*/
```

### LRU Eviction

The pool automatically evicts least recently used items:

```php
// Pool automatically manages memory using LRU
for ($i = 0; $i < 1000; $i++) {
    $object = new SomeObject($i);
    $pool->add("object_$i", $object);
    
    // When pool reaches max size, least recently used items are evicted
}

// Manual pool management
$pool->remove('specific_key');  // Remove specific item
$pool->clear();                 // Clear entire pool

// Get pool information
$keys = $pool->getKeys();       // All stored keys
$size = $pool->size();          // Current size
$capacity = $pool->capacity();  // Maximum capacity
```

## Memory-Efficient Iterators

### Large Dataset Processing

Process large datasets without loading everything into memory:

```php
use Glueful\Performance\MemoryEfficientIterators;

// Stream processing
$largeDataset = getLargeDataset(); // Could be millions of records
foreach (MemoryEfficientIterators::stream($largeDataset) as $key => $item) {
    processItem($item);
    // Only one item in memory at a time
}

// Chunk processing
$results = MemoryEfficientIterators::processInChunks(
    $largeDataset,
    function($chunk) {
        // Process 1000 items at a time
        return processBatch($chunk);
    },
    chunkSize: 1000
);
```

### Database Result Streaming

Process large database results efficiently:

```php
// PDO example
$stmt = $pdo->prepare("SELECT * FROM large_table WHERE condition = ?");
$stmt->execute([$condition]);

foreach (MemoryEfficientIterators::databaseResults($stmt) as $row) {
    processRow($row);
    // Only one row in memory at a time
}

// With chunked processing
$stmt = $pdo->prepare("SELECT * FROM massive_table");
$stmt->execute();

$results = MemoryEfficientIterators::processInChunks(
    MemoryEfficientIterators::databaseResults($stmt),
    function($rows) {
        return bulkProcessRows($rows);
    },
    chunkSize: 500
);
```

### File Processing

Process large files line by line:

```php
// Process large CSV file
foreach (MemoryEfficientIterators::fileLineByLine('/path/to/large-file.csv') as $line) {
    $data = str_getcsv($line);
    processRecord($data);
}

// With line processing
foreach (MemoryEfficientIterators::fileLineByLine(
    '/path/to/large-log.txt',
    function($line) {
        return json_decode(trim($line), true);
    }
) as $logEntry) {
    analyzeLogEntry($logEntry);
}
```

### Functional Processing

Use functional programming patterns efficiently:

```php
// Memory-efficient map
$processedItems = MemoryEfficientIterators::map(
    $largeDataset,
    function($item) {
        return transformItem($item);
    }
);

// Memory-efficient filter
$filteredItems = MemoryEfficientIterators::filter(
    $largeDataset,
    function($item) {
        return $item['status'] === 'active';
    }
);

// Chain operations
$results = MemoryEfficientIterators::filter(
    MemoryEfficientIterators::map($largeDataset, $transformer),
    $filter
);
```

## Integration Examples

### Service Integration

```php
use Glueful\Performance\MemoryManager;
use Glueful\Performance\MemoryPool;
use Glueful\Performance\MemoryAlertingService;

class DataProcessingService
{
    private MemoryManager $memoryManager;
    private MemoryPool $pool;
    private MemoryAlertingService $alerting;

    public function __construct()
    {
        $this->memoryManager = new MemoryManager();
        $this->pool = new MemoryPool(500);
        $this->alerting = new MemoryAlertingService($this->memoryManager);
    }

    public function processLargeDataset(array $data): array
    {
        // Check memory before starting
        $this->alerting->checkAndAlert('data_processing', [
            'operation' => 'large_dataset',
            'records' => count($data)
        ]);

        $results = [];
        
        foreach (MemoryEfficientIterators::processInChunks($data, function($chunk) {
            // Check memory usage during processing
            if ($this->memoryManager->isMemoryHighUsage()) {
                $this->memoryManager->forceGarbageCollection();
            }
            
            return $this->processChunk($chunk);
        }, 1000) as $chunkResult) {
            $results = array_merge($results, $chunkResult);
        }

        return $results;
    }

    private function processChunk(array $chunk): array
    {
        $processor = $this->pool->get('data_processor');
        if (!$processor) {
            $processor = new DataProcessor();
            $this->pool->add('data_processor', $processor);
        }

        return $processor->process($chunk);
    }
}
```

### Background Job Integration

```php
class MemoryAwareBatchJob
{
    private MemoryManager $memoryManager;

    public function handle(array $items): void
    {
        $this->memoryManager = new MemoryManager();
        
        // Process items in memory-efficient chunks
        foreach (MemoryEfficientIterators::processInChunks($items, function($chunk) {
            return $this->processChunk($chunk);
        }, 100) as $result) {
            
            // Monitor memory after each chunk
            $usage = $this->memoryManager->monitor();
            
            if ($usage['percentage'] > 0.8) {
                // Take a break to let memory settle
                sleep(1);
            }
        }
    }
}
```

## Performance Optimization

### Memory Usage Patterns

```php
// Good: Use streaming for large datasets
foreach (MemoryEfficientIterators::stream($largeDataset) as $item) {
    processItem($item);
}

// Bad: Load entire dataset into memory
$allItems = $repository->getAll(); // Could be millions of records
foreach ($allItems as $item) {
    processItem($item);
}

// Good: Use object pooling for expensive objects
$calculator = $pool->get('calculator') ?? new ExpensiveCalculator();
$result = $calculator->calculate($data);
$pool->add('calculator', $calculator);

// Bad: Create new objects repeatedly
for ($i = 0; $i < 1000; $i++) {
    $calculator = new ExpensiveCalculator(); // Expensive!
    $results[] = $calculator->calculate($data[$i]);
}
```

### Memory Monitoring Best Practices

```php
// Monitor critical operations
class CriticalOperation
{
    public function execute(): void
    {
        $memoryManager = new MemoryManager();
        
        // Check before starting
        $initialUsage = $memoryManager->getCurrentUsage();
        
        try {
            $this->performOperation();
        } finally {
            // Check after completion
            $finalUsage = $memoryManager->getCurrentUsage();
            $memoryUsed = $finalUsage['current'] - $initialUsage['current'];
            
            if ($memoryUsed > 10 * 1024 * 1024) { // 10MB
                logger()->warning('High memory usage in critical operation', [
                    'memory_used' => $memoryUsed,
                    'initial' => $initialUsage['formatted']['current'],
                    'final' => $finalUsage['formatted']['current']
                ]);
            }
        }
    }
}
```

## Troubleshooting

### Common Memory Issues

**High memory usage alerts:**
- Check for memory leaks in long-running processes
- Use memory-efficient iterators for large datasets
- Enable garbage collection for critical operations
- Monitor object pooling effectiveness

**Memory monitoring overhead:**
- Adjust sampling rates for production environments
- Configure appropriate logging thresholds
- Use middleware selectively on critical endpoints

**Pool effectiveness:**
- Monitor pool statistics and hit rates
- Adjust pool sizes based on usage patterns
- Consider LRU eviction behavior for object access patterns
