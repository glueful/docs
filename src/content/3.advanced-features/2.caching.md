Glueful includes an enterprise-grade caching system that provides comprehensive performance optimization through intelligent caching, tagging, distribution, and invalidation mechanisms. This section covers the full spectrum of caching capabilities in the Glueful framework.

## Cache System Overview

The Glueful caching system is built around multiple specialized services working together:

- **CacheEngine** - Core caching interface with multi-driver support
- **Cache Tagging** - Group and invalidate related cache entries
- **Query Caching** - Automatic database query result caching
- **Edge Caching** - CDN and edge cache integration
- **Distributed Caching** - Multi-node cache distribution with failover
- **Cache Warmup** - Strategic pre-loading of critical data
- **Cache Invalidation** - Event-driven cache invalidation

### Supported Cache Drivers

- **Redis** - Full-featured Redis with sorted sets, patterns, and pipelines
- **Memcached** - Distributed memory caching with batch operations
- **File** - Filesystem-based caching with fallback capabilities

The system provides automatic fallback, secure serialization, and comprehensive monitoring.

## Configuration Options

Cache settings are defined in `config/cache.php`. Here's an overview of the available configuration options:

```php
// Default cache driver (redis, memcached, file)
'default' => env('CACHE_DRIVER', 'redis'),

// Global cache prefix for key namespacing
'prefix' => env('CACHE_PREFIX', 'glueful:'),

// Enable file-based fallback if primary cache fails
'fallback_to_file' => env('CACHE_FALLBACK', true),

// Default TTL in seconds
'ttl' => env('CACHE_TTL', 3600),

// Lock timeout in seconds
'lock_ttl' => env('CACHE_LOCK_TTL', 60),
```

## Advanced Caching Features

### Cache Tagging System

The cache tagging system allows you to group related cache entries and invalidate them efficiently:

```php
use Glueful\Cache\CacheTaggingService;

// Tag cache entries for group invalidation
CacheTaggingService::tagCache('user:profile:123', ['users', 'profiles']);
CacheTaggingService::tagCache('user:permissions:123', ['users', 'permissions']);
CacheTaggingService::tagCache('role:admin', ['roles', 'permissions']);

// Invalidate all user-related cache
CacheTaggingService::invalidateByTag('users');

// Invalidate multiple tags at once
CacheTaggingService::invalidateByTags(['users', 'permissions']);

// Predefined tag categories
CacheTaggingService::invalidateCategory('auth'); // All auth-related cache
CacheTaggingService::invalidateCategory('permissions'); // All permission cache

// Get tag statistics
$stats = CacheTaggingService::getStats();
```

### Query Caching

Automatic database query result caching with table-based invalidation:

```php
use Glueful\Cache\QueryCacheService;
use Glueful\Database\Attributes\CacheResult;

// Repository method caching with attributes
class UserRepository 
{
    #[CacheResult(ttl: 3600, keyPrefix: 'users', tags: ['users', 'profiles'])]
    public function getActiveUsers(): array
    {
        $connection = $this->getConnection();
        return $connection->table('users')
            ->select()
            ->where('status', 'active')
            ->get();
    }
    
    #[CacheResult(ttl: 1800, tags: ['users', 'stats'])]
    public function getUserStatistics(): array
    {
        // Complex query that should be cached
        return $this->performComplexAggregation();
    }
}

// Use cached repository methods
$queryCache = new QueryCacheService();
$users = $queryCache->cacheRepositoryMethod($userRepo, 'getActiveUsers');

// Automatic invalidation when users table is modified
// INSERT, UPDATE, DELETE operations automatically invalidate relevant query cache
```

### Distributed Caching

Multi-node cache distribution with automatic failover:

```php
use Glueful\Cache\DistributedCacheService;

// Configure distributed cache nodes
$distributedCache = new DistributedCacheService([
    'nodes' => [
        ['host' => 'cache1.example.com', 'port' => 6379, 'weight' => 100],
        ['host' => 'cache2.example.com', 'port' => 6379, 'weight' => 100],
        ['host' => 'cache3.example.com', 'port' => 6379, 'weight' => 50],
    ],
    'strategy' => 'consistent_hash',
    'replicas' => 2
]);

// Use distributed cache seamlessly
$distributedCache->set('user:123', $userData, 3600);
$userData = $distributedCache->get('user:123');

// Health monitoring and failover
$healthStatus = $distributedCache->getNodeHealth();
$distributedCache->removeFailedNode('cache2.example.com:6379');
```

### Cache Warmup

Strategic cache warming for improved performance:

```php
use Glueful\Cache\CacheWarmupService;

$warmupService = new CacheWarmupService();

// Warm specific data types
$warmupService->warmupConfiguration();    // App configuration
$warmupService->warmupPermissions();      // User permissions and roles
$warmupService->warmupActiveUsers();      // Recently active users
$warmupService->warmupMetadata();         // System metadata

// Comprehensive warmup
$stats = $warmupService->performFullWarmup();
echo "Warmed {$stats['items']} cache entries in {$stats['duration']}ms";

// Custom warmup strategies
$warmupService->addStrategy('products', function() {
    return $this->productRepo->getFeaturedProducts();
});
```

## Usage Examples

### Basic Cache Operations

The CacheEngine provides a unified interface for all cache operations:

```php
use Glueful\Cache\CacheEngine;

// Get cache store from container
$cache = container()->get(CacheStore::class);

// Store a value in cache (with 1 hour TTL)
$cache->set('user:profile:123', $userProfile, 3600);

// Retrieve a cached value
$profile = $cache->get('user:profile:123');

// Check if a key exists
if ($cache->has('user:profile:123')) {
    // Key exists
}

// Delete a cached item
$cache->delete('user:profile:123');

// Clear all cache
$cache->clear();
```

### Caching Helpers

The framework includes helpful utilities for common caching patterns:

```php
use Glueful\Helpers\Utils;

// Cache the result of an expensive operation
$result = Utils::withCache('expensive:operation:key', function() {
    // This will only run if the cache key doesn't exist
    return performExpensiveOperation();
}, 1800); // 30 minutes TTL
```

### Creating Cache Keys

To ensure consistent cache keys, use the provided helper:

```php
use Glueful\Helpers\Utils;

// Creates a standardized cache key
$key = Utils::cacheKey('users', $userId, 'profile');  // "users:123:profile"
```

### Advanced Cache Helper

The `CacheHelper` class provides advanced cache management with stampede protection and graceful fallbacks:

```php
use Glueful\Helpers\CacheHelper;

// Create cache instance with graceful fallback
$cache = CacheHelper::createCacheInstance(); // Returns null if cache unavailable

// Check if cache is healthy
if (CacheHelper::isCacheHealthy($cache)) {
    // Cache is available and responding
}

// Safely execute cache operations with fallback
$value = CacheHelper::safeExecute($cache, function($cache) {
    return $cache->get('my_key');
}, 'default_value');

// Use stampede protection for expensive operations
$result = CacheHelper::rememberWithStampedeProtection(
    $cache,
    'expensive:calculation',
    function() {
        return performExpensiveCalculation();
    },
    3600,  // TTL
    60,    // Lock TTL
    30     // Max wait time
);

// Generate scoped cache keys
$userKey = CacheHelper::userKey($userId, 'preferences');
$sessionKey = CacheHelper::sessionKey($sessionId, 'data');
$rateLimitKey = CacheHelper::rateLimitKey($ipAddress, 'api');
$permissionKey = CacheHelper::permissionKey($userId, 'roles');
```

## HTTP Caching with Middleware

Glueful includes a `CacheControlMiddleware` for managing HTTP cache headers:

```php
use Glueful\Http\Middleware\CacheControlMiddleware;

// Add the middleware with custom configuration
Router::addMiddleware(new CacheControlMiddleware([
    'public' => true,
    'max_age' => 3600,
    'methods' => [
        'GET' => true,
        'HEAD' => true,
        'POST' => false,
    ],
    'routes' => [
        'GET /users' => ['max_age' => 300],
        'GET /blobs/*' => ['max_age' => 86400], // 1 day
    ],
    'content_types' => [
        'image/*' => ['max_age' => 86400, 'immutable' => true],
        'application/pdf' => ['max_age' => 86400],
    ],
]));
```

## CLI Commands

The Glueful CLI provides commands for managing the cache system:

```bash
# Clear all cached data
php glueful cache:clear

# Clear specific cache tags
php glueful cache:clear --tag=users --tag=permissions

# Force clear without confirmation
php glueful cache:clear --force

# Show cache status and statistics
php glueful cache:status

# Get a cached item by key
php glueful cache:get <key>

# Set a value in cache (with optional TTL)
php glueful cache:set <key> <value> [<ttl>]

# Delete a cached item
php glueful cache:delete <key>

# Expire a cache key (set TTL to 0)
php glueful cache:expire <key>

# Get remaining TTL for a key
php glueful cache:ttl <key>

# Purge cache by pattern
php glueful cache:purge --pattern="user:*"
```

## Edge Caching & CDN Integration

Glueful provides comprehensive edge caching capabilities for CDN integration:

```php
use Glueful\Cache\EdgeCacheService;

$edgeCache = new EdgeCacheService();

// Generate appropriate cache headers for routes
$headers = $edgeCache->generateCacheHeaders('/api/users', 'application/json');
// Returns: ['Cache-Control' => 'public, max-age=300', 'Vary' => 'Authorization']

// Check if content should be cached at edge
$cacheable = $edgeCache->isCacheable($request, $response);

// Purge edge cache
$edgeCache->purgeUrl('https://example.com/api/users');
$edgeCache->purgeByTag('users');
$edgeCache->purgeAll();

// Get edge cache statistics
$stats = $edgeCache->getStats();
```

### CDN Adapter System

Create custom CDN adapters for different providers:

```php
class CloudflareCDNAdapter extends AbstractCDNAdapter
{
    public function purgeUrl(string $url): bool
    {
        return $this->makeApiCall('/zones/{zone}/purge_cache', [
            'files' => [$url]
        ]);
    }
    
    public function purgeByTag(string $tag): bool
    {
        return $this->makeApiCall('/zones/{zone}/purge_cache', [
            'tags' => [$tag]
        ]);
    }
}
```

## Event-Driven Cache Invalidation

Automatic cache invalidation based on application events:

```php
use Glueful\Cache\CacheInvalidationService;

$invalidation = new CacheInvalidationService();

// Register invalidation patterns
$invalidation->addPattern('user.updated', [
    'user:profile:{user_id}',
    'user:permissions:{user_id}',
    'tags:users,profiles'
]);

$invalidation->addPattern('role.permissions.changed', [
    'role:{role_id}',
    'tags:roles,permissions'
]);

// Invalidate based on events
$invalidation->invalidateByEvent('user.updated', ['user_id' => 123]);
$invalidation->invalidateByEvent('role.permissions.changed', ['role_id' => 'admin']);

// Bulk invalidation
$invalidation->invalidateByEvents([
    ['event' => 'user.updated', 'context' => ['user_id' => 123]],
    ['event' => 'user.updated', 'context' => ['user_id' => 456]]
]);
```

## Advanced Pattern Operations

Work with cache patterns for bulk operations:

```php
use Glueful\Cache\CacheStore;

$cache = container()->get(CacheStore::class);

// Pattern-based deletion
$cache->deletePattern('user:*');           // Delete all user cache
$cache->deletePattern('session:token:*');  // Delete all session tokens
$cache->deletePattern('api:response:*');   // Delete all API response cache

// Enumerate keys by pattern
$userKeys = $cache->keys('user:profile:*');
$sessionKeys = $cache->keys('session:*');

// Bulk operations
$userData = $cache->mget(['user:123', 'user:456', 'user:789']);
$cache->mset([
    'user:123' => $user123Data,
    'user:456' => $user456Data
], 3600);

// Redis sorted sets (when using Redis driver)
$cache->zadd('leaderboard', [
    'user:123' => 100,
    'user:456' => 150
]);
$topUsers = $cache->zrange('leaderboard', 0, 9); // Top 10
```

## Best Practices

### Cache Strategy Design

- **Use cache tags extensively** - Group related cache entries for efficient invalidation
- **Implement query caching** - Use `#[CacheResult]` attributes on expensive repository methods
- **Strategic cache warming** - Pre-load critical data during low-traffic periods
- **TTL strategies** - Use appropriate TTLs based on data volatility and business requirements
- **Event-driven invalidation** - Set up automatic cache invalidation based on data changes

### Performance Optimization

- **Monitor hit ratios** - Aim for 80%+ cache hit ratios; analyze and optimize low-performing cache
- **Use distributed caching** - Implement multi-node caching for high-availability applications
- **Pattern-based operations** - Use bulk operations and pattern matching for efficiency
- **Edge caching integration** - Leverage CDN capabilities for static and semi-static content
- **Cache stampede prevention** - Use proper locking mechanisms for high-traffic cache misses

### Security & Data Management

- **Secure serialization** - Framework automatically uses secure serialization for sensitive data
- **Namespace isolation** - Use logical cache key namespaces to prevent conflicts
- **Tag-based permissions** - Use permission-aware cache tags for user-specific data
- **Health monitoring** - Implement cache health checks and failover mechanisms
- **Data lifecycle** - Regularly clean up expired cache and monitor memory usage

### Development & Maintenance

- **Use CLI tools** - Leverage `php glueful cache` commands for development and debugging
- **Test cache behavior** - Include cache testing in your test suites
- **Document cache strategies** - Document cache tags, TTLs, and invalidation patterns
- **Monitor performance** - Use cache statistics to identify optimization opportunities
- **Gradual rollout** - Test new cache strategies in staging before production deployment
