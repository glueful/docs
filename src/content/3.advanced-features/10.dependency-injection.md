Glueful uses **Symfony Dependency Injection Container** under the hood, providing a robust, enterprise-grade DI system with service providers, auto-wiring, and production-optimized compilation.

## Overview

The Glueful DI Container is built on Symfony DI and offers:

- **Symfony Foundation** - Battle-tested, enterprise-grade DI container
- **Service Providers** - Organized service registration with Symfony ContainerBuilder
- **Production Compilation** - Container compilation for optimal performance
- **Auto-wiring Support** - Automatic dependency resolution using Symfony's auto-wiring
- **Container Commands** - CLI tools for debugging and validation
- **Extension Integration** - Seamless extension service registration

## Quick Start

### Basic Container Usage

```php
use Glueful\DI\Container;
use Glueful\DI\ContainerBootstrap;

// Get the global container (recommended)
$container = container();

// Or initialize manually
$container = ContainerBootstrap::initialize();

// Resolve services - uses Symfony's get() method
$userService = $container->get(UserService::class);
$database = $container->get('database');
$cache = $container->get(\Glueful\Cache\CacheStore::class);
```

### Using Services in Controllers

```php
class UserController extends BaseController
{
    public function __construct(
        private UserService $userService,
        private \Glueful\Cache\CacheStore $cache,
        private \Glueful\Database\Connection $db
    ) {}
    
    public function index(): array
    {
        // Services are automatically injected via Symfony auto-wiring
        return $this->userService->getAllUsers();
    }
}
```

## Container Architecture

### Glueful Container Class

```php
// api/DI/Container.php - Wrapper around Symfony DI
class Container implements ContainerInterface
{
    public function __construct(
        private SymfonyContainerInterface $container
    ) {}

    public function get(string $id): mixed
    {
        return $this->container->get($id);
    }

    public function has(string $id): bool
    {
        return $this->container->has($id);
    }
    
    // Access underlying Symfony container
    public function getSymfonyContainer(): SymfonyContainerInterface
    {
        return $this->container;
    }
    
    // Check if container is compiled
    public function isCompiled(): bool
    {
        return !$this->container instanceof ContainerBuilder;
    }
}
```

### Available Container Methods

```php
// Service resolution (PSR-11 compliant)
$service = $container->get(ServiceName::class);
$exists = $container->has(ServiceName::class);

// Parameter access
$parameter = $container->getParameter('app.debug');
$hasParam = $container->hasParameter('app.name');

// Service introspection
$serviceIds = $container->getServiceIds();

// Register service providers
$container->register(new MyServiceProvider());
```

## Service Providers

Service providers organize service registration using **Symfony ContainerBuilder**:

### Creating Service Providers

```php
use Glueful\DI\ServiceProviderInterface;
use Symfony\Component\DependencyInjection\ContainerBuilder;
use Symfony\Component\DependencyInjection\Definition;
use Symfony\Component\DependencyInjection\Reference;

class UserServiceProvider implements ServiceProviderInterface
{
    public function register(ContainerBuilder $container): void
    {
        // Register UserRepository service
        $container->register(UserRepository::class)
            ->setArguments([new Reference('database')])
            ->setPublic(true);

        // Register UserService with dependencies
        $container->register(UserService::class)
            ->setArguments([
                new Reference(UserRepository::class),
                new Reference(\Glueful\Cache\CacheStore::class)
            ])
            ->setPublic(true);

        // Create service alias
        $container->setAlias('user.service', UserService::class)
            ->setPublic(true);
    }

    public function boot(Container $container): void
    {
        // Post-compilation setup (optional)
        $userService = $container->get(UserService::class);
        $userService->initializeDefaults();
    }

    public function getCompilerPasses(): array
    {
        // Return Symfony compiler passes if needed
        return [];
    }

    public function getName(): string
    {
        return 'user';
    }
}
```

### Built-in Service Providers

Glueful includes comprehensive service providers in `/api/DI/ServiceProviders/`:

#### CoreServiceProvider

Registers essential framework services:

```php
public function register(ContainerBuilder $container): void
{
    // Database services
    $container->register('database', \Glueful\Database\Connection::class)
        ->setPublic(true);

    $container->register(\Glueful\Database\QueryBuilder::class)
        ->setFactory([new Reference('database'), 'createQueryBuilder'])
        ->setPublic(true);

    // Cache services  
    $container->register('cache.store', \Glueful\Cache\CacheStore::class)
        ->setFactory([\Glueful\Cache\CacheFactory::class, 'create'])
        ->setPublic(true);

    // Logger service
    $container->register('logger', \Psr\Log\LoggerInterface::class)
        ->setFactory([$this, 'createLogger'])
        ->setPublic(true);
}
```

#### RepositoryServiceProvider

Registers data repositories:

```php
public function register(ContainerBuilder $container): void
{
    // Register all repositories with database dependency
    $repositories = [
        UserRepository::class,
        ProductRepository::class,
        OrderRepository::class,
    ];

    foreach ($repositories as $repository) {
        $container->register($repository)
            ->setArguments([new Reference('database')])
            ->setPublic(true);
    }
}
```

#### SecurityServiceProvider

Registers security-related services:

```php
public function register(ContainerBuilder $container): void
{
    // Token manager
    $container->register(\Glueful\Auth\TokenManager::class)
        ->setPublic(true);

    // Authentication manager
    $container->register(\Glueful\Auth\AuthenticationManager::class)
        ->setArguments([new Reference(\Glueful\Auth\TokenManager::class)])
        ->setPublic(true);

    // Secure serializers
    $container->register('serializer.cache')
        ->setFactory([\Glueful\Security\SecureSerializer::class, 'forCache'])
        ->setPublic(true);
}
```

## Container Bootstrap

The `ContainerBootstrap` handles container initialization and service provider registration:

### Initialization Process

```php
use Glueful\DI\ContainerBootstrap;

// Initialize container with all service providers
$container = ContainerBootstrap::initialize();

// Container automatically registers these providers:
// - CoreServiceProvider (database, cache, logger)
// - ConfigServiceProvider (configuration management) 
// - SecurityServiceProvider (auth, tokens, serialization)
// - RepositoryServiceProvider (data repositories)
// - ExtensionServiceProvider (extension services)
// - QueueServiceProvider (background jobs)
// - ConsoleServiceProvider (CLI commands)
// - And many more...
```

### Environment-Aware Compilation

```php
// Production: Container is compiled for performance
// Development: Container uses ContainerBuilder for debugging

$isProduction = ($_ENV['APP_ENV'] ?? 'production') === 'production' &&
               !($_ENV['APP_DEBUG'] ?? false);

$container = ContainerFactory::create($isProduction);
```

## Service Registration Patterns

### Basic Service Registration

```php
// Register a simple service
$container->register(MyService::class)
    ->setPublic(true);

// Register with constructor arguments
$container->register(UserService::class)
    ->setArguments([
        new Reference(UserRepository::class),
        new Reference('cache.store')
    ])
    ->setPublic(true);
```

### Factory Pattern

```php
// Register service with factory method
$container->register('custom.service')
    ->setFactory([MyServiceFactory::class, 'create'])
    ->setArguments(['%app.config%'])
    ->setPublic(true);

// Factory with dependencies
$container->register(\Glueful\Database\QueryBuilder::class)
    ->setFactory([new Reference('database'), 'createQueryBuilder'])
    ->setPublic(true);
```

### Service Aliases

```php
// Create service aliases for easier access
$container->setAlias('db', 'database')->setPublic(true);
$container->setAlias('cache', \Glueful\Cache\CacheStore::class)->setPublic(true);

// Use aliases
$db = $container->get('db');
$cache = $container->get('cache');
```

### Tagged Services

```php
use Glueful\DI\ServiceTags;

// Tag services for group processing
$container->register('queue.driver.redis')
    ->setClass(RedisQueueDriver::class)
    ->addTag(ServiceTags::QUEUE_DRIVER)
    ->setPublic(true);

$container->register('cache.pool.redis') 
    ->setClass(RedisCachePool::class)
    ->addTag(ServiceTags::CACHE_POOL)
    ->setPublic(true);
```

## Auto-wiring and Dependency Resolution

### Constructor Injection

```php
// Symfony automatically resolves constructor dependencies
class UserService
{
    public function __construct(
        private UserRepository $userRepo,
        private \Glueful\Cache\CacheStore $cache,
        private \Psr\Log\LoggerInterface $logger
    ) {}
}

// No manual wiring needed - Symfony handles it automatically
$userService = $container->get(UserService::class);
```

### Interface Resolution

```php
// Register interface to implementation binding
$container->register(UserRepositoryInterface::class, UserRepository::class)
    ->setArguments([new Reference('database')])
    ->setPublic(true);

// Or use aliases
$container->setAlias(UserRepositoryInterface::class, UserRepository::class)
    ->setPublic(true);
```

## Extension Integration

Extensions register their services through service providers:

### Extension Service Provider

```php
// extensions/MyExtension/src/MyExtensionServiceProvider.php
class MyExtensionServiceProvider implements ServiceProviderInterface
{
    public function register(ContainerBuilder $container): void
    {
        // Register extension services
        $container->register(ExtensionService::class)
            ->setArguments([new Reference('database')])
            ->setPublic(true);

        // Register extension-specific repositories
        $container->register(ExtensionRepository::class)
            ->setArguments([new Reference('database')])
            ->setPublic(true);
    }

    public function boot(Container $container): void
    {
        // Initialize extension after container is built
        $service = $container->get(ExtensionService::class);
        $service->initialize();
    }

    public function getName(): string
    {
        return 'my-extension';
    }

    public function getCompilerPasses(): array
    {
        return [];
    }
}
```

## Performance Optimization

### Container Compilation

In production, the container is compiled for optimal performance:

```php
// Development: Uses ContainerBuilder (slower, more features)
if (env('APP_ENV') !== 'production') {
    $container = new ContainerBuilder();
    // Services can be inspected, modified at runtime
}

// Production: Uses compiled container (faster, optimized)
if (env('APP_ENV') === 'production') {
    $container = new CompiledContainer();
    // Services are pre-resolved, optimized for speed
}
```

### Service Resolution Optimization

```php
// Services marked as public can be resolved directly
$container->register(UserService::class)
    ->setPublic(true);  // Can be resolved with $container->get()

// Private services are only available as dependencies
$container->register(InternalService::class)
    ->setPublic(false); // Only injected, not directly accessible
```

## Best Practices

### Service Design

1. **Use Constructor Injection** - Symfony's auto-wiring works best with constructor injection
2. **Implement Interfaces** - Register interfaces to implementations for flexibility
3. **Keep Services Focused** - Single responsibility principle
4. **Minimize Dependencies** - Avoid services with too many constructor parameters

### Service Provider Organization

```php
// Group related services in dedicated providers
class DatabaseServiceProvider implements ServiceProviderInterface
{
    public function register(ContainerBuilder $container): void
    {
        // Register all database-related services
        $this->registerConnection($container);
        $this->registerQueryBuilder($container);
        $this->registerRepositories($container);
    }
}
```

### Environment Configuration

```php
// Use environment-specific service configuration
public function register(ContainerBuilder $container): void
{
    $driver = env('CACHE_DRIVER', 'redis');
    
    $container->register('cache.driver')
        ->setClass(match($driver) {
            'redis' => RedisCacheDriver::class,
            'memcached' => MemcachedCacheDriver::class,
            'file' => FileCacheDriver::class,
            default => throw new \InvalidArgumentException("Unknown cache driver: $driver")
        })
        ->setPublic(true);
}
```

## Troubleshooting

### Common Issues

**Service not found:**
```bash
# Check if service is registered
php glueful di:container:debug --service=MyService

# List all available services
php glueful di:container:debug --services
```

**Circular dependency:**
```bash
# Validate container for circular dependencies
php glueful di:container:validate

# Symfony will show the circular dependency chain
```

**Auto-wiring fails:**
```php
// Ensure type hints are present and correct
public function __construct(
    private UserRepositoryInterface $userRepo  // Must be registered interface
) {}
```

**Container compilation issues:**
```bash
# Validate before compilation
php glueful di:container:validate

# Compile with debug info
php glueful di:container:compile --debug
```

### Debugging Services

```php
// Check if service exists
if ($container->has(MyService::class)) {
    $service = $container->get(MyService::class);
} else {
    throw new \Exception('Service not registered');
}

// List all service IDs
$serviceIds = $container->getServiceIds();
foreach ($serviceIds as $id) {
    echo "Registered service: $id\n";
}
```
