This section covers comprehensive performance optimization techniques available in Glueful framework applications.

## Overview

Glueful provides enterprise-grade performance optimization capabilities across all application layers:

- **Memory Management** - Real-time monitoring, pooling, and automatic alerting
- **Database Optimization** - Connection pooling, query analysis, and chunked processing
- **Performance Monitoring** - Middleware and tools for comprehensive metrics
- **Query Optimization** - Automatic query analysis and optimization suggestions
- **Memory-Efficient Processing** - Streaming iterators and lazy loading
- **Cache Performance** - Strategic cache warming and optimization
- **API Performance** - Request/response metrics and optimization

## Memory Management

### MemoryManager

Real-time memory monitoring and management with automatic alerting:

```php
use Glueful\Performance\MemoryManager;

$memoryManager = new MemoryManager();

// Monitor memory usage
$usage = $memoryManager->monitor();
/*
Returns: [
    'current' => '45.2MB',
    'peak' => '67.8MB', 
    'limit' => '128MB',
    'percentage' => 35.3,
    'formatted' => '45.2MB / 128MB (35.3%)'
]
*/

// Check memory status
if ($memoryManager->isMemoryWarning()) {
    // Handle memory pressure (80% threshold)
}

if ($memoryManager->isMemoryCritical()) {
    // Handle critical memory usage (90% threshold)
    $memoryManager->forceGarbageCollection();
}

// Configure custom thresholds
$memoryManager->setWarningThreshold(70);  // 70% warning
$memoryManager->setCriticalThreshold(85); // 85% critical
```

### MemoryPool

Object pooling for memory-efficient resource management:

```php
use Glueful\Performance\MemoryPool;

$memoryPool = new MemoryPool(100); // Max 100 objects

// Store and retrieve objects
$memoryPool->store('key', $expensiveObject);
$object = $memoryPool->retrieve('key');

// Check pool status
$stats = $memoryPool->getStats();
/*
Returns: [
    'size' => 45,
    'capacity' => 100,
    'hit_ratio' => 0.85,
    'evictions' => 12
]
*/
```

### Memory Alerting

Multi-channel memory alerting system:

```php
use Glueful\Performance\MemoryAlertingService;

$alerting = new MemoryAlertingService();

// Configure alerting channels
$alerting->addChannel('log', ['level' => 'warning']);
$alerting->addChannel('slack', ['webhook' => 'https://hooks.slack.com/...']);
$alerting->addChannel('email', ['to' => 'admin@example.com']);

// Monitor with context
$alerting->checkMemoryWithContext('user_import', ['batch_size' => 1000]);

// Get alerting statistics
$stats = $alerting->getAlertStats();
```

## Database Optimization

### Connection Pooling

Enterprise-grade database connection pooling with health monitoring:

```php
use Glueful\Database\ConnectionPool;

// Configure connection pool
$pool = new ConnectionPool([
    'min_connections' => 2,
    'max_connections' => 20,
    'max_idle_time' => 300,     // 5 minutes
    'max_lifetime' => 3600,     // 1 hour
    'health_check_interval' => 30
]);

// Get pool statistics
$stats = $pool->getStatistics();
/*
Returns: [
    'total_connections' => 15,
    'active_connections' => 8,
    'idle_connections' => 7,
    'failed_acquisitions' => 2,
    'avg_acquisition_time' => 12.5,
    'health_check_failures' => 0
]
*/

// Monitor pool health
$health = $pool->performHealthCheck();
if (!$health['healthy']) {
    // Handle unhealthy connections
    $pool->recycleFailedConnections();
}
```

### Chunked Database Processing

Memory-efficient processing of large datasets:

```php
use Glueful\Performance\ChunkedDatabaseProcessor;

$processor = new ChunkedDatabaseProcessor($connection, 1000); // 1000 rows per chunk

// Process large table efficiently
$totalProcessed = $processor->processTable(
    'large_transactions',
    function($rows) {
        foreach ($rows as $row) {
            // Process each row
            processTransaction($row);
        }
        return count($rows); // Return number processed
    },
    'id',
    ['status' => 'pending'] // WHERE conditions
);

// Process with SELECT query
$results = $processor->processSelectQuery(
    "SELECT * FROM users WHERE created_at > ? AND status = ?",
    function($rows) {
        // Process user batch
        return bulkProcessUsers($rows);
    },
    ['2024-01-01', 'active'],
    500 // Custom chunk size
);

echo "Processed {$totalProcessed} records efficiently";
```

### Query Optimization

Automatic query analysis and optimization:

```php
use Glueful\Database\QueryOptimizer;
use Glueful\Database\QueryAnalyzer;

$optimizer = new QueryOptimizer($connection);
$analyzer = new QueryAnalyzer($connection);

// Optimize a complex query
$result = $optimizer->optimizeQuery(
    "SELECT users.*, profiles.bio FROM users JOIN profiles ON users.id = profiles.user_id WHERE users.status = 'active'",
    ['active']
);

echo "Original: {$result['original_query']}";
echo "Optimized: {$result['optimized_query']}";
echo "Estimated improvement: {$result['estimated_improvement']['execution_time']}%";

// Analyze query performance
$analysis = $analyzer->analyzeQuery(
    "SELECT * FROM orders WHERE created_at BETWEEN ? AND ?",
    ['2024-01-01', '2024-12-31']
);

// Review suggestions
foreach ($analysis['optimization_suggestions'] as $suggestion) {
    echo "Priority: {$suggestion['priority']}";
    echo "Suggestion: {$suggestion['suggestion']}";
}

// Check index recommendations
foreach ($analysis['index_recommendations'] as $index) {
    echo "CREATE INDEX idx_{$index['table']}_{implode('_', $index['columns'])} ON {$index['table']} (" . implode(', ', $index['columns']) . ");";
}
```

### Query Monitoring


## Memory-Efficient Processing

### Streaming Iterators

Process large datasets without loading everything into memory:

```php
use Glueful\Performance\MemoryEfficientIterators;

// Stream large file processing
$iterator = MemoryEfficientIterators::fileLines('/path/to/large/file.csv');
foreach ($iterator as $lineNumber => $line) {
    $data = str_getcsv($line);
    processRow($data);
    // Only one line in memory at a time
}

// Stream database results
$iterator = MemoryEfficientIterators::databaseResults(
    $connection,
    "SELECT * FROM large_table WHERE status = ?",
    ['active'],
    1000 // Chunk size
);

foreach ($iterator as $row) {
    processRecord($row);
}

// Functional operations with streaming
$processed = MemoryEfficientIterators::map(
    $iterator,
    function($row) {
        return transformData($row);
    }
)->filter(function($row) {
    return $row['valid'] === true;
})->take(1000);

foreach ($processed as $item) {
    handleProcessedItem($item);
}
```

### Lazy Loading

Defer object creation until actually needed:

```php
use Glueful\Performance\LazyContainer;

$container = new LazyContainer();

// Register lazy-loaded services
$container->lazy('expensive_service', function() {
    return new ExpensiveService(); // Only created when accessed
});

$container->lazy('database_connection', function() {
    return new DatabaseConnection();
});

// Objects are only created when first accessed
$service = $container->get('expensive_service');
```


## Caching Strategies

Glueful provides a comprehensive caching system with multiple storage options.

### Cache Configuration

Configure your preferred cache driver in the `.env` file:

```
CACHE_DRIVER=redis
```

The full configuration options are available in `config/cache.php`:

```php
// Default cache driver (redis, memcached, file)
'default' => env('CACHE_DRIVER', 'redis'),

// Global cache prefix for key namespacing
'prefix' => env('CACHE_PREFIX', 'glueful:'),

// Enable file-based fallback if primary cache fails
'fallback_to_file' => env('CACHE_FALLBACK', true),

// Default TTL in seconds (1 hour)
'ttl' => env('CACHE_TTL', 3600),
```

### Available Cache Drivers

| Driver | Description | Best For | Configuration |
|--------|-------------|----------|--------------|
| Redis | High-performance in-memory data store | Production environments, distributed systems | `CACHE_DRIVER=redis` |
| Memcached | Distributed memory caching system | High-traffic web applications | `CACHE_DRIVER=memcached` |
| File | File-based caching | Development or when memory caching isn't available | `CACHE_DRIVER=file` |

### Using the Cache in Code

```php
use Glueful\Cache\CacheEngine;

// Initialize cache engine
CacheEngine::initialize('glueful:', 'redis');

// Store value with TTL
CacheEngine::set('user:profile:123', $userData, 300);

// Retrieve value
$userData = CacheEngine::get('user:profile:123');

// Delete cache entry
CacheEngine::delete('user:profile:123');

// Check if value exists
if (CacheEngine::has('user:profile:123')) {
    // Use cached value
}

// Convenient helper function
use Glueful\Helpers\Utils;

$results = Utils::withCache('expensive-query', function() {
    // Expensive operation that returns a result
    return $expensiveResult;
}, 3600); // Cache for 1 hour
```

### Cache CLI Commands

Manage the cache from the command line:

```bash
# Clear all cached data
php glueful cache clear

# Show cache status
php glueful cache status

# Get/set specific cache values
php glueful cache get user:profile:123
php glueful cache set my-key "my value" 600
php glueful cache delete my-key
```

## API Response Optimization

### HTTP Caching

Glueful includes a `CacheControlMiddleware` to optimize HTTP caching:

```php
use Glueful\Http\Router;
use Glueful\Http\Middleware\CacheControlMiddleware;

// Add cache middleware with custom settings
Router::addMiddleware(new CacheControlMiddleware([
    'public' => true,                     // Public or private cache
    'max_age' => 3600,                    // Default max age in seconds
    'routes' => [                         // Route-specific overrides
        'GET /users' => ['max_age' => 300],
        'GET /blobs/*' => ['max_age' => 86400],
    ],
    'content_types' => [                  // Content-type specific settings
        'image/*' => ['max_age' => 86400, 'immutable' => true],
        'application/pdf' => ['max_age' => 86400],
    ],
]));
```

### Compression

Enable response compression to reduce bandwidth:

```php
use Glueful\Http\Middleware\CompressionMiddleware;

// Add compression middleware globally
Router::addMiddleware(new CompressionMiddleware([
    'level' => 6,               // Compression level (1-9)
    'min_bytes' => 1024,        // Only compress responses larger than this
]));
```

### Rate Limiting

Protect your API from abuse and maintain performance:

```php
use Glueful\Security\RateLimiter;
use Glueful\Http\Middleware\RateLimitMiddleware;

// Apply rate limiting to API routes
Router::group('/api/v1', function() {
    // Routes defined here
}, [new RateLimitMiddleware([
    'limit' => 60,              // 60 requests
    'period' => 60,             // per 60 seconds
    'by' => 'ip'                // by client IP
])]);

// Different limits for authenticated users
Router::group('/api/v1/admin', function() {
    // Admin routes
}, [new RateLimitMiddleware([
    'limit' => 1000,            // 1000 requests
    'period' => 3600,           // per hour
    'by' => 'user'              // by user ID
])]);
```

## Resource Management

### Memory Management

Glueful provides tools for monitoring and optimizing memory usage:

```php
use Glueful\Logging\LogManager;

$logger = LogManager::getLogger();

// Enable memory monitoring
$logger->configure(['enable_memory_monitoring' => true]);

// Get current memory usage
$usage = $logger->getMemoryUsage(true); // true for real size
echo "Current memory usage: $usage";

// Log memory usage at key points
$logger->debug('Before expensive operation', [
    'memory_usage' => $logger->getMemoryUsage()
]);

// Perform expensive operation
// ...

$logger->debug('After expensive operation', [
    'memory_usage' => $logger->getMemoryUsage()
]);

// Clean up resources
$logger->cleanup();
```

### Memory-Related Best Practices

1. **Process large datasets in chunks** - Use database chunking for large result sets
2. **Clean up after large operations** - Unset large variables when done
3. **Monitor memory usage** - Add memory tracking for key operations
4. **Set appropriate PHP memory limits** - Configure `memory_limit` in PHP settings
5. **Optimize image processing** - Scale down images before processing
6. **Use generators for large data** - Yield results instead of returning large arrays

### Batch Processing

```php
$batchProcessor = new BatchProcessor();
```

### Database Statistics Component

The admin dashboard provides database insights through the Database Statistics component:

```typescript
// In dashboardOverview.ts
async fetchDbStats() {
  this.dbStats.loading = true
  
  try {
    // Get list of tables with their sizes
    const response = await api.db.getDBStats()
    const tables = response.data.tables || []

    this.dbStats.totalTables = response.data.total_tables

    // Sort tables by size and get the largest ones
    const largestTables = [...tables].sort((a, b) => b.size - a.size).slice(0, 5)

    this.dbStats.largestTables = largestTables
    this.dbStats.allTables = tables
  } catch (error) {
    // Error handling
  } finally {
    this.dbStats.loading = false
  }
}
```

## Performance Best Practices

1. **Use appropriate caching** - Cache expensive operations, database results, and API responses
2. **Optimize database queries** - Use indexes, limit columns, and avoid N+1 queries
3. **Set up proper HTTP caching** - Configure cache headers for static resources
4. **Monitor and log performance metrics** - Track response times and resource usage
5. **Use batch processing** - Process large datasets in chunks
6. **Configure connection pooling** - Reuse database connections
7. **Implement rate limiting** - Protect your API from abuse
8. **Clean up sessions** - Use the SessionCleaner to remove expired sessions
9. **Optimize front-end assets** - Minify CSS/JS and optimize images
10. **Regular database maintenance** - Perform database optimization routinely
