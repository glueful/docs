Glueful comes with a powerful command-line interface (CLI) that provides tools for application management, development, and maintenance. The CLI makes it easy to perform common tasks without needing to access the web interface.

## Basic Usage

All Glueful CLI commands follow this structure:

```bash
php glueful <command> [options] [arguments]
```

For example:

````bash
# Show all available commands
php glueful help

# Get help for a specific command
php glueful migrate help
`## Automation & Scripting

The help system provides comprehensive documentation for all available commands.

```bash
# List all available commands
php glueful help

# Get detailed help for a specific command
php glueful <command> help
````

## Installation & Setup Commands

Bootstrap your Glueful application and configure the environment.

```bash
# Install Glueful framework (interactive setup wizard)
php glueful install

# Install with skip options
php glueful install --skip-db --skip-keys --skip-admin

# Force overwrite existing configurations
php glueful install --force

# Run without interactive prompts
php glueful install --quiet

# Generate application keys
php glueful key:generate

# Generate JWT key only
php glueful key:generate --jwt

# Force overwrite existing keys
php glueful key:generate --force

# Display generated keys (insecure - for debugging only)
php glueful key:generate --show

# Check system requirements and configuration
php glueful system:check

# Check with detailed information
php glueful system:check --verbose

# Check production readiness
php glueful system:check --production

# Attempt to fix common issues
php glueful system:check --fix

# Configure production environment
php glueful config:production --check

# Get production readiness score (0-100)
php glueful config:production --score

# Apply production fixes
php glueful config:production --fix

# Apply production template to current .env
php glueful config:production --apply-template

# Migrate configuration to specified environment
php glueful config:production --migrate production

# Generate production audit report
php glueful config:production --audit
```

## Creating Custom Commands

You can extend Glueful's CLI functionality by creating your own custom commands.

### 1. Create Command Class

Create a new command class that extends `Glueful\Console\Command`:

```php
<?php

namespace App\Commands;

use Glueful\Console\Command;

class MyCustomCommand extends Command
{
    /**
     * Get Command Name
     */
    public function getName(): string
    {
        return 'my:command';
    }

    /**
     * Get Command Description
     */
    public function getDescription(): string
    {
        return 'Description of my custom command';
    }

    /**
     * Get detailed help text
     */
    public function getHelp(): string
    {
        return <<<HELP
Custom Command Help

Usage:
  php glueful my:command [options] [arguments]

Options:
  --option1    Description of option 1
  --option2    Description of option 2

Examples:
  php glueful my:command
  php glueful my:command --option1=value
HELP;
    }

    /**
     * Execute the command
     */
    public function execute(array $args = []): int
    {
        $this->info('Executing my custom command...');

        // Parse arguments and options
        $options = $this->parseOptions($args);

        // Your command logic here
        try {
            // Implementation
            $this->success('Command completed successfully');
            return Command::SUCCESS;
        } catch (\Exception $e) {
            $this->error('Command failed: ' . $e->getMessage());
            return Command::FAILURE;
        }
    }

    /**
     * Parse command options
     */
    private function parseOptions(array $args): array
    {
        $options = [];
        foreach ($args as $arg) {
            if (strpos($arg, '--') === 0) {
                $parts = explode('=', substr($arg, 2), 2);
                $options[$parts[0]] = $parts[1] ?? true;
            }
        }
        return $options;
    }
}
```

### 2. Register Command

Register your command in the console kernel:

```php
// In your bootstrap file or service provider
use Glueful\Console\Kernel;

$kernel = new Kernel();
$kernel->registerCommand(\App\Commands\MyCustomCommand::class);
```

### 3. Advanced Command Features

```php
class AdvancedCommand extends Command
{
    public function execute(array $args = []): int
    {
        // Input validation
        if (empty($args)) {
            $this->error('Missing required argument');

        }

        return Command::SUCCESS;
    }
}
```

## Command Exit Codes

Glueful follows standard Unix exit codes for command results:

- `Command::SUCCESS (0)` - Command executed successfully
- `Command::FAILURE (1)` - General failure during command execution
- `Command::INVALID (2)` - Invalid command usage or input

Example usage in commands:

```php
public function execute(array $args = []): int
{
    // Validate input
    if (!$this->validateInput($args)) {
        $this->error('Invalid input provided');
        return Command::INVALID;
    }

    try {
        // Execute command logic
        $this->performOperation();
        $this->success('Operation completed');
        return Command::SUCCESS;
    } catch (\Exception $e) {
        $this->error('Operation failed: ' . $e->getMessage());
        return Command::FAILURE;
    }
}
```

## Best Practices

### Command Design

- **Single Responsibility**: Each command should have one clear purpose
- **Descriptive Names**: Use clear, consistent naming (e.g., `namespace:action`)
- **Comprehensive Help**: Provide detailed help text with examples
- **Error Handling**: Always handle exceptions and return appropriate exit codes

### Performance

- **Memory Awareness**: Monitor memory usage with `php glueful memory:monitor`
- **Progress Feedback**: Commands show progress for long-running operations
- **Database Optimization**: Use `query:profile` for performance analysis
- **Cache Management**: Regular cache clearing for optimal performance

### Security

- **Input Validation**: Commands validate and sanitize arguments
- **Safe Defaults**: Destructive operations require explicit confirmation (e.g., `--force`)
- **Key Management**: Secure key generation with `key:generate`
- **Production Checks**: Use `config:production` for production readiness

### Development Workflow

- **Use Help System**: Explore `php glueful help` to discover available functionality
- **Test Commands**: Test commands in development before production use
- **System Validation**: Use `system:check` to verify environment setup
- **Monitor Resources**: Use `memory:monitor` for resource-intensive operations
- **Migration Management**: Use proper migration workflow (create → run → status)

### Production Considerations

- **Backup First**: Always backup data before running destructive commands like `db:reset`
- **Production Checks**: Use `system:check --production` and `config:production` for production readiness
- **Schedule Tasks**: Use `scheduler` for routine maintenance tasks
- **Monitor Performance**: Use profiling tools for database and memory optimization
- **Automate Deployments**: Create deployment scripts for consistent deployments
- **Log Management**: Redirect command output to logs for monitoring
- **Environment-Specific Configs**: Use appropriate flags for different environments

#### Permission Issues

```bash
# Error: Permission denied
# Solution: Check file permissions
chmod +x glueful
chmod -R 755 storage/
chmod -R 755 database/migrations/
```

#### Database Connection Issues

```bash
# Check database status
php glueful db:status

# Verify system configuration
php glueful system:check --verbose

# Test database connection in install
php glueful install --skip-keys --skip-admin
```

#### Migration Issues

```bash
# Check migration status
php glueful migrate status

# Install migration table if missing
php glueful migrate install

# Reset migrations (WARNING: destructive)
php glueful migrate reset --force
php glueful migrate run
```

#### Cache Issues

```bash
# Clear all cache
php glueful cache clear

# Check cache status
php glueful cache status

# Verify cache configuration
php glueful system:check
```

#### Extension Issues

```bash
# List all extensions
php glueful extensions list

# Validate extension structure
php glueful extensions validate <extension-name>

# Check extension information
php glueful extensions info <extension-name>

# Re-enable extension
php glueful extensions disable <extension-name>
php glueful extensions enable <extension-name>
```

### Debug Mode

Enable verbose output for detailed troubleshooting:

```bash
# Most commands support verbose output
php glueful system:check --verbose
php glueful install --verbose
php glueful migrate run --dry-run

# Monitor memory during command execution
php glueful memory:monitor php glueful migrate run

# Monitor with logging
php glueful memory:monitor --log --csv=migration-memory.csv php glueful migrate run
```

### Log Files

Check relevant log files for detailed error information:

```bash
# Application logs (if configured)
tail -f storage/logs/app.log

# System logs
tail -f /var/log/syslog  # Linux
tail -f /var/log/system.log  # macOS

# Web server logs
tail -f /var/log/apache2/error.log  # Apache
tail -f /var/log/nginx/error.log    # Nginx
```

### Environment Issues

```bash
# Check PHP version and extensions
php glueful system:check

# Verify .env configuration
php glueful config:production --check

# Test production readiness
php glueful system:check --production
```

### Getting Help

```bash
# General help
php glueful help

# Command-specific help
php glueful <command> help
php glueful help <command>

# List all available commands
php glueful help | grep "Available commands:" -A 20
```
