Glueful provides a comprehensive enterprise-grade archive system for data retention, compliance, and storage optimization. The system supports automated archiving, compression, encryption, search capabilities, and health monitoring.

## Overview

The Glueful Archive System offers:

- **Automated Data Archiving** - Schedule-based and threshold-based archiving
- **Compression & Encryption** - Multiple algorithms with AES-256-GCM encryption
- **Search Capabilities** - Fast search across compressed archived data
- **Health Monitoring** - Comprehensive integrity and performance monitoring
- **Retention Policies** - Configurable per-table retention and compliance policies
- **CLI Management** - Complete command-line interface for archive operations

## Quick Start

### Basic Archive Operations

```bash
# Archive old data from a table (default: 90 days)
php glueful archive archive audit_logs

# Archive with custom retention period
php glueful archive archive api_metrics 30

# View archive system status
php glueful archive status

# Show detailed archive statistics
php glueful archive summary

# Check archive system health
php glueful archive health
```

### Configuration

Configure archiving settings in `config/archive.php`:

```php
return [
    'storage' => [
        'path' => env('ARCHIVE_STORAGE_PATH', storage_path('archives')),
        'temp_path' => env('ARCHIVE_TEMP_PATH', storage_path('temp/archives')),
        'max_archive_size' => env('ARCHIVE_MAX_SIZE', 100 * 1024 * 1024), // 100MB
        'auto_cleanup' => env('ARCHIVE_AUTO_CLEANUP', true),
    ],
    
    'compression' => [
        'algorithm' => env('ARCHIVE_COMPRESSION', 'gzip'), // gzip, bzip2, none
        'level' => env('ARCHIVE_COMPRESSION_LEVEL', 6),
    ],
    
    'encryption' => [
        'enabled' => env('ARCHIVE_ENCRYPTION', true),
        'algorithm' => 'AES-256-GCM',
        'key' => env('ARCHIVE_ENCRYPTION_KEY'),
    ],
    
    'retention_policies' => [
        'audit_logs' => [
            'archive_after_days' => 90,
            'retention_years' => 7,
            'auto_archive' => true,
        ],
        'api_metrics' => [
            'archive_after_days' => 30,
            'retention_years' => 2,
            'auto_archive' => true,
        ],
        'notifications' => [
            'archive_after_days' => 60,
            'retention_years' => 1,
            'auto_archive' => false,
        ],
    ],
];
```

## Programming Interface

### Archive Service

Use the archive service programmatically:

```php
use Glueful\Services\Archive\ArchiveService;
use Glueful\Services\Archive\DTOs\ArchiveSearchQuery;

$archiveService = container()->get(ArchiveService::class);

// Archive table data
$cutoffDate = new \DateTime('-90 days');
$result = $archiveService->archiveTable('audit_logs', $cutoffDate);

if ($result->isSuccess()) {
    echo "Archived {$result->getRecordCount()} records";
    echo "Archive size: {$result->getCompressedSize()} bytes";
    echo "Compression ratio: {$result->getCompressionRatio()}%";
} else {
    echo "Archive failed: {$result->getError()}";
}
```

### Searching Archives

Search archived data programmatically:

```php
// Create search query
$searchQuery = new ArchiveSearchQuery();
$searchQuery->setUser('john@example.com')
            ->setEndpoint('/api/orders')
            ->setDateRange(
                new \DateTime('2024-01-01'),
                new \DateTime('2024-01-31')
            )
            ->setPage(1)
            ->setLimit(100);

// Execute search
$searchResult = $archiveService->searchArchives($searchQuery);

foreach ($searchResult->getResults() as $record) {
    echo "Found: {$record['endpoint']} at {$record['timestamp']}";
}

// Get search performance metrics
$metrics = $searchResult->getMetrics();
echo "Search took {$metrics['execution_time']}ms";
echo "Searched {$metrics['archives_searched']} archives";
```

### Archive Statistics

Get archive statistics and table information:

```php
// Get overall archive summary
$summary = $archiveService->getArchiveSummary();
echo "Total archives: {$summary->getTotalArchives()}";
echo "Total storage: {$summary->getTotalStorageFormatted()}";
echo "Compression ratio: {$summary->getAverageCompressionRatio()}%";

// Get table-specific statistics
$tableStats = $archiveService->getTableStats('audit_logs');
if ($tableStats) {
    echo "Table: {$tableStats->getTableName()}";
    echo "Records archived: {$tableStats->getArchivedRecords()}";
    echo "Storage used: {$tableStats->getStorageUsed()}";
    echo "Last archived: {$tableStats->getLastArchived()->format('Y-m-d H:i:s')}";
}

// Get tables needing archival
$needingArchival = $archiveService->getTablesNeedingArchival();
foreach ($needingArchival as $table) {
    echo "Table {$table['name']} has {$table['old_records']} records older than {$table['threshold']} days";
}
```

## Archive Health Monitoring

### Health Checks

Monitor archive system integrity and performance:

```php
use Glueful\Services\Archive\ArchiveHealthChecker;

$healthChecker = new ArchiveHealthChecker();

// Run comprehensive health check
$healthResult = $healthChecker->runHealthCheck();

echo "Overall Health: " . ($healthResult->isHealthy() ? 'Healthy' : 'Issues Found');

// Check specific health metrics
$metrics = $healthResult->getMetrics();
echo "Storage Usage: {$metrics['storage_usage_percentage']}%";
echo "Corrupted Archives: {$metrics['corrupted_count']}";
echo "Missing Files: {$metrics['missing_files_count']}";
echo "Failed Archives: {$metrics['failed_archives_count']}";

// Get health recommendations
foreach ($healthResult->getRecommendations() as $recommendation) {
    echo "Recommendation: {$recommendation}";
}
```

### Health Monitoring Features

The health checker monitors:

- **File System Integrity** - Verifies checksums and detects corruption
- **Storage Usage** - Tracks disk space usage with configurable thresholds
- **Missing Files** - Identifies archives with missing physical files
- **Failed Archives** - Monitors failed archive operations
- **Archive Age Distribution** - Analyzes archive creation patterns
- **Performance Metrics** - Tracks archiving performance over time

### Automated Archiving

Set up automated archiving with scheduling:

```php
// In your scheduler or cron job
use Glueful\Services\Archive\ArchiveService;

$archiveService = container()->get(ArchiveService::class);

// Get tables that need archiving
$tablesNeedingArchival = $archiveService->getTablesNeedingArchival();

foreach ($tablesNeedingArchival as $tableInfo) {
    $table = $tableInfo['name'];
    $threshold = $tableInfo['threshold'];
    
    // Archive old data
    $cutoffDate = new \DateTime("-{$threshold} days");
    $result = $archiveService->archiveTable($table, $cutoffDate);
    
    if ($result->isSuccess()) {
        logger()->info("Auto-archived {$table}", [
            'records' => $result->getRecordCount(),
            'size' => $result->getCompressedSize()
        ]);
    } else {
        logger()->error("Auto-archive failed for {$table}", [
            'error' => $result->getError()
        ]);
    }
}
```

## Production Considerations

### Performance Optimization

- **Use compression** to reduce storage costs
- **Enable encryption** for sensitive data compliance
- **Set appropriate thresholds** to balance storage and performance
- **Monitor storage usage** to prevent disk space issues
- **Use chunked processing** for large table archiving

### Monitoring and Alerting

Set up monitoring for archive health:

```php
// Monitor storage usage
$healthChecker = new ArchiveHealthChecker();
$health = $healthChecker->runHealthCheck();

if ($health->getMetrics()['storage_usage_percentage'] > 85) {
    // Alert: High storage usage
    $alertService->send('Archive storage usage exceeds 85%');
}

// Monitor failed archives
if ($health->getMetrics()['failed_archives_count'] > 10) {
    // Alert: Too many failed archives
    $alertService->send('Multiple archive operations failing');
}

// Monitor integrity
if ($health->getMetrics()['corrupted_count'] > 0) {
    // Alert: Data corruption detected
    $alertService->send('Archive data corruption detected');
}
```

## Best Practices

### Archive Strategy

- **Plan retention policies** based on business and compliance requirements
- **Archive regularly** to prevent database bloat
- **Monitor storage costs** and optimize compression settings
- **Test restore procedures** regularly (when restoration is implemented)
- **Document archive procedures** for operational teams

### Data Management

- **Use appropriate compression** for your data types
- **Enable encryption** for sensitive information
- **Set up automated monitoring** for archive health
- **Implement backup strategies** for archive files
- **Regular integrity checks** to detect corruption early

### Performance

- **Archive during low-traffic periods** to minimize impact
- **Use chunked processing** for large datasets
- **Monitor archive performance** and adjust settings as needed
- **Keep search indexes optimized** for fast retrieval
- **Consider archive tiering** for different data types

## Troubleshooting

### Common Issues

**Archive operations failing:**
- Check storage permissions and disk space
- Verify encryption key configuration
- Review archive logs for specific errors
- Run health check: `php glueful archive health`

**Poor search performance:**
- Check search index integrity
- Consider rebuilding search indexes
- Optimize search query filters
- Monitor storage and memory usage

**Storage usage growing rapidly:**
- Review compression settings
- Check retention policies
- Identify large archives for investigation
- Consider adjusting archive thresholds

**Data integrity issues:**
- Run comprehensive health check
- Verify encryption key hasn't changed
- Check file system integrity
- Review backup and recovery procedures

The Glueful Archive System provides enterprise-grade data archiving with comprehensive monitoring, compliance features, and performance optimization capabilities, making it suitable for production environments with strict data retention requirements.
