This section provides a comprehensive overview of Glueful's architecture, including the request lifecycle, core components, and design patterns.

## Framework Philosophy

Glueful is built on several key architectural principles:

### Modern PHP Architecture

- **PHP 8.2+ Features**: Leverages modern PHP features including attributes, union types, and enums
- **PSR Standards**: Follows PSR-15 (HTTP Middleware), PSR-7 (HTTP Messages), and PSR-4 (Autoloading)
- **Type Safety**: Strong typing throughout the codebase for better reliability and IDE support
- **Dependency Injection**: Built-in container for managing dependencies and services

### Modular Design

- **Core Framework**: Minimal, fast core with essential features
- **Extension System**: Powerful plugin architecture for adding functionality
- **Layered Architecture**: Clear separation between presentation, business logic, and data layers
- **Service-Oriented**: Services handle business logic, controllers handle HTTP concerns

## Core Components

### 1. Bootstrap System

The bootstrap system initializes the framework with comprehensive setup:

```php
<?php
// api/bootstrap.php - Actual Implementation

// Load composer autoloader

// Initialize API versioning
$apiVersion = config('app.api_version', 'v1');
\Glueful\Http\Router::setVersion($apiVersion);

// Enable cache tagging and invalidation services
if (\Glueful\Cache\CacheEngine::isEnabled()) {
    \Glueful\Cache\CacheTaggingService::enable();
    \Glueful\Cache\CacheInvalidationService::enable();
    \Glueful\Cache\CacheInvalidationService::warmupPatterns();
}

// Enable development query monitoring
if (env('APP_ENV') === 'development' && env('ENABLE_QUERY_MONITORING', true)) {
    \Glueful\Database\DevelopmentQueryMonitor::enable();
}

// Validate database connection on startup

    \Glueful\Database\ConnectionValidator::validateOnStartup(
        throwOnFailure: env('DB_STARTUP_STRICT', false)
    );
}

// Initialize API Engine
```

### 3. Middleware System

PSR-15 compatible middleware architecture using Symfony components:

```php
<?php
// MiddlewareInterface.php - PSR-15 Compatible Interface

/**
 * PSR-15 Compatible Middleware Interface
 *
 * This interface follows the PSR-15 specification but adapts it to work
 * with Symfony's HttpFoundation components (Request/Response) instead of PSR-7.
 */
interface MiddlewareInterface
{
    /**
     * Process an incoming request
     *
     * @param Request $request The request
     * @param RequestHandlerInterface $handler The handler to process the request
     * @return Response The response
     */
    public function process(Request $request, RequestHandlerInterface $handler): Response;
}

// Router.php - Middleware Integration
class Router
{
    /** @var MiddlewareInterface[] PSR-15 middleware stack */
    private static array $middlewareStack = [];

    /** @var callable[] Legacy middleware functions (for backward compatibility) */
    private static array $legacyMiddlewares = [];

    private static array $protectedRoutes = []; // Routes that require authentication

    /**
     * Add PSR-15 compatible middleware to the stack
     */
    public static function addMiddleware(MiddlewareInterface $middleware): void
    {
        self::$middlewareStack[] = $middleware;
    }

    /**
     * Process request through middleware pipeline
     */
    private function processMiddleware(Request $request): Response
    {
        $dispatcher = new MiddlewareDispatcher(self::$middlewareStack);
        return $dispatcher->handle($request);
    }
}
```

### 4. Router System

Advanced router implementation using Symfony's Routing Component:

```php
<?php
// Router.php - Advanced Router Implementation

/**
 * Advanced Router Implementation using Symfony's Routing Component with PSR-15 Middleware
 *
 * This router provides robust routing capabilities by leveraging Symfony's routing system
 * and PSR-15 compatible middleware architecture.
 *
 * Key features include:
 * - Route registration with method constraints (GET, POST, PUT, DELETE)
 * - Route grouping with shared prefixes
 * - Dynamic parameter extraction from URLs
 * - PSR-15 compatible middleware pipeline
 * - Authentication middleware integration
 * - Request context handling
 */
class Router
{
    private static ?Router $instance = null;
    private static RouteCollection $routes;
    private static RequestContext $context;
    private static UrlMatcher $matcher;

    /** @var MiddlewareInterface[] PSR-15 middleware stack */
    private static array $middlewareStack = [];

    private static array $protectedRoutes = []; // Routes that require authentication
    private static array $currentGroups = [];

    public static function get(string $path, array $handler, ...$options): void
    {
        self::addRoute('GET', $path, $handler, $options);
    }

    public static function post(string $path, array $handler, ...$options): void
    {
        self::addRoute('POST', $path, $handler, $options);
    }

    public static function group(string $prefix, callable $callback, ...$options): void
    {
        self::$currentGroups[] = [
            'prefix' => $prefix,
            'middleware' => $options['middleware'] ?? [],
            'requiresAuth' => $options['requiresAuth'] ?? false,
            'requiresAdminAuth' => $options['requiresAdminAuth'] ?? false,
        ];

        $callback();

        array_pop(self::$currentGroups);
    }

    public function handleRequest(): Response
    {
        $request = Request::createFromGlobals();

        try {
            // Process through middleware pipeline
            return $this->processMiddleware($request);
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }
}
```

### 5. API Initialization and Request Processing

The main API class orchestrates framework initialization and request handling:

```php
<?php
// API.php - Main API Initialization and Request Handler

/**
 * Main API Initialization and Request Handler
 *
 * Core class responsible for bootstrapping the API framework:
 * - Initializes the routing system
 * - Loads extensions and plugins
 * - Handles incoming API requests
 * - Delegates request processing to appropriate controllers
 * - Provides centralized error handling
 */
class API
{
    /** @var LogManager|null Central logger instance */
    private static ?LogManager $logger = null;

    /**
     * Initialize the API Framework
     *
     * Bootstrap sequence for the API:
     * 1. Load API extensions to register custom functionality
     * 2. Load route definitions from route files
     * 3. Set up middleware pipeline
     * 4. Configure dependency containers
     */
    public static function init(): void
    {
        try {
            self::initializeCore();

            // Load extensions
            ExtensionsManager::loadExtensions();

            // Load routes
            RoutesManager::loadRoutes();

            self::getLogger()->info("API initialization completed successfully");
        } catch (\Throwable $e) {
            self::getLogger()->error("API initialization failed", [
                'error' => $e->getMessage(),
                'trace' => $e->getTraceAsString()
            ]);
            throw $e;
        }
    }

    /**
     * Process incoming API requests
     */
    public static function processRequest(): void
    {
        try {
            // Enable CORS for cross-origin requests
            Cors::enableCors();

            // Get router instance and handle request
            $router = Router::getInstance();
            $response = $router->handleRequest();

            // Send response to client
            $response->send();
        } catch (\Throwable $e) {
            self::handleGlobalException($e);
        }
    }
}
```

## Request Lifecycle

### 1. Request Reception

1. **Web Server**: Receives HTTP request
2. **Entry Point**: `index.php` catches the request
3. **Bootstrap**: Framework initialization via `bootstrap.php`
4. **Symfony Request**: HTTP request is converted to Symfony Request format
5. **API Processing**: `API::processRequest()` handles the request lifecycle

### 2. Middleware Processing

```php
┌─────────────────────┐
│ CORS Middleware     │ ← Security headers, preflight handling
├─────────────────────┤
│ Auth Middleware     │ ← JWT validation, user identification
├─────────────────────┤
│ Rate Limit Middle.  │ ← Request throttling, abuse prevention
├─────────────────────┤
│ Logging Middleware  │ ← Request/response logging
├─────────────────────┤
│ Custom Middleware   │ ← Application-specific logic
└─────────────────────┘
```

### 3. Route Resolution

1. **Path Matching**: Router finds matching route pattern
2. **Parameter Extraction**: URL parameters are extracted
3. **Middleware Assignment**: Route-specific middleware is added
4. **Controller Resolution**: Target controller and method are identified

### 4. Controller Execution

Controllers handle HTTP requests with integrated services and validation:

```php
<?php
// AuthController.php - Example Controller Implementation

class AuthController
{
    private EmailVerification $verifier;
    private AuthenticationService $authService;

    public function __construct()
    {
        $this->verifier = new EmailVerification();
        $this->authService = new AuthenticationService();

        // Initialize the authentication system
        AuthBootstrap::initialize();
    }

    /**
     * User login
     *
     * Authenticates user with credentials and returns tokens.
     * Supports different authentication providers.
     */
    public function login()
    {
        // Create request object for IP and user agent information
        $request = SymfonyRequest::createFromGlobals();

        try {
            // 1. Input validation
            $credentials = Request::validate([
                'email' => 'required|email',
                'password' => 'required|min:8'
            ]);

            // 2. Authentication attempt
            $result = $this->authService->authenticate(
                $credentials['email'],
                $credentials['password'],
                $request
            );

            // 3. Audit logging
            AuditLogger::log(AuditEvent::LOGIN_SUCCESS, [
                'user_id' => $result['user']['id'],
                'ip_address' => $request->getClientIp(),
                'user_agent' => $request->headers->get('User-Agent')
            ]);

            // 4. Response formatting
            return Response::ok($result, 'Login successful')->send();
        } catch (\Exception $e) {
            return $this->handleAuthException($e);
        }
    }

    public function logout()
    {
        $request = SymfonyRequest::createFromGlobals();

        try {
            $result = $this->authService->logout($request);
            return Response::ok($result, 'Logout successful')->send();
        } catch (\Exception $e) {
            return Response::error('Logout failed', Response::HTTP_BAD_REQUEST)->send();
        }
    }
}
```

### 5. Response Processing

1. **Response Creation**: Controller returns Response object
2. **Middleware Processing**: Response passes back through middleware stack
3. **Header Setting**: Security headers, CORS headers added
4. **Content Serialization**: JSON encoding, formatting applied
5. **HTTP Response**: Final HTTP response sent to client

### Extension Integration Points

Extensions can hook into the framework at multiple strategic points:

- **Service Registration**: Register custom providers and channels
- **Configuration Management**: Load and merge extension-specific configurations
- **Health Monitoring**: Provide health checks and resource usage metrics
- **Notification Channels**: Integrate with the notification system
- **Environment Validation**: Control extension behavior per environment
- **Dependency Management**: Define and validate extension dependencies

```php
<?php
// EmailNotification Extension - Real Implementation Example

/**
 * Email Notification Extension
 *
 * Demonstrates actual extension integration patterns:
 * - Service registration with notification system
 * - Configuration loading and merging
 * - Health monitoring and validation
 * - Environment-specific behavior
 * - Resource usage tracking
 */
class EmailNotification extends \Glueful\Extensions
{
    private static array $config = [];
    private static ?EmailNotificationProvider $provider = null;
    private static ?LogManager $logger = null;

    /**
     * Initialize extension with comprehensive setup
     */
    public static function initialize(): void
    {
        // Initialize logging for the extension
        self::$logger = new LogManager('email_notification');

        try {
            // Load and merge configuration from multiple sources
            self::loadConfig();

            // Create and initialize the notification provider
            self::$provider = new EmailNotificationProvider(self::$config);
            if (!self::$provider->initialize(self::$config)) {
                throw new \Exception('Failed to initialize email provider');
            }

            self::$logger->info('EmailNotification extension initialized successfully');
        } catch (\Exception $e) {
            self::$logger->error('EmailNotification initialization failed: ' . $e->getMessage());
            throw $e;
        }
    }

    /**
     * Register extension services with the framework
     */
    public static function registerServices($container = null): void
    {
        try {
            if (self::$provider) {
                // Register with the notification channel manager
                $channelManager = new ChannelManager();
                $channelManager->addChannel('email', self::$provider);

                self::$logger->info('Email notification channel registered successfully');
            }
        } catch (\Exception $e) {
            self::$logger->error('Error registering EmailNotification services: ' . $e->getMessage());
        }
    }

    /**
     * Load configuration with multiple source merging
     */
    private static function loadConfig(): void
    {
        // Load default extension configuration
        $defaultConfig = require __DIR__ . '/src/config.php';

        // Load main application mail configuration
        $mailConfig = config('mail') ?? [];

        // Merge with mail config taking precedence
        self::$config = array_merge($defaultConfig, $mailConfig);
    }

    /**
     * Environment-specific extension behavior
     */
    public static function isEnabledForEnvironment(string $environment): bool
    {
        // Conditional enabling based on environment
        if ($environment === 'dev' || $environment === 'testing') {
            return self::$config['allow_emails_in_development'] ?? false;
        }

        // Always enable in staging and production
        return true;
    }

    /**
     * Comprehensive health monitoring
     */
    public static function checkHealth(): array
    {
        $healthy = true;
        $issues = [];
        $metrics = [
            'memory_usage' => memory_get_usage(true),
            'execution_time' => 0,
            'database_queries' => 0,
            'cache_usage' => 0
        ];

        $startTime = microtime(true);

        // Validate configuration
        if (empty(self::$config)) {
            $healthy = false;
            $issues[] = 'Email configuration not loaded';
        }

        // Check provider health
        if (!self::$provider || !self::$provider->isEmailProviderConfigured()) {
            $healthy = false;
            $issues[] = 'Email provider not properly configured';
        }

        // Validate template directory
        $templateDir = self::$config['template_dir'] ?? null;
        if (!$templateDir || !is_dir($templateDir) || !is_readable($templateDir)) {
            $healthy = false;
            $issues[] = 'Email template directory not accessible';
        }

        // Check notification channel registration
        try {
            $channelManager = new ChannelManager();
            if (!$channelManager->hasChannel('email')) {
                $healthy = false;
                $issues[] = 'Email channel not registered with notification system';
            }
        } catch (\Exception $e) {
            $healthy = false;
            $issues[] = 'Error checking notification channels: ' . $e->getMessage();
        }

        $metrics['execution_time'] = microtime(true) - $startTime;

        return [
            'healthy' => $healthy,
            'issues' => $issues,
            'metrics' => $metrics
        ];
    }

    /**
     * Extension metadata for admin interface
     */
    public static function getMetadata(): array
    {
        return [
            'name' => 'Email Notification',
            'description' => 'Provides email notification capabilities using SMTP/PHPMailer',
            'version' => '0.21.0',
            'type' => 'core',
            'requiredBy' => ['NotificationSystem'],
            'author' => 'Glueful Extensions Team',
            'requires' => []
        ];
    }

    /**
     * Resource usage tracking
     */
    public static function getResourceUsage(): array
    {
        $metrics = [
            'memory_used' => memory_get_usage(true),
            'peak_memory' => memory_get_peak_usage(true),
            'emails_sent' => 0, // Would track actual emails sent
            'template_cache_size' => 0,
            'smtp_connections' => 0
        ];

        // Add provider-specific metrics if available
        if (self::$provider) {
            $providerMetrics = self::$provider->getMetrics();
            $metrics = array_merge($metrics, $providerMetrics);
        }

        return $metrics;
    }
}
```

```php
{
    /** @var int Maximum retry attempts for deadlocked transactions */
    protected int $maxRetries = 3;

    /** @var bool Whether to use soft deletes */
    protected bool $softDeletes = true;

    /**
     * Query with purpose annotation for monitoring
     */
    public function withPurpose(string $purpose): self
    {
        $this->queryPurpose = $purpose;
        return $this;
    }

    /**
     * Execute query with automatic deadlock retry
     */
    private function executeWithRetry(callable $query): mixed
    {
        $attempts = 0;

        while ($attempts < $this->maxRetries) {
            try {
                return $query();
            } catch (DeadlockException $e) {
                $attempts++;
                if ($attempts >= $this->maxRetries) {
                    throw $e;
                }

                // Exponential backoff
                usleep(pow(2, $attempts) * 100000);
            }
        }
    }

    /**
     * Development query monitoring
     */
    private function logQueryForDevelopment(string $sql, array $params): void
    {
        if (env('APP_ENV') === 'development' && env('ENABLE_QUERY_MONITORING', true)) {
            DevelopmentQueryMonitor::logQuery($sql, $params, $this->queryPurpose);
        }
    }
}

// BaseRepository.php - Shared Connection Management
abstract class BaseRepository
{
    /** @var Connection|null Shared database connection across all repositories */
    private static ?Connection $sharedConnection = null;

    /** @var QueryBuilder|null Shared query builder across all repositories */
    private static ?QueryBuilder $sharedQueryBuilder = null;

    protected static function getSharedConnection(): Connection
    {
        if (self::$sharedConnection === null) {
            self::$sharedConnection = new Connection();
        }
        return self::$sharedConnection;
    }

    protected static function getSharedQueryBuilder(): QueryBuilder
    {
        if (self::$sharedQueryBuilder === null) {
            self::$sharedQueryBuilder = new QueryBuilder(self::getSharedConnection());
        }
        return self::$sharedQueryBuilder;
    }
}
```

### Repository Pattern with Audit Integration

```php
<?php
// BaseRepository.php - Advanced Repository Pattern

abstract class BaseRepository
{
    /** @var bool Whether this repository handles sensitive data requiring stricter auditing */
    protected bool $containsSensitiveData = false;

    /** @var array Fields that should be considered sensitive and tracked in audit logs */
    protected array $sensitiveFields = [];

    public function create(array $data): array
    {
        try {
            $this->db->beginTransaction();

            // Pre-creation audit
            if ($this->containsSensitiveData) {
                $this->auditLogger->log(AuditEvent::DATA_MODIFICATION, [
                    'action' => 'create',
                    'table' => $this->table,
                    'sensitive_fields' => array_intersect_key($data, array_flip($this->sensitiveFields))
                ]);
            }

            $result = $this->db->insert($this->table, $data);

            $this->db->commit();
            return $result;

        } catch (\Exception $e) {
            $this->db->rollback();
            throw $e;
        }
    }

    public function findBy(string $field, $value, ?array $fields = null): ?array
    {
        $fields = $fields ?? $this->defaultFields;

        // Audit data access for sensitive repositories
        if ($this->containsSensitiveData) {
            $this->auditLogger->log(AuditEvent::DATA_ACCESS, [
                'action' => 'read',
                'table' => $this->table,
                'search_field' => $field,
                'requested_fields' => $fields
            ]);
        }

        return $this->db
            ->withPurpose("Find {$this->table} by {$field}")
            ->select($this->table, $fields)
            ->where([$field => $value])
            ->first();
    }
}
```
