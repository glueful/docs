This section covers controllers in the Glueful framework, focusing on the BaseController foundation and enterprise-grade features.

## BaseController Foundation

All controllers in Glueful should extend the `BaseController` class, which provides enterprise-grade functionality through a sophisticated trait-based architecture.

### Why Use BaseController

The BaseController provides:
- **Built-in Security**: Permission checking, rate limiting, and audit logging
- **Performance Features**: Request-scoped caching, query optimization, and memory management
- **DI Integration**: Seamless dependency injection with the container
- **Enterprise Patterns**: Comprehensive audit trails and monitoring
- **User Context**: Cached user context and authentication state
- **Resource Management**: Database connections and repository factory access

### Basic Controller Structure

```php
<?php
namespace App\Controllers;

use Glueful\Controllers\BaseController;
use Glueful\Http\Response;

class UserController extends BaseController
{
    public function index(): Response
    {
        // Built-in permission checking
        $this->requirePermission('users.read', 'users');
        
        // Built-in rate limiting
        $this->rateLimit('list_users', 60, 60);
        
        // Built-in query caching
        $users = $this->cacheResponse('users_list', function() {
            return $this->repositoryFactory
                ->getRepository('users')
                ->findAll();
        }, 300, ['users']);
        
        return Response::success($users);
    }
    
    public function show(string $id): Response
    {
        // Permission check with context
        $this->requirePermission('users.read', 'users', ['user_id' => $id]);
        
        // Get user with caching
        $user = $this->cacheResponse("user:{$id}", function() use ($id) {
            return $this->repositoryFactory
                ->getRepository('users')
                ->findById($id);
        }, 600);
        
        if (!$user) {
            return Response::notFound('User not found')->send();
        }
        
        return Response::success($user);
    }
}
```

## BaseController Traits

```php

    use AsyncAuditTrait;           // Asynchronous audit logging
    use CachedUserContextTrait;    // Cached user context and permissions
    use AuthorizationTrait;        // Authorization and permission checks
    use RateLimitingTrait;         // Rate limiting functionality
    use ResponseCachingTrait;      // Response and query caching
    use ResourceAuditingTrait;     // Resource-specific audit logging
    
    // Properties and constructor...
}
```

### 1. AuthorizationTrait

Provides comprehensive permission checking and role-based access control:

```php
public function adminOnlyAction(): Response
{
    // Check if user is admin
    $this->requireCachedAdmin();
    
    // Check specific permission
    $this->requirePermission('users.delete', 'users');
    
    // Check permission with context
    $this->requirePermission('posts.edit', 'posts', ['post_id' => $postId]);
    
    // Get current user info

    $userUuid = $this->getCurrentUserUuid();

}
```

### 2. RateLimitingTrait

Implements sophisticated rate limiting with adaptive behavior:

```php
public function apiAction(): Response
{
    // Basic rate limiting (60 requests per 60 seconds)
    $this->rateLimit('api_action', 60, 60);
    
    // Resource-specific rate limiting
    $this->rateLimitResource('users', 'bulk_update', [
        'max_attempts' => 10,
        'window_seconds' => 300,
        'adaptive' => true
    ]);
    
    // Per-user rate limiting
    $this->rateLimit('user_action', 100, 3600, true); // adaptive enabled
    
    return Response::success(['data' => 'Action completed'], 'Action completed');
}
```

### 3. ResponseCachingTrait

Provides multi-layer caching with CDN integration:

```php
public function expensiveOperation(): Response
{
    // Cache response for 300 seconds
    return $this->cacheResponse('expensive_data', function() {
        return $this->performExpensiveCalculation();
    }, 300, ['calculations', 'reports']);
    
    // Cache database query

        return $this->getSensitiveData();
    }, 'data.read');
    
    // CDN/Edge cache response
    return $this->edgeCacheResponse('global_data', function() {
        return $this->getGlobalData();
    }, 3600);
}
```

## Dependency Injection in Controllers

BaseController integrates seamlessly with Glueful's DI container, providing automatic dependency injection:

### BaseController Constructor

```php
<?php
namespace Glueful\Controllers;

use Glueful\Auth\AuthenticationManager;
use Glueful\Repository\RepositoryFactory;
use Glueful\Logging\AuditLogger;
use Glueful\Models\User;
use Glueful\Http\RequestUserContext;
use Symfony\Component\HttpFoundation\Request;

abstract class BaseController
{
    protected AuthenticationManager $authManager;
    protected RepositoryFactory $repositoryFactory;
    protected AuditLogger $auditLogger;
    protected ?User $currentUser = null;
    protected ?string $currentToken = null;
    protected Request $request;
    protected RequestUserContext $userContext;

    public function __construct(
        ?RepositoryFactory $repositoryFactory = null,
        ?AuthenticationManager $authManager = null,
        ?AuditLogger $auditLogger = null,
        ?Request $request = null
    ) {
        // Initialize with DI container or defaults
        $this->authManager = $authManager ?? AuthBootstrap::getManager();
        $this->repositoryFactory = $repositoryFactory ?? new RepositoryFactory();
        $this->auditLogger = $auditLogger ?? AuditLogger::getInstance();
        $this->request = $request ?? app()->get(Request::class);
        
        // Initialize request user context for cached authentication
        $this->userContext = RequestUserContext::getInstance()->initialize();
        $this->currentUser = $this->userContext->getUser();
        $this->currentToken = $this->userContext->getToken();
    }
}
```

## Request Validation

BaseController integrates with Glueful's validation system for comprehensive input validation:

### DTO-Based Validation

```php
use Glueful\Validation\Attributes\{Rules, Sanitize};
use Glueful\Validation\Validator;

class CreateUserDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string', 'min:3', 'max:50'])]
    public string $name;

    #[Sanitize(['trim', 'sanitize_email'])]
    #[Rules(['required', 'email', 'unique:users,email'])]
    public string $email;

    #[Rules(['required', 'string', 'min:8'])]
    public string $password;
}

public function store(): Response
{
    $postData = Request::getPostData();
    
    $dto = new CreateUserDTO();
    $validator = new Validator();
    
    if (!$validator->validateDTO($dto, $postData)) {
        return Response::error(
            'Validation failed',
            Response::HTTP_UNPROCESSABLE_ENTITY,
            Response::ERROR_VALIDATION,
            null,
            $validator->errors()
        );
    }
    
    // DTO now contains sanitized and validated data
    $user = $this->userService->create($dto);
    return Response::success($user, 'User created successfully');
}
```

### Simple Validation

```php
public function update(string $id): Response
{
    $postData = Request::getPostData();
    
    // Basic validation
    $validator = new Validator();
    $isValid = $validator->validate($postData, [
        'name' => 'sometimes|string|max:255',
        'email' => 'sometimes|email|unique:users,email,' . $id,
        'status' => 'sometimes|in:active,inactive'
    ]);
    
    if (!$isValid) {
        return Response::error(
            'Validation failed',
            Response::HTTP_UNPROCESSABLE_ENTITY,
            Response::ERROR_VALIDATION,
            null,
            $validator->errors()
        )->send();
    }
    
    $user = $this->userService->update($id, $validator->validated());
    return Response::success($user);
}
```

## Error Handling

BaseController provides structured error handling with automatic audit logging:

### Exception Handling with Audit

```php
public function riskyOperation(): Response
{
    try {
        // Audit the attempt
        $this->asyncAudit('security', 'risky_operation_attempt', 'medium', [
            'user_id' => $this->getCurrentUserUuid(),
            'operation' => 'data_export'
        ]);
        
        $result = $this->performRiskyOperation();
        
        // Audit success
        $this->asyncAudit('security', 'risky_operation_success', 'low', [
            'result_size' => count($result)
        ]);
        
        return Response::success($result);
        
    } catch (ResourceNotFoundException $e) {
        return Response::notFound($e->getMessage())->send();
        
    } catch (ValidationException $e) {
        return Response::error(
            'Validation failed',
            Response::HTTP_UNPROCESSABLE_ENTITY,
            Response::ERROR_VALIDATION,
            null,
            $e->getErrors()
        )->send();
        
    } catch (AuthorizationException $e) {
        // Audit security violation
        $this->asyncAudit('security', 'authorization_violation', 'high', [
            'attempted_action' => 'risky_operation',
            'user_id' => $this->getCurrentUserUuid(),
            'error' => $e->getMessage()
        ]);
        
        return Response::forbidden($e->getMessage())->send();
        
    } catch (\Exception $e) {
        // Audit system error
        $this->asyncAudit('system', 'operation_failure', 'high', [
            'error' => $e->getMessage(),
            'trace' => $e->getTraceAsString()
        ]);
        
        return Response::error(
            'Operation failed',
            Response::HTTP_INTERNAL_SERVER_ERROR,
            Response::ERROR_SERVER
        )->send();
    }
}
```

## Built-in Controllers

Glueful provides several core controllers that demonstrate BaseController usage:

### AuthController

Handles authentication with comprehensive audit logging:

```php
class AuthController extends BaseController
{
    public function login(): Response
    {
        // Rate limit login attempts
        $this->rateLimit('login_attempt', 5, 300); // 5 attempts per 5 minutes
        
        $credentials = $this->validateCredentials();
        
        try {
            $result = $this->authService->authenticate(
                $credentials['email'],
                $credentials['password']
            );
            
            // Audit successful login
            $this->asyncAudit('security', 'login_success', 'low', [
                'user_id' => $result['user']['uuid'],
                'ip_address' => $this->request->getClientIp()
            ]);
            
            return Response::success($result);
            
        } catch (AuthenticationException $e) {
            // Audit failed login
            $this->asyncAudit('security', 'login_failed', 'medium', [
                'email' => $credentials['email'],
                'ip_address' => $this->request->getClientIp(),
                'reason' => $e->getMessage()
            ]);
            
            return Response::unauthorized($e->getMessage())->send();
        }
    }
}
```

### NotificationsController

Manages notifications with caching and permissions:

```php
class NotificationsController extends BaseController
{
    public function index(): Response
    {
        // Require authentication
        $this->requireCachedAuthentication();
        
        // Rate limit notification fetching
        $this->rateLimit('fetch_notifications', 60, 60);
        
        // Cache user notifications
        $notifications = $this->cacheResponse(
            "user_notifications:{$this->getCurrentUserUuid()}",
            function() {
                return $this->notificationService->getNotifications(
                    $this->getCurrentUser(),
                    true // unread only
                );
            },
            300, // 5 minutes
            ['notifications', 'user_data']
        );
        
        return Response::success($notifications);
    }
    
    public function markAsRead(string $id): Response
    {
        $this->requireCachedAuthentication();
        
        // Check if user owns this notification
        $this->requirePermission('notifications.read', 'notifications', [
            'notification_id' => $id,
            'user_id' => $this->getCurrentUserUuid()
        ]);
        
        $result = $this->notificationService->markAsRead($id);
        
        // Invalidate cache
        $this->invalidateCache([
            'notifications',
            "user_notifications:{$this->getCurrentUserUuid()}"
        ]);
        
        return Response::success($result);
    }
}
```

## Advanced Controller Patterns

### Bulk Operations with Audit

```php
public function bulkUpdate(): Response
{
    // Check bulk operation permission
    $this->requirePermission('users.bulk_update', 'users');
    
    // Rate limit bulk operations
    $this->rateLimitResource('users', 'bulk_update', [
```

### Paginated Responses with Caching

```php
public function list(): Response
{
    $this->requirePermission('users.read', 'users');
    
    $page = (int) ($_GET['page'] ?? 1);
    $perPage = min((int) ($_GET['per_page'] ?? 20), 100);
    $filters = $_GET['filters'] ?? [];
    
    // Cache paginated results
    $cacheKey = "users_page_{$page}_{$perPage}_" . md5(json_encode($filters));
    
    $result = $this->cacheResponse($cacheKey, function() use ($page, $perPage, $filters) {
        return $this->userRepository->paginate($page, $perPage, $filters);
    }, 300, ['users', 'pagination']);
    
    return Response::success($result);
}
```

### File Upload with Security

```php
public function uploadAvatar(): Response
{
    $this->requireCachedAuthentication();
    $this->rateLimit('file_upload', 10, 3600);

    ]);
```

## Best Practices

### 1. Always Extend BaseController

```php
// ✅ Good
class MyController extends BaseController
{
    // Inherits all enterprise features
}

// ❌ Avoid
class MyController
{
    // Missing security, caching, audit features
}
```

### 2. Use Built-in Security Features

```php
public function secureAction(): Response
{
    // ✅ Use built-in permission checking
    $this->requirePermission('resource.action', 'resource');
    
    // ✅ Use built-in rate limiting
    $this->rateLimit('action_name', 60, 60);
    
    // ✅ Use audit logging
    $this->asyncAudit('category', 'action', 'severity', $context);
}
```

### 3. Leverage Caching

```php
public function expensiveData(): Response
{
    // ✅ Cache expensive operations
    return $this->cacheResponse('cache_key', function() {
        return $this->performExpensiveOperation();
    }, 600, ['tags']);
}
```

### 4. Handle Errors Gracefully

```php
public function robustAction(): Response
{
    try {
        $result = $this->performAction();
        return Response::success($result);
    } catch (SpecificException $e) {
        // ✅ Handle specific exceptions
        return Response::error($e->getMessage(), $e->getStatusCode())->send();
    } catch (\Exception $e) {
        // ✅ Audit unexpected errors
        $this->asyncAudit('system', 'error', 'high', [
            'error' => $e->getMessage()
        ]);
        return Response::error('Internal error', 500)->send();
    }
}
```

### 5. Use Dependency Injection

```php
// ✅ Inject dependencies
public function __construct(

) {}

// ✅ Use repository factory for dynamic access
```

## Performance Considerations

- **Request Scoping**: User context and permissions are cached per request
- **Connection Pooling**: Database connections are shared across traits
- **Query Caching**: Use `cacheQuery()` for expensive database operations
- **Response Caching**: Cache complete responses with appropriate TTL
- **CDN Integration**: Use `edgeCacheResponse()` for global content

## Security Features

- **Automatic Audit**: All security events are logged automatically
- **Rate Limiting**: Built-in adaptive rate limiting
- **Permission Context**: Fine-grained permission checking with context
- **Input Validation**: DTO-based validation with sanitization
- **CSRF Protection**: Integrated CSRF token validation
