This section covers data validation in the Glueful framework, focusing on the modern attribute-based validation system.

## Attribute-Based Validation (Primary)

Glueful's modern validation system uses PHP attributes for clean, declarative validation:

```php
use Glueful\Validation\Validator;
use Glueful\Validation\Attributes\{Rules, Sanitize};

class UserRegistrationDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string', 'min:3', 'max:50'])]
    public string $name;

    #[Sanitize(['trim', 'sanitize_email'])]
    #[Rules(['required', 'email'])]
    public string $email;

    #[Rules(['required', 'string', 'min:8'])]
    public string $password;

    #[Sanitize(['intval'])]
    #[Rules(['required', 'int', 'min:18', 'max:99'])]
    public int $age;
}

// Usage
$dto = new UserRegistrationDTO();
$dto->name = ' John Doe ';
$dto->email = ' john@example.com ';
$dto->password = 'securepass123';
$dto->age = '25';

$validator = new Validator();
if ($validator->validate($dto)) {
    // DTO properties are now sanitized and validated
    echo "Validation passed!";
} else {
    print_r($validator->errors());
}
```

## Built-in DTOs

Glueful provides pre-built DTOs for common validation scenarios:

```php
use Glueful\DTOs\{EmailDTO, PasswordDTO, UsernameDTO};

// Email validation DTO
class EmailDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string'])]
    public string $email;
}

// Password validation DTO
class PasswordDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string', 'min:8', 'max:100'])]
    public string $password;
}

// Username validation DTO
class UsernameDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string'])]
    public string $username;

    public function __construct(string $username)
    {
        $this->username = $username;
    }
}

// Usage in controllers
public function store(): Response
{
    $postData = Request::getPostData();
    
    $dto = new EmailDTO();
    $dto->email = $postData['email'] ?? '';
    
    $validator = new Validator();
    if (!$validator->validate($dto)) {
        return Response::error(
            'Validation failed',
            Response::HTTP_UNPROCESSABLE_ENTITY,
            Response::ERROR_VALIDATION,
            null,
            $validator->errors()
        );
    }

    // Process validated data
    return Response::success(['email' => $dto->email]);
}
```

## Available Validation Rules

### Basic Rules

| Rule       | Description                                        | Example                               |
| ---------- | -------------------------------------------------- | ------------------------------------- |
| `required` | Field must be present and not empty                | `'name' => 'required'`                |
| `optional` | Field is optional but will be validated if present | `'bio' => 'optional\|string'`         |
| `nullable` | Field can be null                                  | `'middle_name' => 'nullable\|string'` |
| `filled`   | Field must be present and not empty if present     | `'comment' => 'filled'`               |

### Type Validation

| Rule                | Description                    | Example                 |
| ------------------- | ------------------------------ | ----------------------- |
| `string`            | Must be a string               | `'name' => 'string'`    |
| `integer` or `int`  | Must be an integer             | `'age' => 'integer'`    |
| `numeric`           | Must be numeric (int or float) | `'price' => 'numeric'`  |
| `boolean` or `bool` | Must be boolean                | `'active' => 'boolean'` |
| `array`             | Must be an array               | `'tags' => 'array'`     |
| `json`              | Must be valid JSON             | `'metadata' => 'json'`  |

### String Validation

| Rule            | Description                       | Example                             |
| --------------- | --------------------------------- | ----------------------------------- |
| `min:value`     | Minimum length/value              | `'password' => 'min:8'`             |
| `max:value`     | Maximum length/value              | `'title' => 'max:255'`              |
| `email`         | Must be valid email               | `'email' => 'email'`                |
| `url`           | Must be valid URL                 | `'website' => 'url'`                |
| `alpha`         | Only alphabetic characters        | `'name' => 'alpha'`                 |
| `alpha_num`     | Only alphanumeric characters      | `'username' => 'alpha_num'`         |
| `alpha_dash`    | Alphanumeric, dashes, underscores | `'slug' => 'alpha_dash'`            |
| `regex:pattern` | Must match regex pattern          | `'phone' => 'regex:/^[0-9-+\s]+$/'` |

### Date and Time Validation

| Rule                   | Description                     | Example                                    |
| ---------------------- | ------------------------------- | ------------------------------------------ |
| `date`                 | Must be valid date              | `'birthday' => 'date'`                     |
| `date_format:format`   | Must match date format          | `'created_at' => 'date_format:Y-m-d'`      |
| `before:date`          | Must be before given date       | `'start_date' => 'before:2024-12-31'`      |
| `after:date`           | Must be after given date        | `'end_date' => 'after:2024-01-01'`         |
| `before_or_equal:date` | Must be before or equal to date | `'deadline' => 'before_or_equal:today'`    |
| `after_or_equal:date`  | Must be after or equal to date  | `'publish_date' => 'after_or_equal:today'` |

### Database Validation

| Rule                                   | Description                       | Example                                   |
| -------------------------------------- | --------------------------------- | ----------------------------------------- |
| `unique:table,column`                  | Must be unique in database        | `'email' => 'unique:users,email'`         |
| `exists:table,column`                  | Must exist in database            | `'category_id' => 'exists:categories,id'` |
| `unique:table,column,except,id_column` | Unique except for specific record | `'email' => 'unique:users,email,123,id'`  |

### File Validation

| Rule                                      | Description                   | Example                                     |
| ----------------------------------------- | ----------------------------- | ------------------------------------------- |
| `file`                                    | Must be uploaded file         | `'avatar' => 'file'`                        |
| `image`                                   | Must be image file            | `'photo' => 'image'`                        |
| `mimes:ext1,ext2`                         | Must have specific MIME types | `'document' => 'mimes:pdf,doc,docx'`        |
| `max_file_size:size`                      | Maximum file size in KB       | `'video' => 'max_file_size:10240'`          |
| `dimensions:min_width=100,min_height=100` | Image dimensions              | `'thumbnail' => 'dimensions:min_width=100'` |

### Comparison Rules

| Rule                   | Description                           | Example                                                       |
| ---------------------- | ------------------------------------- | ------------------------------------------------------------- |
| `confirmed`            | Must have matching confirmation field | `'password' => 'confirmed'` (expects `password_confirmation`) |
| `same:field`           | Must be same as another field         | `'password_repeat' => 'same:password'`                        |
| `different:field`      | Must be different from another field  | `'new_password' => 'different:old_password'`                  |
| `in:value1,value2`     | Must be one of given values           | `'status' => 'in:active,inactive,pending'`                    |
| `not_in:value1,value2` | Must not be one of given values       | `'username' => 'not_in:admin,root,system'`                    |

## Custom Validation Rules

### Creating Custom Rules

```php
<?php

use Glueful\Validation\Rule;

class StrongPasswordRule extends Rule
{
    public function passes(string $attribute, $value): bool
    {
        // Password must contain at least:
        // - 8 characters
        // - 1 uppercase letter
        // - 1 lowercase letter
        // - 1 number
        // - 1 special character

        return strlen($value) >= 8 &&
               preg_match('/[A-Z]/', $value) &&
               preg_match('/[a-z]/', $value) &&
               preg_match('/[0-9]/', $value) &&
               preg_match('/[^A-Za-z0-9]/', $value);
    }

    public function message(): string
    {
        return 'The :attribute must contain at least 8 characters with uppercase, lowercase, number, and special character.';
    }
}

// Register and use the custom rule
$validator->addRule('strong_password', new StrongPasswordRule());

$validator->validate($data, [
    'password' => 'required|strong_password'
]);
```

### Closure-Based Rules

```php
<?php

$validator->validate($data, [
    'username' => [
        'required',
        'string',

            }
        }
    ]
]);
```

## Validation Groups

### Group Related Validations

```php
<?php

class UserValidator
{
    public function validateRegistration(array $data): array
    {
        return $this->validate($data, [
            'username' => 'required|string|min:3|max:50|alpha_dash|unique:users',
            'email' => 'required|email|unique:users',
            'password' => 'required|string|min:8|strong_password|confirmed',
            'terms_accepted' => 'required|accepted',
        ]);
    }

    public function validateProfileUpdate(array $data, int $userId): array
    {
        return $this->validate($data, [
            'username' => "sometimes|string|min:3|max:50|alpha_dash|unique:users,username,{$userId}",
            'email' => "sometimes|email|unique:users,email,{$userId}",
            'first_name' => 'sometimes|string|max:100',
            'last_name' => 'sometimes|string|max:100',
            'bio' => 'nullable|string|max:1000',
            'website' => 'nullable|url',
        ]);
    }

    public function validatePasswordChange(array $data): array
    {
        return $this->validate($data, [
            'current_password' => 'required|string',
            'new_password' => 'required|string|min:8|strong_password|confirmed|different:current_password',
        ]);
    }
}
```

### Conditional Complex Validation

```php
<?php

class OrderValidator
{
    public function validateOrder(array $data): array
    {
        $baseRules = [
            'customer_id' => 'required|integer|exists:customers,id',
            'items' => 'required|array|min:1',
            'items.*.product_id' => 'required|integer|exists:products,id',
            'items.*.quantity' => 'required|integer|min:1',
        ];

        // Add shipping rules if physical products
        if ($this->hasPhysicalProducts($data['items'] ?? [])) {
            $baseRules = array_merge($baseRules, [
                'shipping_address' => 'required|array',
                'shipping_address.street' => 'required|string',
                'shipping_address.city' => 'required|string',
                'shipping_address.country' => 'required|string|size:2',
                'shipping_method' => 'required|in:standard,express,overnight',
            ]);
        }

        // Add tax rules for certain countries
        if (in_array($data['shipping_address']['country'] ?? '', ['US', 'CA'])) {
            $baseRules['tax_id'] = 'sometimes|string|tax_id:' . $data['shipping_address']['country'];
        }

        return $this->validate($data, $baseRules);
    }

    private function hasPhysicalProducts(array $items): bool
    {
        foreach ($items as $item) {
            $product = Product::find($item['product_id']);
            if ($product && $product->type === 'physical') {
                return true;
            }
        }
        return false;
    }
}
```

## Performance Optimization

### Validation Caching

```php
<?php

class CachedValidator
{
    private array $ruleCache = [];

    public function validate(array $data, array $rules): array
    {
        $cacheKey = md5(json_encode($rules));

        if (!isset($this->ruleCache[$cacheKey])) {
            $this->ruleCache[$cacheKey] = $this->compileRules($rules);
        }

        return $this->validateWithCompiledRules($data, $this->ruleCache[$cacheKey]);
    }
}
```

### Async Validation for Heavy Operations

```php
<?php

class AsyncValidator
{
    public function validateAsync(array $data, array $rules): Promise
    {
        $lightRules = $this->extractLightRules($rules);
        $heavyRules = $this->extractHeavyRules($rules);

        // Validate light rules immediately
        $lightValidation = $this->validate($data, $lightRules);

        if (!empty($lightValidation['errors'])) {
            return Promise::resolve($lightValidation);
        }

        // Queue heavy validations (database checks, API calls, etc.)
        return $this->queueHeavyValidation($data, $heavyRules);
    }

    private function extractHeavyRules(array $rules): array
    {
        $heavy = [];
        foreach ($rules as $field => $rule) {
            if (str_contains($rule, 'unique:') || str_contains($rule, 'exists:')) {
                $heavy[$field] = $rule;
            }
        }
        return $heavy;
    }
}
```

## Integration with Controllers

### Controller Base Class with Validation

```php
<?php

abstract class Controller
{
    protected function validate(Request $request, array $rules, array $messages = []): array
    {
        $validator = new Validator();

        if (!$validator->validate($request->request->all(), $rules, $messages)) {
            throw new ValidationException($validator->errors());
        }

        return $validator->validated();
    }

    protected function validateDTO(object $dto, array $data): object
    {
        $validator = new Validator();

        if (!$validator->validateDTO($dto, $data)) {
            throw new ValidationException($validator->errors());
        }

        return $dto;
    }
}

// Usage in specific controller
class UserController extends Controller
{
    public function store(Request $request): Response
    {
        $validatedData = $this->validate($request, [
            'name' => 'required|string|max:255',
            'email' => 'required|email|unique:users',
            'password' => 'required|string|min:8|confirmed',
        ]);

        $user = $this->userService->create($validatedData);

        return Response::success(['data' => $user]);
    }
}
```

## Testing Validation

### Unit Testing Custom Rules

```php
<?php

class StrongPasswordRuleTest extends TestCase
{
    public function test_strong_password_rule_passes_with_valid_password()
    {
        $rule = new StrongPasswordRule();

        $this->assertTrue($rule->passes('password', 'StrongP@ss123'));
        $this->assertTrue($rule->passes('password', 'MyC0mpl3x!Pass'));
    }

    public function test_strong_password_rule_fails_with_weak_password()
    {
        $rule = new StrongPasswordRule();

        $this->assertFalse($rule->passes('password', 'password'));
        $this->assertFalse($rule->passes('password', '12345678'));
        $this->assertFalse($rule->passes('password', 'PASSWORD'));
        $this->assertFalse($rule->passes('password', 'Pass123'));  // No special char
    }
}
```

## Best Practices

### 1. Fail Fast

Validate input as early as possible in your request lifecycle.

### 2. Use DTOs for Complex Validation

For complex forms, use Data Transfer Objects with attribute-based validation.

### 3. Group Related Rules

Create validator classes for related operations (registration, profile update, etc.).

### 4. Consistent Error Messages

Use consistent error message formats across your API.

### 5. Performance Considerations

- Cache compiled validation rules
- Use async validation for heavy database operations
- Validate client-side for better UX, but always validate server-side

### 6. Security First

- Always validate and sanitize user input
- Use whitelist validation (define what's allowed, not what's forbidden)
- Validate file uploads carefully
