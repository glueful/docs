This section covers Glueful's advanced routing system with dependency injection, authentication, and enterprise features.

## Modern Routing Implementation

Glueful uses Symfony's routing component with PSR-15 middleware architecture:

```php
use Glueful\Http\Router;
use Symfony\Component\HttpFoundation\Request;

// Routes with dependency injection and closures
Router::post('/auth/login', function (Request $request) use ($container) {
    $authController = $container->get(AuthController::class);
    return $authController->login();
});

// Route grouping with shared functionality  
Router::group('/auth', function () use ($container) {
    Router::post('/login', function (Request $request) use ($container) {
        return $container->get(AuthController::class)->login();
    });
    
    Router::post('/logout', function () use ($container) {
        return $container->get(AuthController::class)->logout();
    });
});

// Features include:
// - PSR-15 compatible middleware pipeline
// - Symfony routing component integration
// - Dynamic parameter extraction
// - OpenAPI documentation generation
// - Authentication middleware integration
```

## Dependency Injection Integration

The router integrates with Glueful's DI container through closure-based routing:

```php
// Get container instance
$container = app();

// Route with DI container access
Router::post('/users', function (Request $request) use ($container) {
    $userController = $container->get(UserController::class);
    return $userController->create();
});

// Controllers are resolved from the DI container
class UserController extends BaseController
{
    public function __construct(
        private UserService $userService,
        private NotificationService $notifications
    ) {
        // BaseController handles DI container integration
    }
    
    public function create(): Response
    {
        // Services are available via DI
        $user = $this->userService->createUser($userData);
        
        // Built-in features from BaseController
        $this->asyncAudit('user', 'created', 'low', ['user_id' => $user->uuid]);
        
        return Response::success($user);
    }
}

## Route Parameters

Routes support dynamic parameters with automatic validation and type conversion:

```php
// Route with parameters (using BaseController)
Router::get('/users/{id}', [UserController::class, 'show'], requiresAuth: true);

class UserController extends BaseController
{
    public function show(string $id): Response
    {
        // Built-in permission checking with context
        $this->requirePermission('users.read', 'users', ['user_id' => $id]);
        
        // Cache user data
        $user = $this->cacheResponse("user:{$id}", function() use ($id) {
            return $this->userRepository->findById($id);
        }, 600);
        
        if (!$user) {
            return Response::notFound('User not found');
        }
        
        return Response::success($user);
    }
}

// Optional parameters with defaults
Router::get('/users/{id?}', [UserController::class, 'showOrList']);

public function showOrList(?string $id = null): Response
{
    if ($id) {
        return $this->show($id);
    }
    
    // List all users with caching and pagination
    return $this->index();
}
```

```php

Router::group('/admin', function() {

    Router::get('/dashboard', [AdminController::class, 'dashboard']);

    Router::get('/users', [AdminController::class, 'listUsers']);

// API v1 routes with rate limiting
Router::group('/api/v1', function() {
    
    // Public endpoints (limited rate limiting)

## Modern Authentication Integration

Built-in authentication with TokenStorageService and comprehensive audit logging:

```php
// Basic authentication (uses TokenStorageService)
Router::get('/profile', [ProfileController::class, 'show'], requiresAuth: true);

// Admin-only routes with audit logging
Router::get('/admin/settings', [AdminController::class, 'settings'], 
    requiresAuth: true, requiresAdminAuth: true);

// Permission-based routes (checked via BaseController)
Router::delete('/users/{id}', [UserController::class, 'delete'], requiresAuth: true);
// BaseController automatically checks 'users.delete' permission

// Multi-layer authentication example
class AdminController extends BaseController
{
    public function deleteUser(string $id): Response
    {
        // Multiple security layers from BaseController:
        
        // 1. Authentication (automatic via requiresAuth: true)
        // 2. Admin check (automatic via requiresAdminAuth: true)  
        // 3. Specific permission check
        $this->requirePermission('users.delete', 'users', ['user_id' => $id]);
        
        // 4. Rate limiting
        $this->rateLimit('delete_user', 5, 3600); // 5 deletions per hour
        
        // 5. Audit logging (automatic)
        $result = $this->auditResourceAction('users', 'delete', function() use ($id) {
            return $this->userService->deleteUser($id);
        });
        
        return Response::success(['message' => 'User deleted successfully']);
    }
}
```

## Request & Response with BaseController

BaseController provides enhanced request/response handling with built-in features:

```php
// Modern approach with BaseController (recommended)
Router::post('/users', [UserController::class, 'create'], requiresAuth: true);

class UserController extends BaseController
{
    public function create(): Response
    {
        // Get and validate request data
        $postData = Request::getPostData();
        
        // Built-in validation with DTO
        $dto = new CreateUserDTO();
        $validator = new Validator();
        
        if (!$validator->validateDTO($dto, $postData)) {
            return Response::error(
                'Validation failed',
                Response::HTTP_UNPROCESSABLE_ENTITY,
                Response::ERROR_VALIDATION,
                null,
                $validator->errors()
            );
        }
        
        // Rate limiting (built-in)
        $this->rateLimit('create_user', 10, 3600);
        
        // Permission checking (built-in)
        $this->requirePermission('users.create', 'users');
        
        // Business logic with audit
        $user = $this->auditResourceAction('users', 'create', function() use ($dto) {
            return $this->userService->create($dto);
        });
        
        // Cache invalidation
        $this->invalidateCache(['users', 'user_lists']);
        
        return Response::success($user);
    }
}

// Simple parameter handling
Router::get('/users/{id}', [UserController::class, 'show'], requiresAuth: true);

public function show(string $id): Response
{
    // Parameters are automatically injected and type-converted
    // Built-in permission checking with context
    $this->requirePermission('users.read', 'users', ['user_id' => $id]);
    
    // Cached response
    $user = $this->cacheResponse("user:{$id}", function() use ($id) {
        return $this->userRepository->findById($id);
    }, 600);
    
    return $user ? Response::success($user) : Response::notFound('User not found');
}
```

## Performance & Caching Integration

Routes automatically benefit from BaseController's caching capabilities:

```php
class ProductController extends BaseController
{
    public function list(): Response
    {
        $this->requirePermission('products.read', 'products');
        
        // Multi-layer caching
        $products = $this->cacheResponse('products_list', function() {
            // Expensive database operation
            return $this->productRepository->findAllWithCategories();
        }, 300, ['products', 'categories']);
        
        // Edge caching for global content
        return $this->edgeCacheResponse('global_products', function() use ($products) {
            return Response::success($products);
        }, 600);
    }
    
    public function show(string $id): Response
    {
        // Permission-aware caching (TTL varies by user permissions)
        $product = $this->cacheByPermission("product:{$id}", function() use ($id) {
            return $this->productRepository->findByIdWithDetails($id);
        }, 'products.read');
        
        return $product ? Response::success($product) : Response::notFound();
    }
}
```

## Error Handling with BaseController

The router and BaseController provide comprehensive error handling:

```php
class UserController extends BaseController
{
    public function show(string $id): Response
    {
        try {
            // Built-in validation and permissions
            $this->requirePermission('users.read', 'users', ['user_id' => $id]);
            
            $user = $this->userRepository->findById($id);
            
            if (!$user) {
                // Structured error response
                return Response::notFound('User not found');
            }
            
            return Response::success($user);
            
        } catch (AuthorizationException $e) {
            // Auto-audit security violations
            $this->asyncAudit('security', 'unauthorized_access', 'high', [
                'attempted_resource' => 'users',
                'resource_id' => $id,
                'user_id' => $this->getCurrentUserUuid()
            ]);
            
            return Response::forbidden($e->getMessage());
            
        } catch (ValidationException $e) {
            return Response::error(
                'Invalid request',
                Response::HTTP_UNPROCESSABLE_ENTITY,
                Response::ERROR_VALIDATION,
                null,
                $e->getErrors()
            );
            
        } catch (\Exception $e) {
            // System error with audit
            $this->asyncAudit('system', 'route_error', 'high', [
                'route' => '/users/{id}',
                'error' => $e->getMessage(),
                'user_id' => $this->getCurrentUserUuid()
            ]);
            
            return Response::error(
                'Internal server error',
                Response::HTTP_INTERNAL_SERVER_ERROR,
                Response::ERROR_SERVER
            );
        }
    }
}
```

## Best Practices

### 1. Use BaseController for All Routes

```php
// ✅ Good - BaseController provides enterprise features
class ApiController extends BaseController
{
    public function index(): Response
    {
        $this->requirePermission('api.access', 'api');
        $this->rateLimit('api_access', 100, 3600);
        return Response::success($this->getData());
    }
}

// ❌ Avoid - Missing security and enterprise features
class PlainController
{
    public function index()
    {
        // Manual permission checking required
        // No built-in rate limiting
        // No automatic audit logging
    }
}
```

### 2. Organize Routes Logically

```php
// ✅ Good - Logical grouping with shared authentication
Router::group('/api/v1', function() {
    Router::group('/admin', function() {
        // Admin routes
    }, requiresAdminAuth: true);
    
    Router::group('/user', function() {
        // User routes
    });
}, requiresAuth: true);
```

### 3. Use Descriptive Route Names

```php
// ✅ Good - Clear, descriptive routes
Router::get('/users/{id}/profile', [UserController::class, 'getProfile']);
Router::put('/users/{id}/settings/notifications', [UserController::class, 'updateNotificationSettings']);

// ❌ Avoid - Vague or unclear routes
Router::get('/u/{id}', [UserController::class, 'get']);
Router::post('/data', [UserController::class, 'handle']);
```

### 4. Implement Proper Error Handling

```php
// ✅ Good - Comprehensive error handling with audit
public function sensitiveAction(): Response
{
    try {
        $this->requirePermission('sensitive.action', 'system');
        $result = $this->performSensitiveAction();
        
        $this->asyncAudit('security', 'sensitive_action_success', 'medium', [
            'action' => 'data_export',
            'result_count' => count($result)
        ]);
        
        return Response::success($result);
        
    } catch (AuthorizationException $e) {
        $this->asyncAudit('security', 'unauthorized_sensitive_action', 'high', [
            'attempted_action' => 'data_export',
            'user_id' => $this->getCurrentUserUuid()
        ]);
        
        return Response::forbidden('Access denied');
    }
}
```
