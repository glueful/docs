This guide covers best practices and patterns for developing high-quality APIs using the Glueful framework.

## API Design Principles

Glueful follows RESTful API design principles with modern enhancements for better developer experience and maintainability.

### RESTful Resource Design

Design your APIs around resources, not actions:

```php
// Good: Resource-oriented URLs
GET    /api/v1/users           // List users
GET    /api/v1/users/123       // Get specific user
POST   /api/v1/users           // Create user
PUT    /api/v1/users/123       // Update user
DELETE /api/v1/users/123       // Delete user

// Avoid: Action-oriented URLs
POST /api/v1/getUser
POST /api/v1/createUser
POST /api/v1/updateUser
```

### HTTP Status Codes

Use appropriate HTTP status codes to communicate the result of operations. Here's an example from the actual `AuthController`:

```php
<?php
use Glueful\Http\Response;
use Glueful\Http\Request;

class AuthController
{
    public function verifyEmail()
    {
        try {
            $postData = Request::getPostData();
            if (!isset($postData['email'])) {
                return Response::error('Email address is required', Response::HTTP_BAD_REQUEST)->send();
            }

            $otp = $this->verifier->generateOTP();
            $result = $this->verifier->sendVerificationEmail($postData['email'], $otp);

            if (!$result['success']) {
                $errorMessage = $result['message'] ?? 'Failed to send verification email';
                $statusCode = isset($result['error_code'])
                    ? Utils::mapErrorCodeToStatusCode($result['error_code'])
                    : Response::HTTP_BAD_REQUEST;

                return Response::error($errorMessage, $statusCode)->send();
            }

            return Response::ok([
                'data' => [
                    'email' => $postData['email'],
                    'expires_in' => EmailVerification::OTP_EXPIRY_MINUTES * 60
                ]
            ], 'Verification code has been sent to your email')->send();
        } catch (\Exception $e) {
            return Response::error(
                'Failed to send verification email: ' . $e->getMessage(),
                Response::HTTP_INTERNAL_SERVER_ERROR
            )->send();
        }
    }

    public function verifyOtp()
    {
        try {
            $postData = Request::getPostData();
            if (!isset($postData['email']) || !isset($postData['otp'])) {
                return Response::error('Email and OTP are required', Response::HTTP_BAD_REQUEST)->send();
            }

            $isValid = $this->verifier->verifyOTP($postData['email'], $postData['otp']);

            if (!$isValid) {
                return Response::error('Invalid or expired OTP', Response::HTTP_BAD_REQUEST)->send();
            }

            return Response::ok([
                'data' => [
                    'email' => $postData['email'],
                    'verified' => true,
                    'verified_at' => date('Y-m-d\TH:i:s\Z')
                ]
            ], 'OTP verified successfully')->send();
        } catch (\Exception $e) {
            return Response::error(
                'Failed to verify OTP: ' . $e->getMessage(),
                Response::HTTP_INTERNAL_SERVER_ERROR
            )->send();
        }
    }
}
```

## Request Validation

Proper input validation is crucial for API security and data integrity. Glueful uses an attribute-based validation system with DTOs.

### DTO-Based Validation (Recommended)

For structured validation, use Data Transfer Objects with attributes:

```php
<?php
use Glueful\Validation\Attributes\{Rules, Sanitize};
use Glueful\Validation\Validator;
use Glueful\Http\Response;

class UserRegistrationDTO
{
    #[Sanitize(['trim', 'strip_tags'])]
    #[Rules(['required', 'string', 'min:3', 'max:50'])]
    public string $name;

    #[Sanitize(['trim', 'sanitize_email'])]
    #[Rules(['required', 'email'])]
    public string $email;

    #[Sanitize(['trim'])]
    #[Rules(['required', 'string', 'min:8'])]
    public string $password;

    #[Sanitize(['intval'])]
    #[Rules(['required', 'int', 'min:18', 'max:99'])]
    public int $age;

    #[Rules(['string', 'in:active,inactive,pending'])]
    public string $status = 'pending';
}

class UserController
{
    public function register()
    {
        try {
            $postData = Request::getPostData();

            // Create and populate DTO
            $dto = new UserRegistrationDTO();
            $dto->name = $postData['name'] ?? '';
            $dto->email = $postData['email'] ?? '';
            $dto->password = $postData['password'] ?? '';
            $dto->age = $postData['age'] ?? 0;
            $dto->status = $postData['status'] ?? 'pending';

            // Validate DTO
            $validator = new Validator();
            if (!$validator->validate($dto)) {
                return Response::error(
                    'Validation failed',
                    Response::HTTP_UNPROCESSABLE_ENTITY,
                    Response::ERROR_VALIDATION,
                    null,
                    $validator->errors()
                )->send();
            }

            // DTO now contains sanitized and validated data
            $user = $this->userRepository->create($dto);
            return Response::created($user, 'User registered successfully')->send();

        } catch (\Exception $e) {
            return Response::error(
                'Registration failed: ' . $e->getMessage(),
                Response::HTTP_INTERNAL_SERVER_ERROR
            )->send();
        }
    }
}
```

### Role-Based Authorization

Using the actual `RoleRepository` implementation:

```php
<?php
use Glueful\Repositories\RoleRepository;
use Glueful\Http\Response;
use Glueful\Helpers\Utils;

class AdminController
{
    private RoleRepository $roleRepository;

    public function __construct()
    {
        $this->roleRepository = new RoleRepository();
    }

    public function dashboard()
    {
        $user = Utils::getCurrentUser();

        if (!$user) {
            return Response::unauthorized('Authentication required')->send();
        }

        // Check if user has admin role
        $userRoles = $this->roleRepository->getUserRoles($user['uuid']);
        $hasAdminRole = collect($userRoles)->contains('name', 'admin');

        if (!$hasAdminRole) {
            return Response::error(
                'Admin access required',
                Response::HTTP_FORBIDDEN,
                Response::ERROR_AUTHORIZATION
            )->send();
        }

        return Response::ok($this->getDashboardData())->send();
    }

    public function createRole()
    {
        try {
            $postData = Request::getPostData();

            if (empty($postData['name'])) {
                return Response::error(
                    'Role name is required',
                    Response::HTTP_BAD_REQUEST
                )->send();
            }

            $roleId = $this->roleRepository->create([
                'name' => $postData['name'],
                'description' => $postData['description'] ?? '',
                'created_at' => date('Y-m-d H:i:s')
            ]);

            return Response::created([
                'role_id' => $roleId,
                'name' => $postData['name']
            ], 'Role created successfully')->send();

        } catch (\Exception $e) {
            return Response::error(
                'Failed to create role: ' . $e->getMessage(),
                Response::HTTP_INTERNAL_SERVER_ERROR
            )->send();
        }
    }
}
```

### Permission-Based Authorization

Using the actual `PermissionRepository` implementation:

```php
<?php
use Glueful\Repositories\PermissionRepository;
use Glueful\Security\PermissionManager;
use Glueful\Helpers\Utils;

class UserManagementController
{
    private PermissionRepository $permissionRepository;

    public function __construct()
    {
        $this->permissionRepository = new PermissionRepository();
    }

    public function delete(string $id)
    {
        $user = Utils::getCurrentUser();

        if (!$user) {
            return Response::unauthorized('Authentication required')->send();
        }

        // Check if user has permission to delete users
        $hasPermission = PermissionManager::can('users', 'delete', $user['uuid']);

        if (!$hasPermission) {
            return Response::error(
                'Insufficient permissions to delete users',
                Response::HTTP_FORBIDDEN,
                Response::ERROR_AUTHORIZATION
            )->send();
        }

        // Proceed with deletion...
        try {
            $success = $this->userRepository->delete($id);

            if (!$success) {
                return Response::notFound('User not found')->send();
            }

            return Response::ok(null, 'User deleted successfully')->send();

        } catch (\Exception $e) {
            return Response::error(
                'Failed to delete user: ' . $e->getMessage(),
                Response::HTTP_INTERNAL_SERVER_ERROR
            )->send();
        }
    }
}
```

### Global Error Handler

The framework includes built-in error handling in the `ExceptionHandler`:

```php
<?php
// From Glueful\Exceptions\ExceptionHandler
class ExceptionHandler
{
    public static function sendJsonResponse(
        string $message,
        int $statusCode = 500,
        ?array $data = null
    ): void {
        $response = [
            'success' => false,
            'status' => $statusCode,
            'message' => $message
        ];

        // Add data only if it's not null
        if ($data !== null) {
            $response['data'] = $data;
        }

        // Set HTTP response code
        http_response_code($statusCode);

        // Set JSON content type
        header('Content-Type: application/json');

        // Output JSON
        echo json_encode($response, JSON_UNESCAPED_SLASHES | JSON_UNESCAPED_UNICODE);

        exit;
    }
}
```

### Structured Error Responses

The `Response` class provides standardized error types:

```php
<?php
// Available error types in Response class
class Response
{
    public const ERROR_VALIDATION = 'VALIDATION_ERROR';
    public const ERROR_AUTHENTICATION = 'AUTHENTICATION_ERROR';
    public const ERROR_AUTHORIZATION = 'AUTHORIZATION_ERROR';
    public const ERROR_NOT_FOUND = 'NOT_FOUND_ERROR';
    public const ERROR_RATE_LIMIT = 'RATE_LIMIT_ERROR';
    public const ERROR_SERVER = 'SERVER_ERROR';
    public const ERROR_SECURITY = 'SECURITY_ERROR';

    public static function error(
        string $message,
        int $statusCode = self::HTTP_BAD_REQUEST,
        ?string $errorType = null,
        ?string $errorCode = null,
        mixed $details = null,
        ?string $requestId = null
    ): self {
        $errorDetails = [
            'type' => $errorType ?? self::getErrorTypeFromStatus($statusCode),
            'code' => $errorCode,
            'details' => $details,
            'timestamp' => date('c'),
            'request_id' => $requestId ?? self::generateRequestId()
        ];

        // Remove null values from error details
        $errorDetails = array_filter($errorDetails, fn($value) => $value !== null);

        return new self(null, $statusCode, $message, false, $errorDetails);
    }
}
```

```php
<?php
// In your bootstrap file or service provider
use Glueful\Exceptions\ExceptionHandler;

ExceptionHandler::register(function(\Throwable $e) {
    // Log the exception
    error_log("API Error: " . $e->getMessage());

    // Return appropriate response based on exception type

        return Response::error(
            $e->getMessage(),
            422,
            'VALIDATION_ERROR',
            null,
            $e->getErrors()
        )->send();

        'Internal server error',
        500
    )->send();
});
```

### Database Query Optimization

```php
class UserRepository
{
    public function getAll(array $filters = [], int $limit = 20, int $offset = 0)
    {
        $query = $this->db->table('users')
            ->select(['uuid', 'username', 'email', 'status', 'created_at']) // Only select needed columns
            ->where('deleted_at', 'IS', null); // Filter out soft-deleted records

        // Apply filters efficiently
        if (isset($filters['status'])) {
            $query->where('status', '=', $filters['status']);
        }

        if (isset($filters['search'])) {
            $query->whereGroup(function($q) use ($filters) {
                $q->where('username', 'LIKE', "%{$filters['search']}%")
                  ->orWhere('email', 'LIKE', "%{$filters['search']}%");
            });
        }

        return $query->limit($limit)
            ->offset($offset)
            ->orderBy('created_at', 'DESC')
            ->get();
    }
}
```

```php
class UserController

        $data = Request::getPostData();

        $data = $this->sanitizeInput($data);

            return $value;
```

```php
        'allowed_headers' => ['Content-Type', 'Authorization', 'X-API-Version'],
        'expose_headers' => ['X-API-Version', 'X-Rate-Limit-Remaining'],
        'max_age' => 86400,
        'supports_credentials' => true
    ]
];
```

#### Factory Methods for Common Scenarios

```php
use Glueful\Http\Cors;

$cors->handle();

$cors->handle();
```

### API Key Management

```php
<?php
use Glueful\Helpers\Utils;

class ApiKeyController
{
    public function generateKey()
    {
```

### Performance Monitoring

```php
class PerformanceMiddleware implements MiddlewareInterface
{
    public function process(Request $request, RequestHandlerInterface $handler): Response
    {
        $startTime = microtime(true);
        $startMemory = memory_get_usage();

        $response = $handler->handle($request);

        $executionTime = microtime(true) - $startTime;
        $memoryUsage = memory_get_usage() - $startMemory;

        // Log performance metrics
        Log::info('API Performance', [
            'route' => $request->getPathInfo(),
            'method' => $request->getMethod(),
            'execution_time' => $executionTime,
            'memory_usage' => $memoryUsage,
            'status_code' => $response->getStatusCode()
        ]);

        return $response;
    }
}
```

## Best Practices Summary

1. **Design RESTful APIs** - Use resource-oriented URLs and appropriate HTTP methods
2. **Implement proper versioning** - Support multiple API versions for backward compatibility
3. **Validate all input** - Use comprehensive validation rules and sanitization
4. **Handle errors consistently** - Provide meaningful error messages and proper status codes
5. **Secure your endpoints** - Implement authentication, authorization, and rate limiting
6. **Document your API** - Use OpenAPI/Swagger for comprehensive documentation
7. **Optimize for performance** - Implement caching, compression, and efficient queries
8. **Test thoroughly** - Write unit and integration tests for all endpoints
9. **Monitor and log** - Track API usage, performance, and errors
10. **Follow security best practices** - Sanitize input, configure CORS, and manage API keys securely
