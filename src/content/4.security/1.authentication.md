Glueful provides a comprehensive, flexible authentication system with multiple authentication strategies and robust security features.

## Architecture Overview

Glueful's authentication system is built on a provider-based architecture that supports multiple authentication methods:

- **JWT Token Authentication** (default)
- **API Key Authentication**
- **Admin Authentication** 
- **LDAP Authentication** (enterprise)
- **SAML Authentication** (enterprise)
- **Social Login Authentication** (with extension)

The system uses a clean, object-oriented design with these key components:

- `AuthenticationManager`: Central coordinator that manages multiple authentication providers
- `AuthenticationProviderInterface`: Common interface for all authentication strategies
- `TokenStorageService`: Dual-layer session storage (database + cache) with analytics
- `JWTService`: Secure JWT token generation, validation and lifecycle management
- `AuthFailureTracker`: Failed authentication attempt tracking and blocking
- `EmailVerification`: Email verification system with OTP support
- `PasswordHasher`: Secure password hashing using modern algorithms

## JWT Authentication

Glueful uses JSON Web Tokens (JWT) for secure, stateless authentication:

```php
<?php

// Login endpoint implementation
public function login()
{
    try {
        // Get credentials from request
        $credentials = Request::getPostData();
        
        // Authenticate user
        $userData = $this->authService->authenticate($credentials);
        
        if (!$userData) {
            return Response::unauthorized(['message' => 'Invalid credentials'])->send();
        }
        
        // Generate token pair
        $tokens = $this->authService->generateTokens($userData);
        
        return Response::ok([
            'tokens' => $tokens,
            'user' => $userData
        ], 'Login successful')->send();
    } catch (\Exception $e) {
        return Response::error(
            'Authentication failed: ' . $e->getMessage(),
            Response::HTTP_INTERNAL_SERVER_ERROR
        )->send();
    }
}
```

### Token Management

Glueful implements a secure token pair system:

- **Access Token**: Short-lived (15 minutes by default) for API authorization
- **Refresh Token**: Long-lived (7 days by default) for obtaining new access tokens

Token features:

- **Token fingerprinting** for enhanced security
- **Automatic token refresh** mechanism
- **Token revocation** capabilities with blacklisting
- **Configurable expiration** times
- **Dual-layer storage** (database + cache) for performance
- **Session analytics** and security monitoring
- **Cleanup mechanisms** for expired sessions

```php
// Refresh tokens
Router::post('/auth/refresh-token', function() use ($authController) {
    return $authController->refreshToken();
});

// Validate token
Router::post('/auth/validate-token', function() use ($authController) {
    return $authController->validateToken();
});

// Revoke current session
Router::post('/auth/logout', function() use ($authController) {
    return $authController->logout();
});

// Revoke all user sessions
Router::post('/auth/logout-all', function() use ($authController) {
    return $authController->logoutAll();
});
```

## Protected Routes

Secure routes with authentication middleware:

```php
// Route with standard authentication
Router::get('/profile', [ProfileController::class, 'show'], requiresAuth: true);

// Admin-only route
Router::get('/admin/dashboard', [AdminController::class, 'dashboard'], requiresAuth: true, requiresAdminAuth: true);

// Using middleware directly with specific providers
Router::get('/settings', [SettingsController::class, 'index'])
    ->middleware(new AuthenticationMiddleware(
        false,
        AuthBootstrap::getManager(),
        ['jwt', 'api_key']
    ));
```

## API Key Authentication

Glueful supports API key authentication for service-to-service communication:

```php
// Generate API key
$apiKey = $this->userRepository->generateApiKey($userUuid);

// Use API key in requests
$headers = [
    'X-API-Key: ' . $apiKey
];
```

API keys can be used across all routes that support authentication, providing an alternative to JWT tokens for automated services.

## Role-Based Access Control

Glueful includes a comprehensive RBAC system:

```php
// Check user roles and permissions
if (!$this->authService->hasPermission($user, 'manage_users')) {
    return Response::forbidden(['message' => 'Insufficient permissions']);
}

// Assign roles to users
$this->roleRepository->assignRoleToUser($user['uuid'], 'admin');

// Create new roles and permissions
$roleId = $this->roleRepository->createRole([
    'name' => 'editor',
    'description' => 'Content editor role'
]);
$this->permissionRepository->addPermissionToRole($roleId, 'edit_content');
```

## Email Verification

Glueful provides a comprehensive email verification system with OTP (One-Time Password) support:

```php
use Glueful\Security\EmailVerification;
use Glueful\Security\OTP;

// Initialize email verification service
$emailVerification = container()->get(EmailVerification::class);

// Send verification email with OTP code
Router::post('/auth/verify-email', function() use ($emailVerification) {
    $request = Request::createFromGlobals();
    $email = $request->request->get('email');
    
    $result = $emailVerification->sendVerificationEmail($email);
    
    if ($result['success']) {
        return Response::ok([
            'message' => 'Verification email sent',
            'expires_in' => $result['expires_in']
        ]);
    }
    
    return Response::error($result['message'], 400);
});

// Verify the OTP code
Router::post('/auth/verify-otp', function() use ($emailVerification) {
    $request = Request::createFromGlobals();
    $email = $request->request->get('email');
    $otp = $request->request->get('otp');
    
    $result = $emailVerification->verifyOTP($email, $otp);
    
    if ($result['success']) {
        return Response::ok(['message' => 'Email verified successfully']);
    }
    
    return Response::error($result['message'], 400);
});

// Password reset with OTP
Router::post('/auth/reset-password', function() use ($emailVerification) {
    $request = Request::createFromGlobals();
    $email = $request->request->get('email');
    
    $result = $emailVerification->sendPasswordResetEmail($email);
    
    return Response::ok(['message' => 'Reset email sent if account exists']);
});
```

### OTP System Features

The verification system includes:
- **Configurable OTP length** (4-8 digits) and expiration (5-30 minutes)
- **Rate limiting** to prevent abuse (max 3 attempts per hour)
- **Secure storage** of hashed verification codes
- **Multiple OTP types**: Numeric, alphanumeric, custom character sets
- **Integration** with notification system for multiple delivery channels

```php
// Generate custom OTP
$otp = OTP::generateNumeric(6); // 6-digit numeric OTP
$alphanumeric = OTP::generateAlphanumeric(8); // 8-character alphanumeric

// Verify OTP with expiration
$isValid = OTP::verifyOTP($userOtp, $storedHash, $expirationTime);
```

## Advanced Security Features

### Session Management with TokenStorageService

Glueful uses a sophisticated dual-layer session storage system:

```php
use Glueful\Auth\TokenStorageService;

// Store session with comprehensive metadata
$tokenStorage = container()->get(TokenStorageService::class);

$sessionData = [
    'uuid' => $userUuid,
    'username' => $username,
    'email' => $email,
    'roles' => $userRoles
];

$tokens = [
    'access_token' => $accessToken,
    'refresh_token' => $refreshToken
];

$success = $tokenStorage->storeSession($sessionData, $tokens);

// Query active sessions
$activeSessions = $tokenStorage->queryBuilder()
    ->where(['user_uuid' => $userUuid, 'is_active' => true])
    ->orderBy(['created_at' => 'DESC'])
    ->get();

// Session analytics
$analytics = $tokenStorage->getSessionAnalytics($userUuid);
// Returns: total_sessions, active_sessions, login_frequency, security_events

// Cleanup expired sessions
$cleanedCount = $tokenStorage->cleanupExpiredSessions();
```

### Authentication Failure Tracking

Protect against brute force attacks with automatic blocking:

```php
use Glueful\Security\AuthFailureTracker;

// Track failures by IP or user
$ipTracker = new AuthFailureTracker($clientIp, 5, 900); // 5 attempts, 15 min block
$userTracker = new AuthFailureTracker($userUuid, 3, 1800); // 3 attempts, 30 min block

// Before authentication attempt
if ($ipTracker->isBlocked() || $userTracker->isBlocked()) {
    return Response::error('Too many failed attempts', 429, [
        'retry_after' => max($ipTracker->getRetryAfter(), $userTracker->getRetryAfter())
    ]);
}

// After failed authentication
if (!$authResult) {
    $ipTracker->recordFailure();
    $userTracker->recordFailure();
    
    return Response::unauthorized([
        'message' => 'Invalid credentials',
        'attempts_remaining' => 5 - $ipTracker->getFailures()
    ]);
}

// After successful authentication
$ipTracker->resetFailures();
$userTracker->resetFailures();
```

### Security Features Summary

- **Dual-Layer Session Storage**: Database + cache for performance and reliability
- **Session Analytics**: Track login patterns, detect anomalies
- **Brute Force Protection**: IP and user-based failure tracking with automatic blocking
- **Token Fingerprinting**: Bind tokens to user context (IP, User-Agent)
- **Audit Logging**: Comprehensive authentication event tracking
- **Secure Password Handling**: Modern hashing algorithms with configurable work factors
- **CSRF Protection**: Built-in protection for state-changing requests
- **Email Verification**: OTP-based email verification with rate limiting
- **Session Management**: Active session monitoring, remote termination
- **Token Lifecycle**: Automatic cleanup, revocation, and refresh mechanisms

## Configuration

Configure authentication in your `.env` file:

```env
# JWT Configuration
ACCESS_TOKEN_LIFETIME=900      # Access token lifetime in seconds (15 minutes)
REFRESH_TOKEN_LIFETIME=604800  # Refresh token lifetime in seconds (7 days)
SESSION_LIFETIME=86400         # Session lifetime in seconds (24 hours)
REMEMBER_ME_LIFETIME=2592000   # Remember me lifetime in seconds (30 days)
JWT_KEY=your-secure-jwt-key    # Secret key for JWT signing

# Authentication Security
AUTH_GUARD_ENABLED=true        # Enable authentication guards
AUTH_MAX_ATTEMPTS=5            # Max failed attempts before blocking
AUTH_BLOCK_DURATION=900        # Block duration in seconds after max attempts
AUTH_FAILURE_TRACKING=true     # Enable failure tracking

# Email Verification
EMAIL_VERIFICATION_ENABLED=true    # Enable email verification
OTP_LENGTH=6                        # OTP code length (4-8 digits)
OTP_EXPIRATION=300                  # OTP expiration in seconds (5 minutes)
OTP_MAX_ATTEMPTS=3                  # Max OTP verification attempts

# Session Configuration
SESSION_USE_CACHE=true              # Use cache for session storage
SESSION_CACHE_TTL=3600              # Session cache TTL in seconds
SESSION_CLEANUP_INTERVAL=86400      # Cleanup interval for expired sessions
SESSION_ANALYTICS_ENABLED=true     # Enable session analytics

# Token Security
TOKEN_FINGERPRINTING=true          # Enable token fingerprinting
TOKEN_BLACKLIST_ENABLED=true       # Enable token blacklisting
```

For more advanced configuration, see the [Security Configuration](/security/configuration) guide.
