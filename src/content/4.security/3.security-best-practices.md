This guide provides comprehensive security recommendations for building and maintaining secure Glueful applications, including emergency procedures, monitoring, and production security validation.

## Authentication Security

### Password Policies
- Enforce strong password requirements (minimum length, complexity)
- Implement account lockout after multiple failed attempts
- Use secure password hashing with bcrypt or Argon2
- Require periodic password changes for sensitive applications

### Multi-factor Authentication
- Enable MFA for administrative and privileged accounts
- Support multiple MFA methods (SMS, authenticator apps, hardware tokens)
- Require MFA for sensitive operations even after initial authentication

### Session Management
- Set appropriate session timeouts (shorter for privileged sessions)
- Implement secure session storage and rotation
- Add "Remember Me" functionality with enhanced security checks
- Provide session listing and remote termination for users

```php
// Example: Configure session security in your Glueful application
$sessionConfig = [
    'lifetime' => 120,           // Minutes until session expiration
    'regenerate' => true,        // Regenerate session ID periodically
    'secure' => true,            // HTTPS-only cookies
    'same_site' => 'strict',     // Restrict cross-site requests
];
```

## Authorization Implementation

### Principle of Least Privilege
- Assign users the minimum permissions required for their role
- Regularly audit and review permission assignments
- Implement time-based or temporary elevated permissions

### Role-Based Access Control
- Use Glueful's built-in RBAC system
- Create specific roles rather than assigning individual permissions
- Document all roles and their associated permissions
- Implement role hierarchies for easier management

```php
// Example: Implementing the principle of least privilege
$roleRepo = new RoleRepository();

// Create a focused role with limited permissions
$roleId = $roleRepo->createRole([
    'name' => 'report_viewer',
    'description' => 'Can only view reports'
]);

// Assign only the necessary permissions
$permissionRepo = new PermissionRepository();
$permissionRepo->assignRolePermission(
    $roleId,
    'reports',
    ['A']  // VIEW permission only
);
```

### Permission Auditing
- Implement logging for permission changes
- Conduct regular permission reviews
- Use Glueful's debug mode for permission troubleshooting

```php
// Example: Debug permission issues
$debug = $permissionRepo->hasPermissionDebug(
    $userUuid,
    'sensitive_data',
    'B'
);

// Log permission check results
LogService::log('permission_check', $debug);
```

### Rate Limiting
- Implement rate limiting for all API endpoints
- Use graduated rate limits based on endpoint sensitivity  
- Add proper rate limit headers in responses
- Log and alert on rate limit violations

#### Advanced Rate Limiting with Adaptive Features

```php
use Glueful\Security\{RateLimiter, AdaptiveRateLimiter, RateLimiterRule};

// Basic rate limiting
$basicLimiter = RateLimiter::perIp(
    $request->ip(),
    maxAttempts: 100,
    windowSeconds: 3600
);

if (!$basicLimiter->attempt()) {
    return Response::error('Rate limit exceeded', 429, [
        'retry_after' => $basicLimiter->getRetryAfter(),
        'remaining' => $basicLimiter->remaining()
    ]);
}

// Adaptive rate limiting with behavioral analysis
$adaptiveLimiter = new AdaptiveRateLimiter(
    "api_endpoint:{$endpoint}:{$userUuid}",
    maxAttempts: 50,
    windowSeconds: 3600,
    context: [
        'user_uuid' => $userUuid,
        'endpoint' => $endpoint,
        'ip_address' => $request->ip(),
        'user_agent' => $request->headers->get('User-Agent')
    ],
    enableDistributed: true
);

// Add dynamic rules based on behavior
$suspiciousActivityRule = new RateLimiterRule(
    'suspicious_activity',
    maxAttempts: 10,        // Reduce limit for suspicious users
    windowSeconds: 3600,
    threshold: 0.7          // Activate when behavior score > 0.7
);
$adaptiveLimiter->addRule($suspiciousActivityRule);

if (!$adaptiveLimiter->attempt()) {
    $behaviorScore = $adaptiveLimiter->getBehaviorScore();
    
    return Response::error('Rate limit exceeded', 429, [
        'retry_after' => $adaptiveLimiter->getRetryAfter(),
        'remaining' => $adaptiveLimiter->remaining(),
        'behavior_score' => $behaviorScore,
        'message' => $behaviorScore > 0.5 
            ? 'Suspicious activity detected' 
            : 'Rate limit exceeded'
    ]);
}
```


### Emergency Security Procedures

#### Lockdown Mode

Implement emergency lockdown capabilities for security incidents:

```php
use Glueful\Security\SecurityManager;

// Enable emergency lockdown
php glueful security:lockdown --reason="Security incident detected" --level=high

// Check lockdown status
$lockdownStatus = SecurityManager::getLockdownStatus();
if ($lockdownStatus['enabled']) {
    // Restrict access based on lockdown level
    $allowedOperations = $lockdownStatus['allowed_operations'];
    
    if (!in_array($currentOperation, $allowedOperations)) {
        return Response::error('System in lockdown mode', 503, [
            'reason' => $lockdownStatus['reason'],
            'estimated_duration' => $lockdownStatus['estimated_duration']
        ]);
    }
}

// Disable lockdown after incident resolution
php glueful security:lockdown-disable --confirm
```

#### Incident Response Procedures

```php
class SecurityIncidentHandler
{
    public function handleSecurityIncident(string $incidentType, array $details): void
    {
        // Log the incident
        AuditLogger::log('security_incident', [
            'type' => $incidentType,
            'details' => $details,
            'severity' => $this->calculateSeverity($incidentType, $details),
            'timestamp' => time()
        ]);
        
        // Take immediate action based on incident type
        switch ($incidentType) {
            case 'brute_force_attack':
                $this->handleBruteForceAttack($details);
                break;
                
            case 'data_breach_suspected':
                $this->handleDataBreachSuspicion($details);
                break;
                
            case 'malware_detected':
                $this->handleMalwareDetection($details);
                break;
        }
    }
    
    private function handleBruteForceAttack(array $details): void
    {
        // Block offending IPs
        foreach ($details['source_ips'] as $ip) {
            $this->blockIpAddress($ip, duration: 3600); // 1 hour block
        }
        
        // Force password reset for targeted accounts
        if (isset($details['targeted_accounts'])) {
            foreach ($details['targeted_accounts'] as $userUuid) {
                $this->forcePasswordReset($userUuid);
            }
        }
        
        // Alert security team
        $this->sendSecurityAlert('Brute force attack detected', $details);
    }
    
    private function handleDataBreachSuspicion(array $details): void
    {
        // Enable high-level lockdown
        SecurityManager::enableLockdown('data_breach_suspected', 'high');
        
        // Revoke all active sessions
        $this->revokeAllActiveSessions();
        
        // Disable API access temporarily
        $this->disableApiAccess(duration: 7200); // 2 hours
        
        // Immediate security team notification
        $this->sendUrgentSecurityAlert('Data breach suspected', $details);
    }
}
```

### Intrusion Detection
- Monitor for suspicious activities

#### Advanced Anomaly Detection

```php
class SecurityAnomalyDetector
{
    public function detectAnomalies(string $userUuid, array $currentActivity): array
    {
        $anomalies = [];
        
        // Detect unusual login patterns
        $loginAnomaly = $this->detectLoginAnomalies($userUuid, $currentActivity);
        if ($loginAnomaly['is_anomalous']) {
            $anomalies[] = $loginAnomaly;
        }
        
        // Detect unusual API usage patterns
        $apiAnomaly = $this->detectApiUsageAnomalies($userUuid, $currentActivity);
        if ($apiAnomaly['is_anomalous']) {
            $anomalies[] = $apiAnomaly;
        }
        
        // Detect privilege escalation attempts
        $privilegeAnomaly = $this->detectPrivilegeEscalation($userUuid, $currentActivity);
        if ($privilegeAnomaly['is_anomalous']) {
            $anomalies[] = $privilegeAnomaly;
        }
        
        return $anomalies;
    }
    
    private function detectLoginAnomalies(string $userUuid, array $activity): array
    {
        $userProfile = $this->getUserBehaviorProfile($userUuid);
        
        $anomalyScore = 0;
        $reasons = [];
        
        // Check time-based anomalies
        $currentHour = (int)date('H');
        if (!in_array($currentHour, $userProfile['typical_login_hours'])) {
            $anomalyScore += 0.3;
            $reasons[] = 'unusual_login_time';
        }
        
        // Check location-based anomalies
        $currentLocation = $this->getLocationFromIp($activity['ip_address']);
        if (!$this->isLocationTypical($currentLocation, $userProfile['typical_locations'])) {
            $anomalyScore += 0.4;
            $reasons[] = 'unusual_location';
        }
        
        // Check device/browser anomalies
        $deviceFingerprint = $this->generateDeviceFingerprint($activity['user_agent']);
        if (!in_array($deviceFingerprint, $userProfile['known_devices'])) {
            $anomalyScore += 0.2;
            $reasons[] = 'unknown_device';
        }
        
        return [
            'is_anomalous' => $anomalyScore > 0.5,
            'anomaly_score' => $anomalyScore,
            'reasons' => $reasons,
            'type' => 'login_anomaly'
        ];
    }
}
```

### Security Auditing
- Conduct regular security audits
- Review access logs periodically

#### Automated Security Auditing

```php
class SecurityAuditor
{
    public function performSecurityAudit(): array
    {
        $auditResults = [
            'timestamp' => date('Y-m-d H:i:s'),
            'checks' => []
        ];
        
        // Audit user permissions
        $auditResults['checks']['permissions'] = $this->auditUserPermissions();
        
        // Audit session security
        $auditResults['checks']['sessions'] = $this->auditSessionSecurity();
        
        // Audit API security
        $auditResults['checks']['api_security'] = $this->auditApiSecurity();
        
        // Audit configuration security
        $auditResults['checks']['configuration'] = $this->auditConfigurationSecurity();
        
        // Calculate overall security score
        $auditResults['overall_score'] = $this->calculateOverallSecurityScore($auditResults['checks']);
        
        // Generate recommendations
        $auditResults['recommendations'] = $this->generateSecurityRecommendations($auditResults['checks']);
        
        return $auditResults;
    }
    
    private function auditUserPermissions(): array
    {
        $issues = [];
        
        // Check for users with excessive permissions
        $usersWithManyRoles = $this->findUsersWithExcessiveRoles(threshold: 5);
        if (!empty($usersWithManyRoles)) {
            $issues[] = [
                'type' => 'excessive_permissions',
                'severity' => 'medium',
                'users' => $usersWithManyRoles,
                'message' => 'Users with more than 5 roles detected'
            ];
        }
        
        // Check for inactive users with active permissions
        $inactiveUsersWithPermissions = $this->findInactiveUsersWithPermissions(days: 90);
        if (!empty($inactiveUsersWithPermissions)) {
            $issues[] = [
                'type' => 'inactive_user_permissions',
                'severity' => 'high',
                'users' => $inactiveUsersWithPermissions,
                'message' => 'Inactive users with active permissions detected'
            ];
        }
        
        return [
            'status' => empty($issues) ? 'pass' : 'fail',
            'issues' => $issues,
            'checked_at' => time()
        ];
    }
    
    private function auditSessionSecurity(): array
    {
        $issues = [];
        
        // Check for long-running sessions
        $longRunningSessions = $this->findLongRunningSessions(hours: 48);
        if (!empty($longRunningSessions)) {
            $issues[] = [
                'type' => 'long_running_sessions',
                'severity' => 'medium',
                'count' => count($longRunningSessions),
                'message' => 'Sessions running longer than 48 hours detected'
            ];
        }
        
        // Check for sessions from unusual locations
        $suspiciousSessions = $this->findSuspiciousSessions();
        if (!empty($suspiciousSessions)) {
            $issues[] = [
                'type' => 'suspicious_sessions',
                'severity' => 'high',
                'sessions' => $suspiciousSessions,
                'message' => 'Sessions from unusual locations detected'
            ];
        }
        
        return [
            'status' => empty($issues) ? 'pass' : 'fail',
            'issues' => $issues,
            'checked_at' => time()
        ];
    }
}

php glueful security:audit --fix-issues --dry-run
```

#### Automated Dependency Monitoring

```php
// Set up automated dependency vulnerability scanning
class DependencySecurityMonitor
{
    public function scanDependencies(): array
    {
        $scanner = new VulnerabilityScanner();
        $results = $scanner->performDependencyScan();
        
        // Check for critical vulnerabilities
        $criticalVulns = array_filter(
            $results['vulnerabilities'],
            fn($vuln) => $vuln['severity'] === 'critical'
        );
        
        if (!empty($criticalVulns)) {
            // Alert development team
            $this->alertDevelopmentTeam($criticalVulns);
            
            // Create tracking issues
            foreach ($criticalVulns as $vuln) {
                $this->createSecurityIssue($vuln);
            }
        }
        
        return $results;
    }
    
    private function alertDevelopmentTeam(array $vulnerabilities): void
    {
        $message = "Critical security vulnerabilities detected in dependencies:\n";
        
        foreach ($vulnerabilities as $vuln) {
            $message .= "- {$vuln['package']}: {$vuln['description']}\n";
            $message .= "  Current: {$vuln['current_version']}, Fix: {$vuln['recommendation']}\n";
        }
        
        // Send notification through your preferred channel
        NotificationService::send('security_alert', $message, [
            'channels' => ['email', 'slack'],
            'priority' => 'urgent'
        ]);
    }
}
```
