## Emergency Lockdown System

### Lockdown Mode Overview

The lockdown system provides emergency security capabilities to quickly restrict access during security incidents:

```php
use Glueful\Security\SecurityManager;

// Enable emergency lockdown
SecurityManager::enableLockdown('Security incident detected', 'high');

// Check lockdown status
$lockdownStatus = SecurityManager::getLockdownStatus();

if ($lockdownStatus['enabled']) {
    $level = $lockdownStatus['level']; // low, medium, high, critical
    $reason = $lockdownStatus['reason'];
    $allowedOperations = $lockdownStatus['allowed_operations'];
    
    // Restrict operations based on lockdown level
    if (!in_array($currentOperation, $allowedOperations)) {
        return Response::error('System in lockdown mode', 503, [
            'reason' => $reason,
            'level' => $level,
            'estimated_duration' => $lockdownStatus['estimated_duration']
        ]);
    }
}

// Disable lockdown after incident resolution
SecurityManager::disableLockdown();
```

### Lockdown Levels and Restrictions

```php
class LockdownManager
{
    private const LOCKDOWN_LEVELS = [
        'low' => [
            'allowed_operations' => [
                'read_profile', 'logout', 'health_check'
            ],
            'restrictions' => [
                'no_user_registration',
                'no_password_changes',
                'no_bulk_operations'
            ]
        ],
        'medium' => [
            'allowed_operations' => [
                'read_profile', 'logout', 'health_check', 'emergency_contact'
            ],
            'restrictions' => [
                'no_user_registration',
                'no_password_changes',
                'no_bulk_operations',
                'no_data_modifications',
                'admin_only_api_access'
            ]
        ],
        'high' => [
            'allowed_operations' => [
                'logout', 'health_check', 'emergency_contact'
            ],
            'restrictions' => [
                'read_only_mode',
                'admin_only_access',
                'no_api_access',
                'session_termination'
            ]
        ],
        'critical' => [
            'allowed_operations' => [
                'health_check', 'emergency_contact'
            ],
            'restrictions' => [
                'system_shutdown',
                'emergency_access_only',
                'all_sessions_terminated'
            ]
        ]
    ];
    
    public function applyLockdownRestrictions(string $level, string $operation): bool
    {
        $config = self::LOCKDOWN_LEVELS[$level] ?? self::LOCKDOWN_LEVELS['critical'];
        
        // Check if operation is allowed
        if (!in_array($operation, $config['allowed_operations'])) {
            AuditLogger::log('lockdown_operation_blocked', [
                'level' => $level,
                'operation' => $operation,
                'timestamp' => time()
            ]);
            
            return false;
        }
        
        return true;
    }
    
    public function enableAutomaticLockdown(array $triggers): void
    {
        // Monitor for automatic lockdown triggers
        foreach ($triggers as $trigger) {
            switch ($trigger['type']) {
                case 'vulnerability_count':
                    if ($this->getCriticalVulnerabilityCount() >= $trigger['threshold']) {
                        $this->enableLockdown('Critical vulnerabilities detected', 'medium');
                    }
                    break;
                    
                case 'failed_auth_rate':
                    $failureRate = $this->getAuthFailureRate(300); // 5 minutes
                    if ($failureRate >= $trigger['threshold']) {
                        $this->enableLockdown('High authentication failure rate', 'low');
                    }
                    break;
                    
                case 'suspicious_activity':
                    $suspiciousEvents = $this->getSuspiciousActivityCount(600); // 10 minutes
                    if ($suspiciousEvents >= $trigger['threshold']) {
                        $this->enableLockdown('Suspicious activity detected', 'medium');
                    }
                    break;
            }
        }
    }
}
```

## Adaptive Rate Limiting

### Advanced Rate Limiting with Behavioral Analysis

The `AdaptiveRateLimiter` provides sophisticated rate limiting with behavioral profiling:

```php
use Glueful\Security\AdaptiveRateLimiter;
use Glueful\Security\RateLimiterRule;
use Glueful\Http\RequestContext;

// Create adaptive rate limiter with context
$requestContext = RequestContext::fromGlobals();
$adaptiveLimiter = new AdaptiveRateLimiter(
    "api_endpoint:users:{$userUuid}",
    maxAttempts: 100,
    windowSeconds: 3600,
    context: [
        'user_uuid' => $userUuid,
        'endpoint' => 'users',
        'ip_address' => $request->ip(),
        'user_agent' => $request->headers->get('User-Agent'),
        'timestamp' => time()
    ],
    enableDistributed: true,
    requestContext: $requestContext
);

// Add dynamic rules based on behavior
$suspiciousActivityRule = new RateLimiterRule(
    'suspicious_activity',
    maxAttempts: 20,        // Reduced limit for suspicious users
    windowSeconds: 3600,
    threshold: 0.7          // Activate when behavior score > 0.7
);

$newUserRule = new RateLimiterRule(
    'new_user_protection',
    maxAttempts: 50,        // Lower limit for new users
    windowSeconds: 3600,
    threshold: 0.0,         // Always active
    conditions: ['user_age_days' => ['<', 7]]
);

$adaptiveLimiter->addRule($suspiciousActivityRule);
$adaptiveLimiter->addRule($newUserRule);

// Check rate limit with adaptive behavior
if (!$adaptiveLimiter->attempt()) {
    $behaviorScore = $adaptiveLimiter->getBehaviorScore();
    $activeRules = $adaptiveLimiter->getActiveApplicableRules();
    
    return Response::error('Rate limit exceeded', 429, [
        'retry_after' => $adaptiveLimiter->getRetryAfter(),
        'remaining' => $adaptiveLimiter->remaining(),
        'behavior_score' => $behaviorScore,
        'active_rules' => array_keys($activeRules),
        'message' => $behaviorScore > 0.5 
            ? 'Suspicious activity detected' 
            : 'Rate limit exceeded'
    ]);
}
```

### Behavioral Profiling

```php
class BehaviorAnalyzer
{
    public function analyzeBehavior(string $userUuid, array $context): float
    {
        $score = 0.0;
        
        // Analyze request patterns
        $score += $this->analyzeRequestPatterns($userUuid, $context);
        
        // Analyze temporal patterns
        $score += $this->analyzeTemporalPatterns($userUuid, $context);
        
        // Analyze geolocation patterns
        $score += $this->analyzeLocationPatterns($userUuid, $context);
        
        // Analyze device/browser patterns
        $score += $this->analyzeDevicePatterns($userUuid, $context);
        
        return min(1.0, max(0.0, $score));
    }
    
    private function analyzeRequestPatterns(string $userUuid, array $context): float
    {
        $recentRequests = $this->getRecentUserRequests($userUuid, 3600);
        $score = 0.0;
        
        // Check for rapid-fire requests
        $requestTimes = array_column($recentRequests, 'timestamp');
        $rapidRequests = $this->countRapidRequests($requestTimes, 60, 10); // 10+ requests in 1 minute
        
        if ($rapidRequests > 0) {
            $score += 0.3;
        }
        
        // Check for unusual endpoint access patterns
        $endpoints = array_column($recentRequests, 'endpoint');
        $uniqueEndpoints = array_unique($endpoints);
        
        if (count($uniqueEndpoints) > 20) { // Accessing many different endpoints
            $score += 0.2;
        }
        
        // Check for bot-like behavior patterns
        $userAgent = $context['user_agent'] ?? '';
        if ($this->detectBotLikeUserAgent($userAgent)) {
            $score += 0.4;
        }
        
        return $score;
    }
    
    private function analyzeTemporalPatterns(string $userUuid, array $context): float
    {
        $userProfile = $this->getUserBehaviorProfile($userUuid);
        $currentHour = (int)date('H');
        $score = 0.0;
        
        // Check if current activity time is unusual for this user
        $typicalHours = $userProfile['typical_activity_hours'] ?? [];
        if (!empty($typicalHours) && !in_array($currentHour, $typicalHours)) {
            $score += 0.2;
        }
        
        // Check for continuous activity (no breaks)
        $continuousHours = $this->getContinuousActivityHours($userUuid);
        if ($continuousHours > 12) {
            $score += 0.3;
        }
        
        return $score;
    }
    
    private function analyzeLocationPatterns(string $userUuid, array $context): float
    {
        $ipAddress = $context['ip_address'] ?? '';
        $userProfile = $this->getUserBehaviorProfile($userUuid);
        $score = 0.0;
        
        // Get geolocation for current IP
        $currentLocation = $this->getLocationFromIP($ipAddress);
        $typicalLocations = $userProfile['typical_locations'] ?? [];
        
        // Check for unusual geographic location
        if (!empty($typicalLocations) && !$this->isLocationTypical($currentLocation, $typicalLocations)) {
            $score += 0.4;
            
            // Higher score for very distant locations
            $distance = $this->calculateMinimumDistance($currentLocation, $typicalLocations);
            if ($distance > 5000) { // More than 5000 km from usual locations
                $score += 0.3;
            }
        }
        
        // Check for rapid location changes
        $recentLocations = $this->getRecentUserLocations($userUuid, 3600);
        if ($this->detectRapidLocationChanges($recentLocations)) {
            $score += 0.5;
        }
        
        return $score;
    }
}
```

### Distributed Rate Limiting

```php
use Glueful\Security\RateLimiterDistributor;

// Configure distributed rate limiting for multi-server environments
class DistributedRateLimitingService
{
    private RateLimiterDistributor $distributor;
    
    public function __construct()
    {
        $this->distributor = new RateLimiterDistributor();
        $this->registerNode();
    }
    
    public function registerNode(): void
    {
        $nodeId = gethostname() . '_' . getmypid();
        $nodeInfo = [
            'id' => $nodeId,
            'hostname' => gethostname(),
            'ip_address' => $this->getServerIP(),
            'capacity' => 1000, // requests per second capacity
            'load_factor' => $this->getCurrentLoadFactor()
        ];
        
        $this->distributor->registerNode($nodeInfo);
    }
    
    public function createDistributedRateLimiter(string $key, int $maxAttempts, int $windowSeconds): AdaptiveRateLimiter
    {
        // Adjust limits based on cluster capacity
        $clusterInfo = $this->distributor->getClusterInfo();
        $adjustedLimit = $this->adjustLimitForCluster($maxAttempts, $clusterInfo);
        
        $limiter = new AdaptiveRateLimiter(
            $key,
            $adjustedLimit,
            $windowSeconds,
            enableDistributed: true
        );
        
        // Sync with global rate limit state
        $this->distributor->synchronizeGlobalLimits($key, $limiter);
        
        return $limiter;
    }
    
    private function adjustLimitForCluster(int $baseLimit, array $clusterInfo): int
    {
        $totalCapacity = array_sum(array_column($clusterInfo['nodes'], 'capacity'));
        $nodeCapacity = $clusterInfo['current_node']['capacity'];
        
        // Proportionally adjust limit based on node capacity
        $adjustmentFactor = $nodeCapacity / $totalCapacity;
        return (int)($baseLimit * $adjustmentFactor);
    }
}
```

### Data Integrity and Security

```php
class SecureDataHandler
{
    private SecureSerializer $serializer;
    
    public function __construct()
    {
        $this->serializer = new SecureSerializer([
            'allowed_classes' => $this->getAllowedClasses(),
            'enable_integrity_check' => true,
            'enable_encryption' => true,
            'compression_level' => 6
        ]);
    }
    
    public function secureStore(string $key, mixed $data, int $ttl = 3600): bool
    {
        try {
            // Add metadata for integrity checking
            $payload = [
                'data' => $data,
                'timestamp' => time(),
                'checksum' => $this->calculateChecksum($data),
                'version' => '1.0'
            ];
            
            $serialized = $this->serializer->serialize($payload);
            
            return CacheEngine::set($key, $serialized, $ttl);
        } catch (Exception $e) {
            AuditLogger::log('secure_storage_failed', [
                'key' => $key,
                'error' => $e->getMessage(),
                'data_type' => gettype($data)
            ]);
            
            return false;
        }
    }
    
    public function secureRetrieve(string $key): mixed
    {
        $serialized = CacheEngine::get($key);
        
        if (!$serialized) {
            return null;
        }
        
        try {
            $payload = $this->serializer->unserialize($serialized);
            
            // Verify data integrity
            if (!$this->verifyIntegrity($payload)) {
                AuditLogger::log('data_integrity_violation', [
                    'key' => $key,
                    'timestamp' => time()
                ]);
                
                return null;
            }
            
            return $payload['data'];
        } catch (Exception $e) {
            AuditLogger::log('secure_retrieval_failed', [
                'key' => $key,
                'error' => $e->getMessage()
            ]);
            
            return null;
        }
    }
    
    private function verifyIntegrity(array $payload): bool
    {
        $expectedChecksum = $this->calculateChecksum($payload['data']);
        return hash_equals($expectedChecksum, $payload['checksum']);
    }
    
    private function calculateChecksum(mixed $data): string
    {
        return hash('sha256', serialize($data) . config('app.key'));
    }
}
```

## Advanced Hash and Encryption

### Hash Utilities

```php
use Glueful\Security\Hash;

// Generate secure hashes with different algorithms
$passwordHash = Hash::generate($password, 'argon2i', ['memory_cost' => 1024, 'time_cost' => 2]);
$dataHash = Hash::generate($sensitiveData, 'blake2b');
$fastHash = Hash::generate($nonCriticalData, 'xxh3');

// Verify hashes with timing-safe comparison
$isValid = Hash::verify($password, $passwordHash);

// Get hash information
$hashInfo = Hash::getInfo($passwordHash);
/*
Returns:
[
    'algorithm' => 'argon2i',
    'options' => ['memory_cost' => 1024, 'time_cost' => 2],
    'is_strong' => true,
    'needs_rehash' => false
]
*/

// Advanced hash operations
class SecureHashManager
{
    public function createSecureHash(string $data, array $options = []): array
    {
        $algorithm = $options['algorithm'] ?? 'argon2i';
        $salt = $options['salt'] ?? random_bytes(32);
        
        $hash = Hash::generate($data, $algorithm, array_merge([
            'salt' => $salt,
            'memory_cost' => 1024,
            'time_cost' => 3,
            'threads' => 2
        ], $options));
        
        return [
            'hash' => $hash,
            'algorithm' => $algorithm,
            'salt' => base64_encode($salt),
            'created_at' => time(),
            'strength_score' => $this->calculateHashStrength($hash, $algorithm)
        ];
    }
    
    public function verifyAndRehash(string $data, array $hashData): array
    {
        $isValid = Hash::verify($data, $hashData['hash']);
        
        if (!$isValid) {
            return ['valid' => false];
        }
        
        // Check if hash needs updating
        $needsRehash = $this->needsRehash($hashData);
        
        if ($needsRehash) {
            $newHashData = $this->createSecureHash($data);
            return [
                'valid' => true,
                'needs_rehash' => true,
                'new_hash' => $newHashData
            ];
        }
        
        return ['valid' => true, 'needs_rehash' => false];
    }
    
    private function needsRehash(array $hashData): bool
    {
        // Rehash if older than 1 year
        if (time() - $hashData['created_at'] > 365 * 24 * 3600) {
            return true;
        }
        
        // Rehash if strength score is below threshold
        if ($hashData['strength_score'] < 7.0) {
            return true;
        }
        
        return false;
    }
}
```

### Random String Generation

```php
use Glueful\Security\RandomStringGenerator;

// Generate various types of random strings
$apiKey = RandomStringGenerator::generate(32, 'hex');
$sessionToken = RandomStringGenerator::generate(40, 'base64url');
$userFriendlyCode = RandomStringGenerator::generate(8, 'alphanumeric_upper');

// Fast generation for high-volume use cases
$fastToken = RandomStringGenerator::generateFast(16); // Uses optimized algorithm

// Custom character sets
$customToken = RandomStringGenerator::generate(20, 'custom', [
    'charset' => '23456789ABCDEFGHJKLMNPQRSTUVWXYZ' // No confusing characters
]);

// Secure generation with additional entropy
class SecureTokenGenerator
{
    public function generateSecureApiKey(): string
    {
        // Combine multiple entropy sources
        $entropy = [
            random_bytes(16),
            microtime(true),
            getmypid(),
            gethostname()
        ];
        
        $combinedEntropy = hash('sha256', implode('', $entropy));
        
        return RandomStringGenerator::generate(32, 'hex', [
            'additional_entropy' => $combinedEntropy
        ]);
    }
    
    public function generateOTP(int $length = 6): string
    {
        // Generate cryptographically secure OTP
        $otp = '';
        for ($i = 0; $i < $length; $i++) {
            $otp .= random_int(0, 9);
        }
        
        return $otp;
    }
    
    public function generateNanoID(int $length = 21): string
    {
        // URL-safe unique ID generation
        $alphabet = '0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz_-';
        $id = '';
        
        for ($i = 0; $i < $length; $i++) {
            $id .= $alphabet[random_int(0, strlen($alphabet) - 1)];
        }
        
        return $id;
    }
}
```
