Glueful provides comprehensive enterprise authentication providers for seamless integration with corporate identity systems and single sign-on (SSO) solutions.

## SAML Authentication Provider

The SAML authentication provider enables integration with enterprise identity providers like Azure AD, Okta, Google Workspace, and other SAML 2.0 compliant systems.

### Configuration

Configure SAML authentication in your application:

```php
<?php

// Register SAML authentication provider
$authManager = AuthBootstrap::getManager();
$authManager->registerProvider('saml', new SamlAuthenticationProvider());
```

### SAML Settings

Configure your SAML settings for each identity provider:

```php
// SAML configuration example
$samlConfig = [
    'debug' => false,
    'default_idp' => 'azure_ad',
    'providers' => [
        'azure_ad' => [
            'idp' => [
                'entity_id' => 'https://sts.windows.net/tenant-id/',
                'sso_url' => 'https://login.microsoftonline.com/tenant-id/saml2',
                'slo_url' => 'https://login.microsoftonline.com/tenant-id/saml2',
                'x509cert' => '-----BEGIN CERTIFICATE-----...-----END CERTIFICATE-----',
            ],
            'sp' => [
                'entity_id' => 'https://yourapp.com/saml/azure_ad/metadata',
                'acs_url' => 'https://yourapp.com/saml/azure_ad/acs',
                'sls_url' => 'https://yourapp.com/saml/azure_ad/sls',
                'x509cert' => '',
                'private_key' => ''
            ],
            'attribute_mapping' => [
                'email' => ['http://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddress'],
                'name' => ['http://schemas.xmlsoap.org/ws/2005/05/identity/claims/name'],
                'first_name' => ['http://schemas.xmlsoap.org/ws/2005/05/identity/claims/givenname'],
                'last_name' => ['http://schemas.xmlsoap.org/ws/2005/05/identity/claims/surname'],
                'roles' => ['http://schemas.microsoft.com/ws/2008/06/identity/claims/role']
            ],
            'role_mapping' => [
                'Admin' => 'superuser',
                'User' => 'user',
            ],
            'security' => [
                'want_assertions_signed' => true,
            ]
        ]
    ]
];
```

### SAML Routes

Set up SAML routes for SSO workflow:

```php
// SAML SSO initiation
Router::get('/saml/{idp}/login', function($idp) {
    $samlProvider = new SamlAuthenticationProvider();
    return $samlProvider->initiateLogin($idp, Request::createFromGlobals());
});

// SAML Assertion Consumer Service (ACS)
Router::post('/saml/{idp}/acs', function($idp) {
    $request = Request::createFromGlobals();
    $request->attributes->set('idp', $idp);

    $samlProvider = new SamlAuthenticationProvider();
    $userData = $samlProvider->authenticate($request);

    if ($userData) {
        // Generate tokens and redirect to application
        $tokens = $samlProvider->generateTokens($userData);
        return Response::ok(['tokens' => $tokens, 'user' => $userData]);
    }

    return Response::unauthorized(['message' => 'SAML authentication failed']);
});

// SAML Single Logout Service (SLS)
Router::get('/saml/{idp}/sls', function($idp) {
    $samlProvider = new SamlAuthenticationProvider();
    return $samlProvider->logout($idp, Request::createFromGlobals());
});

// SAML metadata endpoint
Router::get('/saml/{idp}/metadata', function($idp) {
    $samlProvider = new SamlAuthenticationProvider();
    $metadata = $samlProvider->generateSpMetadata($idp, Request::createFromGlobals());

    return Response::make($metadata, 200, [
        'Content-Type' => 'application/xml'
    ]);
});
```

### Role Mapping

Map SAML roles to application roles:

```php
'role_mapping' => [
    // Direct role mapping
    'Admin' => 'superuser',
    'Manager' => 'admin',
    'Employee' => 'user',

    // Pattern matching for complex role names
    '/^App-(.+)-Admins$/i' => 'admin',
    '/^Department-(.+)-Users$/i' => 'user'
]
```

## LDAP Authentication Provider

The LDAP authentication provider supports Active Directory and other LDAP-compliant directory services.

### Configuration

```php
<?php

// Register LDAP authentication provider
$authManager = AuthBootstrap::getManager();
$authManager->registerProvider('ldap', new LdapAuthenticationProvider());
```

### LDAP Settings

Configure LDAP servers and authentication:

```php
$ldapConfig = [
    'default_server' => 'company_ad',
    'servers' => [
        'company_ad' => [
            'hosts' => ['ldap.company.com'],
            'base_dn' => 'dc=company,dc=com',
            'bind_username' => 'cn=service-account,ou=service,dc=company,dc=com',
            'bind_password' => 'secure_password_here',
            'port' => 389,
            'use_ssl' => false,
            'use_tls' => true,
            'timeout' => 5,
            'version' => 3,
            'follow_referrals' => false,
            'username_attribute' => 'sAMAccountName',
            'user_search_base' => 'ou=users,dc=company,dc=com',
            'account_suffix' => '@company.com',
            'username_format' => '{username}',
            'attribute_mapping' => [
                'email' => ['mail', 'userPrincipalName'],
                'name' => ['displayName', 'cn'],
                'first_name' => ['givenName'],
                'last_name' => ['sn'],
                'phone' => ['telephoneNumber'],
                'title' => ['title'],
                'department' => ['department']
            ],
            'group_mapping' => [
                'Domain Admins' => 'superuser',
                'IT Staff' => 'admin',
                'Domain Users' => 'user',
                // Pattern matching for complex group names
                '/^App-(.+)-Admins$/i' => 'admin',
            ]
        ]
    ]
];
```

### LDAP Authentication

Authenticate users against LDAP:

```php
Router::post('/auth/ldap', function() {
    $request = Request::createFromGlobals();
    $ldapProvider = new LdapAuthenticationProvider();

    $userData = $ldapProvider->authenticate($request);

    if ($userData) {
        $tokens = $ldapProvider->generateTokens($userData);
        return Response::ok([
            'tokens' => $tokens,
            'user' => $userData
        ], 'LDAP authentication successful');
    }

    return Response::unauthorized([
        'message' => 'LDAP authentication failed',
        'error' => $ldapProvider->getError()
    ]);
});

// Multi-server LDAP authentication
Router::post('/auth/ldap/{server}', function($server) {
    $request = Request::createFromGlobals();
    $request->request->set('ldap_server', $server);

    $ldapProvider = new LdapAuthenticationProvider();
    $userData = $ldapProvider->authenticate($request);

    if ($userData) {
        $tokens = $ldapProvider->generateTokens($userData);
        return Response::ok(['tokens' => $tokens, 'user' => $userData]);
    }

    return Response::unauthorized(['message' => 'Authentication failed']);
});
```

### Group-Based Authorization

Map LDAP groups to application roles:

```php
'group_mapping' => [
    // Direct group name mapping
    'Domain Admins' => 'superuser',
    'IT Staff' => 'admin',
    'HR Team' => 'hr_admin',

    // Pattern matching with regex
    '/^App-(.+)-Admins$/i' => 'admin',
    '/^Department-(.+)-Users$/i' => 'user'
]
```

## OAuth 2.0 Server

Glueful includes a complete OAuth 2.0 server implementation supporting multiple grant types.

### Installation and Setup

Enable the OAuth Server extension:

```php
<?php

// In your application bootstrap
use Glueful\Extensions\OAuthServer;

// Initialize OAuth Server
OAuthServer::initialize();
```

### Supported Grant Types

The OAuth server supports these grant types:

- **Authorization Code Grant** (with PKCE support)
- **Client Credentials Grant**
- **Password Grant**
- **Refresh Token Grant**

### Client Registration

Register OAuth clients:

```php
// Create OAuth client
Router::post('/oauth/clients', function() {
    $clientData = Request::getPostData();

    $client = [
        'client_id' => bin2hex(random_bytes(20)),
        'client_secret' => bin2hex(random_bytes(32)),
        'name' => $clientData['name'],
        'redirect_uris' => $clientData['redirect_uris'],
        'grant_types' => $clientData['grant_types'] ?? ['authorization_code'],
        'scopes' => $clientData['scopes'] ?? ['read'],
        'is_confidential' => $clientData['is_confidential'] ?? true
    ];

    // Store client in database
    $oauthServer = new OAuthServer();
    $clientId = $oauthServer->createClient($client);

    return Response::ok(['client' => $client]);
});
```

### Authorization Endpoint

Handle authorization requests:

```php
Router::get('/oauth/authorize', function() {
    $request = Request::createFromGlobals();
    $oauthServer = new OAuthServer();

    // Validate authorization request
    $authRequest = $oauthServer->validateAuthorizationRequest($request->query->all());

    if (!$authRequest) {
        return Response::error('Invalid authorization request', 400);
    }

    // Show authorization form to user
    return Response::view('oauth/authorize', [
        'client' => $authRequest['client'],
        'scopes' => $authRequest['scopes']
    ]);
});

Router::post('/oauth/authorize', function() {
    $request = Request::createFromGlobals();
    $oauthServer = new OAuthServer();

    if ($request->request->get('action') === 'approve') {
        // Generate authorization code
        $code = $oauthServer->generateAuthorizationCode(
            $request->request->all(),
            $request->attributes->get('user_id')
        );

        $redirectUri = $request->request->get('redirect_uri');
        $redirectUri .= '?code=' . $code . '&state=' . $request->request->get('state');

        return Response::redirect($redirectUri);
    }

    return Response::error('Authorization denied', 403);
});
```

### Token Endpoint

Issue OAuth tokens:

```php
Router::post('/oauth/token', function() {
    $request = Request::createFromGlobals();
    $oauthServer = new OAuthServer();

    try {
        $tokenResponse = $oauthServer->issueToken($request->request->all());
        return Response::ok($tokenResponse);
    } catch (\Exception $e) {
        return Response::error($e->getMessage(), 400);
    }
});
```

### Token Validation

Validate OAuth tokens:

```php
// OAuth token validation middleware
Router::get('/api/protected', function() {
    return Response::ok(['message' => 'Access granted', 'data' => 'Protected content']);
})->middleware(new AuthenticationMiddleware(
    false,
    AuthBootstrap::getManager(),
    ['oauth'] // Use OAuth authentication provider
));
```

## Environment Configuration

Configure authentication providers in your `.env` file:

```env
# SAML Configuration
SAML_DEBUG=false
SAML_DEFAULT_IDP=azure_ad
SAML_STRICT_MODE=true

# LDAP Configuration
LDAP_DEFAULT_SERVER=company_ad
LDAP_TIMEOUT=5
LDAP_USE_TLS=true

# OAuth Server Configuration
OAUTH_ACCESS_TOKEN_TTL=3600          # 1 hour
OAUTH_REFRESH_TOKEN_TTL=2592000      # 30 days
OAUTH_AUTH_CODE_TTL=600              # 10 minutes
OAUTH_REQUIRE_PKCE=true              # Require PKCE for security
OAUTH_ALLOW_PUBLIC_CLIENTS=false     # Only allow confidential clients
```

## Security Considerations

### SAML Security

- Always validate SAML assertions and signatures
- Use encrypted assertions when possible
- Implement proper session management
- Configure appropriate certificate validation

### LDAP Security

- Use TLS/SSL for LDAP connections
- Use service accounts with minimal privileges
- Implement connection timeouts
- Validate LDAP responses and handle errors gracefully

### OAuth Security

- Always use PKCE for public clients
- Implement proper scope validation
- Use short-lived access tokens
- Rotate refresh tokens when possible
- Validate redirect URIs strictly

## Troubleshooting

### Common SAML Issues

```php
// Debug SAML authentication
$samlProvider = new SamlAuthenticationProvider();
$errors = $samlProvider->getError();

if ($errors) {
    error_log("SAML Error: " . $errors);
}

// Validate SAML metadata
$metadata = $samlProvider->generateSpMetadata('azure_ad', $request);
$validationErrors = $samlProvider->validateMetadata($metadata);
```

### LDAP Connection Issues

```php
// Test LDAP connectivity
$ldapProvider = new LdapAuthenticationProvider();
$connection = $ldapProvider->testConnection('company_ad');

if (!$connection) {
    error_log("LDAP Connection Error: " . $ldapProvider->getError());
}
```

### OAuth Token Issues

```php
// Validate OAuth token manually
$oauthServer = new OAuthServer();
$tokenInfo = $oauthServer->validateToken($accessToken);

if (!$tokenInfo) {
    error_log("OAuth Token Validation Failed");
}
```
