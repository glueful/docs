Glueful provides comprehensive query optimization and analysis tools to help you identify performance bottlenecks and improve database query efficiency.

## Overview

The query optimization system includes:

- **QueryOptimizer**: Automatic query optimization suggestions
- **ExecutionPlanAnalyzer**: Database execution plan analysis
- **QueryPatternRecognizer**: Pattern detection for common optimizations
- **Query Profiling**: Real-time performance monitoring

## Query Optimizer

The QueryOptimizer analyzes your queries and provides database-specific optimization suggestions:

```php
use Glueful\Database\QueryOptimizer;
use Glueful\Database\Connection;

$connection = new Connection();
$optimizer = new QueryOptimizer($connection);

// Analyze a query and get optimization suggestions
$query = "SELECT * FROM users WHERE email = ? AND status = 'active'";
$suggestions = $optimizer->optimize($query, [$email]);

foreach ($suggestions as $suggestion) {
    echo "Type: {$suggestion['type']}\n";
    echo "Suggestion: {$suggestion['message']}\n";
    echo "Impact: {$suggestion['impact']}\n";
    echo "Optimized Query: {$suggestion['optimized_query']}\n\n";
}
```

### Optimization Types

The optimizer can detect and suggest improvements for:

```php
// Index recommendations
$suggestions = $optimizer->analyzeIndexNeeds($tableName, $whereConditions);

// Query rewriting suggestions
$rewritten = $optimizer->rewriteQuery($originalQuery, $parameters);

// JOIN optimization
$optimizedJoins = $optimizer->optimizeJoins($query);

// Subquery optimization
$optimizedSubqueries = $optimizer->optimizeSubqueries($query);
```

## Execution Plan Analysis

Analyze how the database executes your queries:

```php
use Glueful\Database\ExecutionPlanAnalyzer;

$analyzer = new ExecutionPlanAnalyzer($connection);

// Get execution plan for a query
$plan = $analyzer->analyze("
    SELECT u.name, COUNT(o.id) as order_count
    FROM users u
    LEFT JOIN orders o ON u.id = o.user_id
    WHERE u.status = 'active'
    GROUP BY u.id
    ORDER BY order_count DESC
    LIMIT 10
");

// Analyze the execution plan
echo "Query Cost: {$plan['cost']}\n";
echo "Execution Time Estimate: {$plan['estimated_time']}ms\n";
echo "Rows Examined: {$plan['rows_examined']}\n";
echo "Using Index: " . ($plan['using_index'] ? 'Yes' : 'No') . "\n";

// Get detailed plan steps
foreach ($plan['steps'] as $step) {
    echo "Step: {$step['operation']}\n";
    echo "Table: {$step['table']}\n";
    echo "Cost: {$step['cost']}\n";
    echo "Rows: {$step['rows']}\n\n";
}
```

### Database-Specific Analysis

```php
// MySQL-specific execution plan
if ($connection->getDriver() === 'mysql') {
    $mysqlPlan = $analyzer->getMySQLExecutionPlan($query);
    
    // Check for full table scans
    $fullTableScans = $analyzer->detectFullTableScans($mysqlPlan);
    
    // Analyze index usage
    $indexUsage = $analyzer->analyzeIndexUsage($mysqlPlan);
}

// PostgreSQL-specific analysis
if ($connection->getDriver() === 'pgsql') {
    $postgresqlPlan = $analyzer->getPostgreSQLExecutionPlan($query);
    
    // Analyze buffer usage
    $bufferAnalysis = $analyzer->analyzeBufferUsage($postgresqlPlan);
}
```

## Query Pattern Recognition

Identify common performance patterns and anti-patterns:

```php
use Glueful\Database\QueryPatternRecognizer;

$recognizer = new QueryPatternRecognizer();

// Analyze query patterns
$patterns = $recognizer->analyze($query);

foreach ($patterns as $pattern) {
    switch ($pattern['type']) {
        case 'N+1_QUERY':
            echo "N+1 Query detected: {$pattern['description']}\n";
            echo "Suggestion: {$pattern['solution']}\n";
            break;
            
        case 'MISSING_INDEX':
            echo "Missing index detected on: {$pattern['columns']}\n";
            echo "Suggested index: {$pattern['suggested_index']}\n";
            break;
            
        case 'INEFFICIENT_JOIN':
            echo "Inefficient join detected: {$pattern['join_type']}\n";
            echo "Optimization: {$pattern['optimization']}\n";
            break;
            
        case 'LARGE_OFFSET':
            echo "Large offset pagination detected\n";
            echo "Consider cursor-based pagination\n";
            break;
    }
}
```

## CLI Query Analysis Commands

Glueful provides powerful CLI commands for query analysis:

```bash
# Profile a specific query
php glueful db:query:profile --query="SELECT * FROM users WHERE status = 'active'" --explain

# Analyze query performance
php glueful db:query:analyze --table=users --where="status='active'"

# Get optimization suggestions
php glueful db:query:optimize --query="SELECT u.*, p.* FROM users u JOIN profiles p ON u.id = p.user_id"

# Analyze all slow queries
php glueful db:query:analyze --slow-queries --threshold=1000

# Generate index suggestions for a table
php glueful db:index:suggest --table=orders --analyze-queries
```

### Batch Query Analysis

```bash
# Analyze multiple queries from a file
php glueful db:query:analyze --file=queries.sql --output=analysis.json

# Analyze queries from application logs
php glueful db:query:analyze --log-file=storage/logs/query.log --format=json

# Compare query performance across different database configurations
php glueful db:query:compare --config1=production --config2=staging
```

## Performance Profiling

Real-time query performance monitoring:

```php
use Glueful\Database\QueryProfilerService;

$profiler = new QueryProfilerService();

// Start profiling
$profiler->startProfiling();

// Execute your queries
$users = $db->table('users')->where('status', 'active')->get();
$orders = $db->table('orders')->where('user_id', $userId)->get();

// Get profiling results
$results = $profiler->getResults();

foreach ($results as $result) {
    echo "Query: {$result['query']}\n";
    echo "Parameters: " . json_encode($result['parameters']) . "\n";
    echo "Execution Time: {$result['execution_time']}ms\n";
    echo "Memory Usage: {$result['memory_usage']} bytes\n";
    echo "Rows Affected: {$result['rows_affected']}\n";
    
    if ($result['execution_time'] > 1000) {
        echo "⚠️  Slow query detected!\n";
    }
    
    echo "\n";
}

// Get summary statistics
$stats = $profiler->getStatistics();
echo "Total Queries: {$stats['total_queries']}\n";
echo "Average Execution Time: {$stats['avg_execution_time']}ms\n";
echo "Slowest Query: {$stats['slowest_query_time']}ms\n";
echo "Total Memory Used: {$stats['total_memory']} bytes\n";
```

### Profiling with Context

```php
// Profile queries with business context
$profiler->setContext([
    'controller' => 'UserController',
    'action' => 'index',
    'user_id' => $currentUserId,
    'request_id' => $requestId
]);

// Profile specific operations
$profiler->startOperation('user_dashboard_load');

// Your database operations here
$users = $userRepo->getActiveUsers();
$stats = $analyticsRepo->getUserStats($userId);

$profiler->endOperation('user_dashboard_load');

// Get operation-specific results
$operationResults = $profiler->getOperationResults('user_dashboard_load');
```

## Index Analysis and Recommendations

Analyze and optimize database indexes:

```php
use Glueful\Database\IndexAnalyzer;

$indexAnalyzer = new IndexAnalyzer($connection);

// Analyze existing indexes
$indexAnalysis = $indexAnalyzer->analyzeTable('users');

echo "Unused Indexes:\n";
foreach ($indexAnalysis['unused_indexes'] as $index) {
    echo "- {$index['name']} (Last used: {$index['last_used']})\n";
}

echo "\nMissing Indexes:\n";
foreach ($indexAnalysis['missing_indexes'] as $suggestion) {
    echo "- Columns: " . implode(', ', $suggestion['columns']) . "\n";
    echo "  Reason: {$suggestion['reason']}\n";
    echo "  Impact: {$suggestion['impact']}\n";
    echo "  SQL: {$suggestion['create_sql']}\n\n";
}

// Get index usage statistics
$usage = $indexAnalyzer->getIndexUsageStats('users');
foreach ($usage as $index => $stats) {
    echo "Index: {$index}\n";
    echo "Usage Count: {$stats['usage_count']}\n";
    echo "Selectivity: {$stats['selectivity']}\n";
    echo "Size: {$stats['size_mb']} MB\n\n";
}
```

## Best Practices for Query Optimization

### 1. Regular Analysis

```php
// Set up automated query analysis
$optimizer = new QueryOptimizer($connection);

// Analyze queries periodically
$optimizer->scheduleAnalysis([
    'interval' => '1 hour',
    'threshold' => 100, // ms
    'notify_on_slow_queries' => true,
    'auto_suggest_indexes' => true
]);
```

### 2. Development Profiling

```php
// Enable profiling in development
if (config('app.env') === 'development') {
    $profiler = new QueryProfilerService();
    $profiler->enableAutoDebugging();
    
    // Log slow queries
    $profiler->onSlowQuery(function($query, $time) {
        logger()->warning("Slow query detected: {$query} ({$time}ms)");
    });
}
```

### 3. Production Monitoring

```php
// Monitor queries in production
$monitor = new QueryMonitor();
$monitor->trackSlowQueries([
    'threshold' => 500, // ms
    'sample_rate' => 0.1, // 10% sampling
    'alert_threshold' => 1000 // ms
]);
```

### 4. Index Maintenance

```bash
# Regular index maintenance
php glueful db:index:analyze --all-tables
php glueful db:index:cleanup --remove-unused
php glueful db:index:rebuild --fragmented-only
```

## Troubleshooting Common Issues

### Slow Queries

```php
// Identify slow queries
$slowQueries = $profiler->getSlowQueries(['threshold' => 1000]);

foreach ($slowQueries as $query) {
    // Analyze the slow query
    $analysis = $optimizer->analyzeSlowQuery($query);
    
    echo "Query: {$query['sql']}\n";
    echo "Time: {$query['execution_time']}ms\n";
    echo "Suggestions:\n";
    
    foreach ($analysis['suggestions'] as $suggestion) {
        echo "- {$suggestion}\n";
    }
}
```

### Memory Usage Issues

```php
// Monitor memory usage during query execution
$memoryTracker = new QueryMemoryTracker();

$memoryTracker->startTracking();
$largeResult = $db->table('large_table')->get();
$memoryUsage = $memoryTracker->getUsage();

if ($memoryUsage > 50 * 1024 * 1024) { // 50MB
    echo "High memory usage detected: " . formatBytes($memoryUsage) . "\n";
    echo "Consider using chunked processing or pagination\n";
}
```

### Connection Pool Issues

```php
// Monitor connection pool performance
$poolMonitor = new ConnectionPoolMonitor();
$poolStats = $poolMonitor->getStatistics();

if ($poolStats['active_connections'] > $poolStats['max_connections'] * 0.8) {
    echo "Connection pool utilization high: {$poolStats['utilization']}%\n";
    echo "Consider increasing pool size or optimizing query patterns\n";
}
```
