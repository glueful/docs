This section covers working with database models in the Glueful framework.

## Repository Pattern

Glueful implements the repository pattern for database access, which provides a clean separation between data access logic and business logic:

```php
<?php

namespace App\Repository;

use Glueful\Database\Connection;

class UserRepository
{
    private Connection $connection;

    public function __construct()
    {
        $this->connection = new Connection();
    }

    public function getAll(array $filters = [], int $limit = 20, int $offset = 0)
    {
        $query = $this->connection->table('users')
            ->select(['uuid', 'username', 'email', 'status', 'created_at']);

        if (isset($filters['status'])) {
            $query->where('status', '=', $filters['status']);
        }

        return $query->limit($limit)
            ->offset($offset)
            ->orderBy('created_at', 'DESC')
            ->get();
    }

    public function findById(string $id)
    {
        return $this->connection->table('users')
            ->select(['uuid', 'username', 'email', 'status', 'created_at'])
            ->where('uuid', '=', $id)
            ->first();
    }
}
```

## Built-in Repositories

Glueful comes with several built-in repositories for common operations:

- `UserRepository` - User management and authentication
- `RoleRepository` - Roles and role assignments
- `PermissionRepository` - Access control and permissions
- `NotificationRepository` - System notifications

These repositories provide standardized access to core system models with proper validation and business logic.

## Query Builder

The QueryBuilder provides a fluent interface for SQL operations with multi-database support:

```php
// Get connection and use table method
$connection = new Connection();

// Basic selects
$users = $connection->table('users')
    ->select(['id', 'name', 'email'])
    ->where('status', '=', 'active')
    ->orderBy('name', 'ASC')
    ->limit(10)
    ->get();

// Joins
$posts = $connection->table('posts')
    ->select(['posts.id', 'posts.title', 'users.name as author'])
    ->join('users', 'users.id', '=', 'posts.user_id')
    ->where('posts.status', '=', 'published')
    ->get();

// Aggregates
$count = $connection->table('users')
    ->where('status', '=', 'active')
    ->count();
```

### Advanced Where Clauses

The QueryBuilder supports various condition types:

```php
// Complex where conditions
$query->where('status', '=', 'active')
      ->whereBetween('created_at', [$startDate, $endDate])
      ->whereNull('deleted_at')
      ->whereIn('role', ['admin', 'manager'])
      ->whereRaw('YEAR(created_at) = ?', [2025]);

// OR conditions
$query->where('status', '=', 'active')
      ->orWhere('status', '=', 'pending');

// Grouped conditions
$query->where('status', '=', 'active')
      ->whereGroup(function($q) {
          $q->where('role', '=', 'admin')
            ->orWhere('role', '=', 'superuser');
      });
```

### Database Drivers

Glueful's QueryBuilder automatically adapts to different database engines:

- MySQL with backtick identifier quoting
- PostgreSQL with double-quote identifiers
- SQLite with specific syntax support

The driver abstraction maintains consistent API across different database systems.

## Transactions

Database transactions ensure data integrity for multi-step operations:

```php
$connection = new Connection();

try {
    $connection->beginTransaction();

    // Perform multiple operations
    $userId = $connection->table('users')->insertGetId([
        'name' => 'John Doe',
        'email' => 'john@example.com',
    ]);

    $connection->table('profiles')->insert([
        'user_id' => $userId,
        'bio' => 'New user bio',
    ]);

    $connection->commit();
} catch (\Exception $e) {
    $connection->rollBack();
    throw $e;
}
```

## Model Relationships

While Glueful uses the repository pattern rather than ORM-style models, you can implement relationships in your repositories:

```php
class UserRepository
{
    // ...

    public function getWithProfile(string $id)
    {
        $user = $this->findById($id);
        
        if (!$user) {
            return null;
        }
        
        $profile = $this->connection->table('profiles')
            ->where('user_uuid', '=', $user['uuid'])
            ->first();
            
        $user['profile'] = $profile;
        
        return $user;
    }
    
    public function getRoles(string $userUuid)
    {
        return $this->connection->table('roles')
            ->select(['roles.*'])
            ->join('user_roles_lookup', 'roles.uuid', '=', 'user_roles_lookup.role_uuid')
            ->where('user_roles_lookup.user_uuid', '=', $userUuid)
            ->get();
    }
}
```

## Raw Expressions

For complex SQL operations, you can use raw expressions:

```php
use Glueful\Database\RawExpression;

// Use raw SQL expressions (use with caution)
$db->table('users')
   ->select(['*', new RawExpression('COUNT(*) OVER() as total_count')])
   ->whereRaw('created_at > NOW() - INTERVAL ? DAY', [30])
   ->orderBy('id', 'DESC')
   ->get();
```

## Database Migration Support

Glueful's database migration system integrates with models to manage schema evolution:

```php
class CreateUsersTable implements MigrationInterface
{
    public function up(SchemaManager $schema): void
    {
        $schema->createTable('users', [
            'id' => 'BIGINT PRIMARY KEY AUTO_INCREMENT',
            'uuid' => 'CHAR(12) NOT NULL',
            'username' => 'VARCHAR(100) NOT NULL',
            'email' => 'VARCHAR(255) NOT NULL',
            'password' => 'VARCHAR(255) NOT NULL',
            'status' => 'VARCHAR(20) DEFAULT "active"',
            'created_at' => 'TIMESTAMP DEFAULT CURRENT_TIMESTAMP',
            'updated_at' => 'TIMESTAMP NULL ON UPDATE CURRENT_TIMESTAMP'
        ])->addIndex([
            ['type' => 'UNIQUE', 'column' => 'email'],
            ['type' => 'UNIQUE', 'column' => 'username'],
            ['type' => 'INDEX', 'column' => 'status']
        ]);
    }

    public function down(SchemaManager $schema): void
    {
        $schema->dropTable('users');
    }
}
```

## Advanced Repository Features

Glueful's repositories include several advanced features for enterprise applications:

### Base Repository Class

The `BaseRepository` provides common functionality for all repositories:

```php
<?php

namespace Glueful\Repository;

use Glueful\Database\Connection;

abstract class BaseRepository
{
    protected Connection $connection;
    protected string $table;
    protected string $primaryKey = 'id';
    protected array $fillable = [];
    protected array $hidden = ['password', 'remember_token'];
    protected bool $useAuditLog = true;
    
    public function __construct()
    {
        $this->connection = new Connection();
    }
    
    // Bulk operations
    public function bulkCreate(array $records): int
    {
        return $this->connection->table($this->table)->bulkInsert($records);
    }
    
    public function bulkUpdate(array $conditions, array $data): int
    {
        return $this->connection->table($this->table)
            ->where($conditions)
            ->bulkUpdate($data);
    }
    
    public function bulkDelete(array $conditions): int
    {
        return $this->connection->table($this->table)
            ->where($conditions)
            ->bulkDelete();
    }
    
    // Advanced querying
    public function findWhere(array $conditions, array $columns = ['*']): array
    {
        return $this->connection->table($this->table)
            ->select($columns)
            ->where($conditions)
            ->get();
    }
    
    public function findWhereIn(string $column, array $values): array
    {
        return $this->connection->table($this->table)
            ->whereIn($column, $values)
            ->get();
    }
    
    public function search(array $columns, string $term): array
    {
        return $this->connection->table($this->table)
            ->search($columns, $term, 'OR')
            ->get();
    }
    
    // Pagination with metadata
    public function paginate(int $page = 1, int $perPage = 20, array $conditions = []): array
    {
        $query = $this->connection->table($this->table);
        
        if (!empty($conditions)) {
            $query->where($conditions);
        }
        
        return $query->paginate($page, $perPage);
    }
    
    // Soft delete support
    public function softDelete(array $conditions): bool
    {
        return $this->connection->table($this->table)
            ->where($conditions)
            ->update(['deleted_at' => date('Y-m-d H:i:s')]);
    }
    
    public function restore(array $conditions): bool
    {
        return $this->connection->table($this->table)
            ->where($conditions)
            ->update(['deleted_at' => null]);
    }
    
    public function withTrashed(): self
    {
        // Implementation for including soft-deleted records
        return $this;
    }
    
    public function onlyTrashed(): self
    {
        // Implementation for only soft-deleted records
        return $this;
    }
}
```

### Repository with Audit Logging

```php
<?php

namespace App\Repository;

use Glueful\Repository\BaseRepository;
use Glueful\Audit\AuditLogger;
use Glueful\Security\RequestContext;

class UserRepository extends BaseRepository
{
    protected string $table = 'users';
    protected string $primaryKey = 'uuid';
    protected array $fillable = ['username', 'email', 'status'];
    protected array $auditableEvents = ['created', 'updated', 'deleted'];
    
    private AuditLogger $auditLogger;
    private RequestContext $requestContext;
    
    public function __construct()
    {
        parent::__construct();
        $this->auditLogger = new AuditLogger();
        $this->requestContext = new RequestContext();
    }
    
    public function create(array $data): string
    {
        // Filter data based on fillable fields
        $filteredData = array_intersect_key($data, array_flip($this->fillable));
        $filteredData['uuid'] = Utils::generateNanoID();
        $filteredData['created_at'] = date('Y-m-d H:i:s');
        
        $result = $this->connection->table($this->table)->insert($filteredData);
        
        if ($result && $this->useAuditLog) {
            $this->auditLogger->logEvent([
                'event_type' => 'user_created',
                'table_name' => $this->table,
                'record_id' => $filteredData['uuid'],
                'new_values' => $this->sanitizeForAudit($filteredData),
                'user_id' => $this->requestContext->getUserId(),
                'ip_address' => $this->requestContext->getIpAddress(),
                'user_agent' => $this->requestContext->getUserAgent(),
                'timestamp' => date('Y-m-d H:i:s')
            ]);
        }
        
        return $filteredData['uuid'];
    }
    
    public function update(string $uuid, array $data): bool
    {
        // Get original data for audit trail
        $originalData = $this->findById($uuid);
        if (!$originalData) {
            return false;
        }
        
        // Filter and update data
        $filteredData = array_intersect_key($data, array_flip($this->fillable));
        $filteredData['updated_at'] = date('Y-m-d H:i:s');
        
        $result = $this->connection->table($this->table)
            ->where(['uuid' => $uuid])
            ->update($filteredData);
        
        if ($result && $this->useAuditLog) {
            $this->auditLogger->logEvent([
                'event_type' => 'user_updated',
                'table_name' => $this->table,
                'record_id' => $uuid,
                'old_values' => $this->sanitizeForAudit($originalData),
                'new_values' => $this->sanitizeForAudit(array_merge($originalData, $filteredData)),
                'changed_fields' => array_keys($filteredData),
                'user_id' => $this->requestContext->getUserId(),
                'ip_address' => $this->requestContext->getIpAddress(),
                'user_agent' => $this->requestContext->getUserAgent(),
                'timestamp' => date('Y-m-d H:i:s')
            ]);
        }
        
        return $result;
    }
    
    public function delete(string $uuid, bool $softDelete = true): bool
    {
        $originalData = $this->findById($uuid);
        if (!$originalData) {
            return false;
        }
        
        if ($softDelete) {
            $result = $this->softDelete(['uuid' => $uuid]);
        } else {
            $result = $this->connection->table($this->table)
                ->where(['uuid' => $uuid])
                ->delete();
        }
        
        if ($result && $this->useAuditLog) {
            $this->auditLogger->logEvent([
                'event_type' => $softDelete ? 'user_soft_deleted' : 'user_hard_deleted',
                'table_name' => $this->table,
                'record_id' => $uuid,
                'old_values' => $this->sanitizeForAudit($originalData),
                'user_id' => $this->requestContext->getUserId(),
                'ip_address' => $this->requestContext->getIpAddress(),
                'user_agent' => $this->requestContext->getUserAgent(),
                'timestamp' => date('Y-m-d H:i:s')
            ]);
        }
        
        return $result;
    }
    
    // Advanced user-specific methods
    public function findByEmail(string $email): ?array
    {
        return $this->connection->table($this->table)
            ->where(['email' => $email])
            ->whereNull('deleted_at')
            ->first();
    }
    
    public function getActiveUsersWithRoles(): array
    {
        return $this->connection->table($this->table)
            ->select([
                'users.uuid',
                'users.username',
                'users.email',
                'users.status',
                'GROUP_CONCAT(roles.name) as roles'
            ])
            ->leftJoin('user_roles_lookup', 'users.uuid = user_roles_lookup.user_uuid')
            ->leftJoin('roles', 'user_roles_lookup.role_uuid = roles.uuid')
            ->where(['users.status' => 'active'])
            ->whereNull('users.deleted_at')
            ->groupBy(['users.uuid'])
            ->get();
    }
    
    public function getUsersByPermission(string $permission): array
    {
        return $this->connection->table($this->table)
            ->select(['users.*'])
            ->join('user_roles_lookup', 'users.uuid = user_roles_lookup.user_uuid')
            ->join('roles', 'user_roles_lookup.role_uuid = roles.uuid')
            ->join('role_permissions_lookup', 'roles.uuid = role_permissions_lookup.role_uuid')
            ->join('permissions', 'role_permissions_lookup.permission_uuid = permissions.uuid')
            ->where(['permissions.name' => $permission])
            ->whereNull('users.deleted_at')
            ->distinct()
            ->get();
    }
    
    // Transaction support
    public function createUserWithProfile(array $userData, array $profileData): string
    {
        return $this->connection->transaction(function() use ($userData, $profileData) {
            $userUuid = $this->create($userData);
            
            $profileData['user_uuid'] = $userUuid;
            $this->connection->table('user_profiles')->insert($profileData);
            
            return $userUuid;
        });
    }
    
    private function sanitizeForAudit(array $data): array
    {
        // Remove sensitive fields from audit log
        return array_diff_key($data, array_flip($this->hidden));
    }
}
```

### Audit Logging System

```php
<?php

namespace Glueful\Audit;

use Glueful\Database\Connection;

class AuditLogger
{
    private Connection $connection;
    private array $sensitiveFields = ['password', 'remember_token', 'api_key'];
    
    public function __construct()
    {
        $this->connection = new Connection();
    }
    
    public function logEvent(array $eventData): bool
    {
        // Sanitize sensitive data
        if (isset($eventData['old_values'])) {
            $eventData['old_values'] = $this->sanitizeData($eventData['old_values']);
        }
        
        if (isset($eventData['new_values'])) {
            $eventData['new_values'] = $this->sanitizeData($eventData['new_values']);
        }
        
        // Convert arrays to JSON
        if (isset($eventData['old_values']) && is_array($eventData['old_values'])) {
            $eventData['old_values'] = json_encode($eventData['old_values']);
        }
        
        if (isset($eventData['new_values']) && is_array($eventData['new_values'])) {
            $eventData['new_values'] = json_encode($eventData['new_values']);
        }
        
        if (isset($eventData['changed_fields']) && is_array($eventData['changed_fields'])) {
            $eventData['changed_fields'] = json_encode($eventData['changed_fields']);
        }
        
        return $this->connection->table('audit_logs')->insert($eventData);
    }
    
    public function getAuditTrail(string $tableName, string $recordId): array
    {
        return $this->connection->table('audit_logs')
            ->where(['table_name' => $tableName, 'record_id' => $recordId])
            ->orderBy('timestamp', 'DESC')
            ->get();
    }
    
    public function getUserActivity(string $userId, int $limit = 50): array
    {
        return $this->connection->table('audit_logs')
            ->where(['user_id' => $userId])
            ->orderBy('timestamp', 'DESC')
            ->limit($limit)
            ->get();
    }
    
    public function getRecentActivity(int $hours = 24): array
    {
        $since = date('Y-m-d H:i:s', strtotime("-{$hours} hours"));
        
        return $this->connection->table('audit_logs')
            ->where('timestamp', '>=', $since)
            ->orderBy('timestamp', 'DESC')
            ->get();
    }
    
    public function searchAuditLogs(array $criteria): array
    {
        $query = $this->connection->table('audit_logs');
        
        if (isset($criteria['event_type'])) {
            $query->where('event_type', '=', $criteria['event_type']);
        }
        
        if (isset($criteria['table_name'])) {
            $query->where('table_name', '=', $criteria['table_name']);
        }
        
        if (isset($criteria['user_id'])) {
            $query->where('user_id', '=', $criteria['user_id']);
        }
        
        if (isset($criteria['ip_address'])) {
            $query->where('ip_address', '=', $criteria['ip_address']);
        }
        
        if (isset($criteria['date_from'])) {
            $query->where('timestamp', '>=', $criteria['date_from']);
        }
        
        if (isset($criteria['date_to'])) {
            $query->where('timestamp', '<=', $criteria['date_to']);
        }
        
        return $query->orderBy('timestamp', 'DESC')->get();
    }
    
    private function sanitizeData(array $data): array
    {
        foreach ($this->sensitiveFields as $field) {
            if (isset($data[$field])) {
                $data[$field] = '[REDACTED]';
            }
        }
        
        return $data;
    }
}
```

### Repository Caching

```php
<?php

namespace App\Repository;

use Glueful\Cache\CacheEngine;

class CachedUserRepository extends UserRepository
{
    private int $cacheTtl = 3600; // 1 hour
    
    public function findById(string $uuid): ?array
    {
        $cacheKey = "user:{$uuid}";
        
        return CacheEngine::remember($cacheKey, $this->cacheTtl, function() use ($uuid) {
            return parent::findById($uuid);
        });
    }
    
    public function findByEmail(string $email): ?array
    {
        $cacheKey = "user:email:{$email}";
        
        return CacheEngine::remember($cacheKey, $this->cacheTtl, function() use ($email) {
            return parent::findByEmail($email);
        });
    }
    
    public function update(string $uuid, array $data): bool
    {
        $result = parent::update($uuid, $data);
        
        if ($result) {
            // Invalidate cache
            CacheEngine::delete("user:{$uuid}");
            
            // If email was updated, invalidate email cache too
            if (isset($data['email'])) {
                $originalData = $this->findById($uuid);
                if ($originalData) {
                    CacheEngine::delete("user:email:{$originalData['email']}");
                }
            }
        }
        
        return $result;
    }
    
    public function delete(string $uuid, bool $softDelete = true): bool
    {
        $originalData = $this->findById($uuid);
        $result = parent::delete($uuid, $softDelete);
        
        if ($result && $originalData) {
            CacheEngine::delete("user:{$uuid}");
            CacheEngine::delete("user:email:{$originalData['email']}");
        }
        
        return $result;
    }
}
```

## Security Considerations

Glueful's database layer implements several security features:

- All input parameters are properly escaped via PDO prepared statements
- Query Logger automatically redacts sensitive data like passwords and tokens
- Database access is controlled through the repository pattern
- Configuration handles different environments (development, testing, production)
- Comprehensive logging for audit and security monitoring
- Automatic audit trails for sensitive operations
- Request context tracking for security analysis
- Data sanitization for audit logs
- Role-based access control integration
