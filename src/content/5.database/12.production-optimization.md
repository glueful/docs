This guide provides comprehensive best practices and optimization strategies for running Glueful databases in production environments.

## Pre-Production Checklist

Before deploying to production, ensure all these items are properly configured:

### Database Configuration
- [ ] Connection pooling is enabled and properly tuned
- [ ] Query caching is configured with appropriate TTL values
- [ ] Performance monitoring is enabled with proper thresholds
- [ ] Backup and recovery systems are tested and functional
- [ ] Security settings are configured (audit logging, access control)
- [ ] SSL/TLS encryption is enabled for database connections
- [ ] Database users have minimal required privileges

### Infrastructure Setup
- [ ] Database server has adequate RAM, CPU, and storage
- [ ] Database and application servers are in the same network zone
- [ ] Monitoring and alerting systems are configured
- [ ] Log rotation and management are set up
- [ ] Disaster recovery procedures are documented and tested

## Index Optimization

### Index Strategy Guidelines

```php
// Automated index analysis and suggestions
class ProductionIndexOptimizer
{
    public function analyzeAndOptimize()
    {

        $missingIndexes = $this->identifyMissingIndexes();

        $indexUsage = $this->analyzeIndexUsage();
        
        // 4. Generate optimization report
        return $this->generateOptimizationReport($missingIndexes, $unusedIndexes, $indexUsage);
    }
    
    private function identifyMissingIndexes(): array
    {
        // Analyze slow query log and execution plans
        return [
            [
                'table' => 'users',
                'columns' => ['email', 'status'],
                'type' => 'composite',
                'reason' => 'Frequent WHERE email = ? AND status = ? queries',
                'impact' => 'high',
                'sql' => 'CREATE INDEX idx_users_email_status ON users(email, status)'
            ],
            [
                'table' => 'orders',
                'columns' => ['created_at'],
                'type' => 'single',
                'reason' => 'Date range queries and ORDER BY created_at',
                'impact' => 'medium',
                'sql' => 'CREATE INDEX idx_orders_created_at ON orders(created_at)'
            ],
        ];
    }
}
```

### Index Best Practices

1. **Primary Keys**: Always use surrogate primary keys (auto-increment or UUID)
2. **Foreign Keys**: Index all foreign key columns
3. **Composite Indexes**: Order columns by selectivity (most selective first)
4. **Partial Indexes**: Use for filtered queries (PostgreSQL)
5. **Covering Indexes**: Include frequently accessed columns

```sql
-- Examples of optimized indexes

-- Composite index for user login
CREATE INDEX idx_users_email_status ON users(email, status);

-- Partial index for active records only (PostgreSQL)
CREATE INDEX idx_active_users ON users(created_at) WHERE status = 'active';

-- Covering index to avoid table lookups
CREATE INDEX idx_orders_covering ON orders(user_id, status) INCLUDE (total, created_at);

-- Index for date range queries
CREATE INDEX idx_orders_date_range ON orders(created_at, status);
```

## Query Optimization

### Query Pattern Optimization

```php
// Optimize N+1 query problems
class OptimizedUserRepository extends BaseRepository
{
    // BAD: N+1 query problem
    public function getUsersWithRolesBad(): array
    {
        $users = $this->findAll();
        foreach ($users as &$user) {
            $user['roles'] = $this->getRoles($user['uuid']); // N queries
        }
        return $users;
    }
    
    // GOOD: Single query with JOIN
    public function getUsersWithRolesOptimized(): array
    {
        return $this->db->table('users')
            ->select([
                'users.uuid',
                'users.username',
                'users.email',
                'GROUP_CONCAT(roles.name) as roles'
            ])
            ->leftJoin('user_roles_lookup', 'users.uuid = user_roles_lookup.user_uuid')
            ->leftJoin('roles', 'user_roles_lookup.role_uuid = roles.uuid')
            ->groupBy(['users.uuid'])
            ->get();
    }
    
    // GOOD: Use eager loading pattern
    public function getUsersWithRolesEager(array $userIds): array
    {
        // Get users
        $users = $this->db->table('users')
            ->whereIn('uuid', $userIds)
            ->get();
        
        // Get all roles in one query
        $userRoles = $this->db->table('user_roles_lookup')
            ->select(['user_uuid', 'role_uuid', 'roles.name as role_name'])
            ->join('roles', 'user_roles_lookup.role_uuid = roles.uuid')
            ->whereIn('user_uuid', $userIds)
            ->get();
        
        // Combine results
        $rolesMap = [];
        foreach ($userRoles as $role) {
            $rolesMap[$role['user_uuid']][] = $role['role_name'];
        }
        
        foreach ($users as &$user) {
            $user['roles'] = $rolesMap[$user['uuid']] ?? [];
        }
        
        return $users;
    }
}
```

### Pagination Optimization

```php
// Optimize pagination for large datasets
class OptimizedPagination
{
    // BAD: OFFSET pagination for large datasets
    public function paginateWithOffset(int $page, int $perPage): array
    {
        $offset = ($page - 1) * $perPage;
        
        return $this->db->table('large_table')
            ->orderBy('id')
            ->limit($perPage)
            ->offset($offset) // Becomes slow for large offsets
            ->get();
    }
    
    // GOOD: Cursor-based pagination
    public function paginateWithCursor(?int $lastId, int $perPage): array
    {
        $query = $this->db->table('large_table')
            ->orderBy('id');
        
        if ($lastId) {
            $query->where('id', '>', $lastId);
        }
        
        return $query->limit($perPage)->get();
    }
    
    // GOOD: Keyset pagination for specific use cases
    public function paginateWithKeyset(string $lastCreatedAt, int $lastId, int $perPage): array
    {
        return $this->db->table('large_table')
            ->where(function($query) use ($lastCreatedAt, $lastId) {
                $query->where('created_at', '>', $lastCreatedAt)
                      ->orWhere(function($q) use ($lastCreatedAt, $lastId) {
                          $q->where('created_at', '=', $lastCreatedAt)
                            ->where('id', '>', $lastId);
                      });
            })
            ->orderBy('created_at')
            ->orderBy('id')
            ->limit($perPage)
            ->get();
    }
}
```

## Memory Management

### Connection Memory Optimization

```php
// Memory-conscious connection management
class MemoryOptimizedRepository
{
    private const BATCH_SIZE = 1000;
    
    public function processBulkData(array $data): void
    {
        // Process in batches to avoid memory exhaustion
        $batches = array_chunk($data, self::BATCH_SIZE);
        
        foreach ($batches as $batch) {
            $this->db->transaction(function() use ($batch) {
                $this->processBatch($batch);
            });
            
            // Force garbage collection after each batch
            if (function_exists('gc_collect_cycles')) {
                gc_collect_cycles();
            }
        }
    }
    
    public function streamLargeResultSet(callable $processor): void
    {
        // Use chunked processing for large result sets
        $this->db->table('large_table')
            ->orderBy('id')
            ->chunk(1000, function($results) use ($processor) {
                foreach ($results as $row) {
                    $processor($row);
                }
                
                // Clear result set memory
                unset($results);
            });
    }
}
```

## Monitoring and Alerting

### Production Monitoring Setup

```php
// Production monitoring configuration
class ProductionMonitoring
{
    public function setupMonitoring(): void
    {
        $monitor = new PerformanceMonitor($this->connection, [
            'sampling_rate' => 0.01, // Monitor 1% of queries in production
            'slow_query_threshold' => 1000,
            'memory_threshold' => 512 * 1024 * 1024, // 512MB
            'enable_stack_traces' => false, // Disable for performance
        ]);
        
        // Set up alerts
        $this->setupAlerts($monitor);
        
        // Configure metrics collection
        $this->setupMetricsCollection($monitor);
    }
    
    private function setupAlerts(PerformanceMonitor $monitor): void
    {
        // Critical alerts
        $monitor->onCriticalIssue(function($issue) {
            $this->sendCriticalAlert([
                'type' => $issue['type'],
                'message' => $issue['message'],
                'metrics' => $issue['metrics'],
                'timestamp' => date('Y-m-d H:i:s'),
            ]);
        });
        
        // Performance degradation alerts
        $monitor->onPerformanceDegradation(function($metrics) {
            if ($metrics['avg_response_time'] > 2000) { // 2 seconds
                $this->sendWarningAlert('High database response time detected');
            }
            
            if ($metrics['connection_utilization'] > 90) {
                $this->sendWarningAlert('High connection pool utilization');
            }
        });
    }
    
    private function setupMetricsCollection(PerformanceMonitor $monitor): void
    {
        // Export metrics to external monitoring systems
        $monitor->onMetricsCollection(function($metrics) {
            // Send to Prometheus
            $this->exportToPrometheus($metrics);
            
            // Send to New Relic
            $this->exportToNewRelic($metrics);
            
            // Store in time-series database
            $this->storeInInfluxDB($metrics);
        });
    }
}
```

### Health Checks

```php
// Comprehensive health check system
class DatabaseHealthCheck
{
    public function performHealthCheck(): array
    {
        $checks = [
            'connection' => $this->checkConnection(),
            'query_performance' => $this->checkQueryPerformance(),
            'connection_pool' => $this->checkConnectionPool(),
            'disk_space' => $this->checkDiskSpace(),
            'replication' => $this->checkReplication(),
            'backup_status' => $this->checkBackupStatus(),
        ];
        
        $overallHealth = $this->calculateOverallHealth($checks);
        
        return [
            'status' => $overallHealth,
            'checks' => $checks,
            'timestamp' => date('Y-m-d H:i:s'),
        ];
    }
    
    private function checkConnection(): array
    {
        try {
            $start = microtime(true);
            $this->db->query('SELECT 1');
            $responseTime = (microtime(true) - $start) * 1000;
            
            return [
                'status' => $responseTime < 100 ? 'healthy' : 'degraded',
                'response_time' => $responseTime,
                'message' => "Connection response time: {$responseTime}ms",
            ];
        } catch (\Exception $e) {
            return [
                'status' => 'unhealthy',
                'error' => $e->getMessage(),
                'message' => 'Database connection failed',
            ];
        }
    }
    
    private function checkQueryPerformance(): array
    {
        // Check recent query performance
        $slowQueries = $this->getSlowQueries(300); // Last 5 minutes
        
        if (count($slowQueries) > 10) {
            return [
                'status' => 'degraded',
                'slow_query_count' => count($slowQueries),
                'message' => 'High number of slow queries detected',
            ];
        }
        
        return [
            'status' => 'healthy',
            'slow_query_count' => count($slowQueries),
            'message' => 'Query performance is normal',
        ];
    }
}
```

## Backup and Recovery

### Production Backup Strategy

```php
// Comprehensive backup system for production
class ProductionBackupSystem
{
    public function setupBackupStrategy(): void
    {
        // Daily full backups
        $this->scheduleBackup('full', '0 2 * * *', [
            'compression' => true,
            'encryption' => true,
            'verification' => true,
            'storage' => ['s3', 'local'],
        ]);
        
        // Hourly incremental backups (if supported)
        $this->scheduleBackup('incremental', '0 * * * *', [
            'compression' => true,
            'encryption' => true,
            'storage' => ['s3'],
        ]);
        
        // Weekly backup verification
        $this->scheduleBackupVerification('0 3 * * 0');
        
        // Monthly disaster recovery test
        $this->scheduleDisasterRecoveryTest('0 4 1 * *');
    }
    
    public function performBackup(string $type, array $options): bool
    {
        try {
            // Pre-backup health check
            $healthStatus = $this->performHealthCheck();
            if ($healthStatus['status'] !== 'healthy') {
                $this->logWarning('Backup initiated with degraded health status');
            }
            
            // Perform backup
            $backupFile = $this->createBackup($type, $options);
            
            // Verify backup integrity
            if ($options['verification']) {
                $this->verifyBackup($backupFile);
            }
            
            // Upload to storage locations
            foreach ($options['storage'] as $storage) {
                $this->uploadBackup($backupFile, $storage);
            }
            
            // Clean up old backups
            $this->cleanupOldBackups();
            
            // Send success notification
            $this->sendBackupNotification('success', $backupFile);
            
            return true;
        } catch (\Exception $e) {
            $this->logError('Backup failed: ' . $e->getMessage());
            $this->sendBackupNotification('failure', null, $e->getMessage());
            return false;
        }
    }
}
```
