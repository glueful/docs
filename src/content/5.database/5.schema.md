Glueful provides powerful schema management tools through the SchemaBuilder classes, which support multiple database engines including MySQL, PostgreSQL, and SQLite.

## SchemaBuilder Overview

The schema builder allows you to create, modify, and manage database structures using a consistent API regardless of the underlying database engine.

```php
use Glueful\Database\Connection;

// Get the schema builder for your database
$connection = new Connection();
$schema = $connection->getSchemaBuilder();
```

## Creating Tables

Create tables using the fluent callback-based API:

```php
$schema->createTable('users', function ($table) {
    $table->bigInteger('id')->primary()->autoIncrement();
    $table->string('uuid', 12);
    $table->string('username', 255);
    $table->string('email', 255);
    $table->string('password', 100)->nullable();
    $table->string('status', 20)->default('active');
    $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
    $table->timestamp('updated_at')->nullable();
    
    // Add indexes
    $table->unique('uuid');
    $table->unique('username');
    $table->unique('email');
    $table->index('status');
});
```

## Adding Indexes

Add various types of indexes using fluent methods:

```php
$schema->createTable('products', function ($table) {
    $table->bigInteger('id')->primary()->autoIncrement();
    $table->string('name', 255);
    $table->decimal('price', 10, 2);
    $table->bigInteger('category_id');
    $table->string('status', 20)->default('active');
    $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
    
    // Single column unique index
    $table->unique('name');
    
    // Regular indexes
    $table->index('category_id');
    $table->index('status');
    $table->index('created_at');
    
    // Multi-column index with custom name
    $table->unique(['name', 'category_id'], 'unique_product_per_category');
});
```

## Foreign Keys

Establish relationships between tables using fluent foreign key methods:

```php
$schema->createTable('orders', function ($table) {
    $table->bigInteger('id')->primary()->autoIncrement();
    $table->string('uuid', 12);
    $table->string('user_uuid', 12);
    $table->decimal('total', 10, 2);
    $table->string('status', 50);
    $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
    
    // Add indexes
    $table->unique('uuid');
    $table->index('user_uuid');
    $table->index('status');
    
    // Add foreign key constraint
    $table->foreign('user_uuid')
        ->references('uuid')
        ->on('users')
        ->restrictOnDelete(); // or ->cascadeOnDelete() or ->nullOnDelete()
});

// Create a junction table with multiple foreign keys
$schema->createTable('order_items', function ($table) {
    $table->bigInteger('id')->primary()->autoIncrement();
    $table->string('order_uuid', 12);
    $table->string('product_uuid', 12);
    $table->integer('quantity');
    $table->decimal('price', 10, 2);
    
    // Foreign keys
    $table->foreign('order_uuid')
        ->references('uuid')
        ->on('orders')
        ->cascadeOnDelete();
        
    $table->foreign('product_uuid')
        ->references('uuid')
        ->on('products')
        ->restrictOnDelete();
});
```

## Modifying Tables

Modify existing tables by adding columns using the fluent callback API:

```php
// Add new columns to an existing table
$schema->alterTable('users', function ($table) {
    $table->string('phone_number', 20)->nullable();
    $table->text('bio')->nullable();
    $table->timestamp('last_activity_at')->nullable();
    
    // Add indexes on new columns
    $table->index('phone_number');
    $table->index('last_activity_at');
});
```

## Dropping Tables and Columns

Remove database objects when no longer needed:

```php
// Drop a table (fails if table doesn't exist)
$schema->dropTable('temp_users');

// Drop a table if it exists (safe)
$schema->dropTableIfExists('temp_users');

// Drop columns using alterTable callback
$schema->alterTable('users', function ($table) {
    $table->dropColumn('unused_column');
    $table->dropIndex('old_index_name');
    $table->dropForeignKey('fk_old_constraint');
});
```

## Column Types

The SchemaBuilder supports various column types with fluent method chaining:

```php
$schema->createTable('comprehensive_example', function ($table) {
    // Primary key with auto-increment
    $table->bigInteger('id')->primary()->autoIncrement();
    
    // String columns with length constraints
    $table->string('name', 255);
    $table->string('code', 50)->unique();
    
    // Text columns for larger content
    $table->text('description')->nullable();
    
    // Numeric columns
    $table->integer('count')->default(0);
    $table->decimal('price', 10, 2);
    
    // JSON column for structured data
    $table->json('metadata')->nullable();
    
    // Boolean column
    $table->boolean('is_active')->default(true);
    
    // Timestamp columns
    $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
    $table->timestamp('updated_at')->nullable();
    $table->timestamp('deleted_at')->nullable();
});

## Retrieving Schema Information

Inspect database schema using the SchemaBuilder interface:

```php
// Check if table exists
$exists = $schema->hasTable('users');

// Check if column exists
$hasColumn = $schema->hasColumn('users', 'email');

// Get all tables
$tables = $schema->getTables();

// Get table columns
$columns = $schema->getTableColumns('users');

// Get complete table schema
$tableSchema = $schema->getTableSchema('users');

// Get table size and row count
$size = $schema->getTableSize('users');
$count = $schema->getTableRowCount('users');
```

## Performance Considerations

- Use appropriate index types for your query patterns
- Be careful with adding too many indexes as they slow down write operations
- Consider using foreign key constraints only for critical relationships
- For large tables, always use indexed columns in WHERE clauses
- Be mindful of schema changes on large tables as they can lock tables during alteration

## Transaction Support

Wrap schema operations in transactions for atomic changes:

```php
// Use SchemaBuilder transaction method
$schema->transaction(function () use ($schema) {
    // Create multiple tables atomically
    $schema->createTable('orders', function ($table) {
        $table->bigInteger('id')->primary()->autoIncrement();
        $table->string('uuid', 12)->unique();
        $table->decimal('amount', 10, 2);
        $table->text('description')->nullable();
        $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
        
        $table->index('created_at');
    });
    
    $schema->createTable('order_items', function ($table) {
        $table->bigInteger('id')->primary()->autoIncrement();
        $table->string('order_uuid', 12);
        $table->string('product_name', 255);
        $table->integer('quantity');
        
        $table->foreign('order_uuid')
            ->references('uuid')
            ->on('orders')
            ->cascadeOnDelete();
    });
});

## Multi-Database Support

The SchemaBuilder automatically adapts to different database engines:

```php
// This code works across MySQL, PostgreSQL, and SQLite
$schema->createTable('portable_table', function ($table) {
    $table->bigInteger('id')->primary()->autoIncrement(); // Adapts to each engine
    $table->string('name', 255);
    $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
});

// Engine-specific adaptations:
// MySQL: BIGINT AUTO_INCREMENT PRIMARY KEY
// PostgreSQL: BIGSERIAL PRIMARY KEY
// SQLite: INTEGER PRIMARY KEY AUTOINCREMENT
```

## Integration with Migrations

Glueful's SchemaBuilder is designed to work seamlessly with the built-in migration system:

```php
<?php
// In a migration file

use Glueful\Database\Migrations\MigrationInterface;
use Glueful\Database\Schema\Interfaces\SchemaBuilderInterface;

class CreateSocialAccountsTable implements MigrationInterface
{
    public function up(SchemaBuilderInterface $schema): void
    {
        $schema->createTable('social_accounts', function ($table) {
            $table->bigInteger('id')->primary()->autoIncrement();
            $table->string('uuid', 12);
            $table->string('user_uuid', 12);
            $table->string('provider', 50);
            $table->string('social_id', 255);
            $table->text('profile_data')->nullable();
            $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
            $table->timestamp('updated_at')->nullable();
            
            // Add indexes
            $table->unique('uuid');
            $table->index('user_uuid');
            $table->unique(['provider', 'social_id']);
            
            // Add foreign key
            $table->foreign('user_uuid')
                ->references('uuid')
                ->on('users')
                ->cascadeOnDelete();
        });
    }
    
    public function down(SchemaBuilderInterface $schema): void
    {
        $schema->dropTableIfExists('social_accounts');
    }
    
    public function getDescription(): string
    {
        return "Create social_accounts table for social login integration";
    }
}
```

## Indexing Strategy Best Practices

Glueful follows these best practices for indexing:

1. **Primary keys** are automatically indexed
2. **Foreign keys** should be indexed to improve join performance
3. **Unique constraints** are enforced with unique indexes
4. **Frequently queried fields** should have appropriate indexes
5. **Multi-column indexes** for queries that filter on multiple columns

Index naming follows a consistent pattern:
- `idx_[table]_[column1]_[column2]` for multi-column indexes
- `idx_[table]_[column]` for single-column indexes

This strategy ensures optimal query performance while maintaining clean and readable schema definitions.

## Schema Validation and Preview

The SchemaBuilder includes validation and preview capabilities:

```php
// Preview what SQL would be executed
$sqlStatements = $schema->preview();
foreach ($sqlStatements as $sql) {
    echo "Would execute: {$sql}\n";
}

// Validate schema operations before execution
$validation = $schema->validate();
if (!empty($validation['errors'])) {
    foreach ($validation['errors'] as $error) {
        echo "Validation Error: {$error}\n";
    }
}

// Execute all pending operations
$results = $schema->execute();
```

Glueful provides CLI commands for schema management:

```bash
# Migration commands
php glueful migrate:run
php glueful migrate:status
php glueful migrate:create CreateUsersTable
php glueful migrate:rollback

# Database management
php glueful db:status
php glueful db:reset --force
```

These commands integrate with the migration system to provide comprehensive database schema management capabilities.
