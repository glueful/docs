This section covers database management in the Glueful framework, including schema structure, migrations, and query building.

## Overview

Glueful provides a comprehensive set of tools for working with databases, including:

- **[Query Builder](./query-builder)**: A fluent interface for constructing database queries
- **[Schema Management](./schema)**: Tools for creating and modifying database structures
- **[Migrations](./migrations)**: Version control for your database schema
- **[Pagination](./pagination)**: Efficient handling of large datasets
- **[Database Models](./database-models)**: Repository pattern for database access

## Database Connection

To get started with database operations, you first need to establish a connection:

```php
use Glueful\Database\Connection;

// Create a database connection (or use global container)
$connection = new Connection();
// Or get from container: $connection = container()->get('database');

// Get a query builder instance using Connection::table() method
$users = $connection->table('users')->select(['id', 'name'])->get();

// Or get a schema builder for database structure operations
$schema = $connection->getSchemaBuilder();
```

## Database Operations

Here are some common database operations you can perform with Glueful:

```php
// Execute CRUD operations using Connection::table() method
$connection = new Connection();

// Select records
$users = $connection->table('users')
    ->select(['id', 'name', 'email'])
    ->where('status', 'active')
    ->get();

// Insert records
$userId = $connection->table('users')->insert([
    'name' => 'John Doe',
    'email' => 'john@example.com',
    'status' => 'active'
]);

// Update records
$affected = $connection->table('users')
    ->where('id', 5)
    ->update(['status' => 'inactive']);

// Delete records
$deleted = $connection->table('users')
    ->where('status', 'deleted')
    ->delete();

// Use complex joins and conditions
$results = $connection->table('products')
    ->select(['products.*', 'categories.name AS category_name'])
    ->join('categories', 'products.category_id', '=', 'categories.id')
    ->where('products.price', '>', 100)
    ->orderBy('products.created_at', 'DESC')
    ->limit(20)
    ->get();
```

## Transaction Support

Glueful provides robust transaction support to ensure data integrity when performing multiple operations:

```php
// Using Connection for transactions
$connection = new Connection();
$pdo = $connection->getPDO();

try {
    // Start transaction
    $pdo->beginTransaction();
    
    // Execute multiple operations using Connection::table()
    $orderId = $connection->table('orders')->insert([
        'customer_id' => 123,
        'total' => 99.99,
        'status' => 'pending'
    ]);
    
    $connection->table('order_items')->insert([
        'order_id' => $orderId,
        'product_id' => 456,
        'quantity' => 1
    ]);
    
    $connection->table('inventory')
        ->where('product_id', 456)
        ->update(['stock' => $connection->raw('stock - 1')]);
    
    // Commit if all operations succeed
    $pdo->commit();
    
    return true;
} catch (\Exception $e) {
    // Rollback on error
    $pdo->rollBack();
    
    // Log error
    error_log("Transaction failed: " . $e->getMessage());
    
    return false;
}
```

## Repository Pattern

Glueful implements the repository pattern to abstract database access and separate business logic from data access. This pattern provides:

- Centralized data access logic
- Improved testability
- Encapsulated query construction
- Type safety through models
- Reusable data access methods

Here's an example of a typical repository implementation:

```php
namespace Glueful\Repository;

use Glueful\Database\Connection;
use Glueful\Models\Product;

class ProductRepository {
    private Connection $connection;
    
    public function __construct(Connection $connection = null) {
        $this->connection = $connection ?? new Connection();
    }
    
    public function find(string $uuid): ?Product {
        $result = $this->connection->table('products')
            ->select(['*'])
            ->where('uuid', $uuid)
            ->first();
            
        if (!$result) {
            return null;
        }
        
        return new Product($result);
    }
    
    public function save(Product $product): bool {
        $data = $product->toArray();
        
        // Check if product exists
        $existing = $this->find($product->getUuid());
        
        if ($existing) {
            // Update existing product
            return $this->connection->table('products')
                ->where('uuid', $product->getUuid())
                ->update($data);
        } else {
            // Insert new product
            return $this->connection->table('products')->insert($data);
        }
    }
    
    public function delete(string $uuid): bool {
        return $this->connection->table('products')
            ->where('uuid', $uuid)
            ->delete();
    }
    
    public function findByCategory(string $categoryId): array {
        return $this->connection->table('products')
            ->select(['*'])
            ->where('category_id', $categoryId)
            ->where('status', 'active')
            ->orderBy('created_at', 'DESC')
            ->get();
    }
}
```

## CLI Database Management

Glueful comes with comprehensive command-line tools for database management:

### Basic Database Operations

```bash
# Run pending migrations
php glueful migrate:run

# Check database status
php glueful db:status

# Reset database (requires confirmation)
php glueful db:reset --force

# Generate JSON schema
php glueful generate:json api-definitions -d mydb -T users

# Run database seeders
php glueful db:seed

# Drop all tables and re-run migrations
php glueful db:fresh
```

### Advanced Database Tools

```bash
# Connection pool management
php glueful db:pool:status             # Check connection pool status
php glueful db:pool:reset              # Reset connection pool
php glueful db:pool:health             # Health check for pooled connections

# Query profiling and analysis
php glueful db:query:profile           # Profile database queries
php glueful db:query:analyze           # Analyze query performance
php glueful db:query:optimize          # Suggest query optimizations

# Profile specific queries
php glueful db:profile --query="SELECT * FROM users WHERE status = 'active'" --explain

# Cache management
php glueful cache:clear                # Clear all cache
php glueful cache:warm                 # Warm up application cache
```

## Database Performance & Profiling

Glueful includes advanced performance monitoring and profiling tools to help optimize your database operations.

### Query Profiling

```php
use Glueful\Database\QueryProfilerService;
use Glueful\Database\ExecutionPlanAnalyzer;

// Enable query profiling
$profiler = new QueryProfilerService();
$profiler->startProfiling();

// Execute your queries
$users = $db->select('users', ['*'], ['status' => 'active']);

// Get profiling results
$results = $profiler->getResults();
foreach ($results as $result) {
    echo "Query: {$result['query']}\n";
    echo "Execution time: {$result['execution_time']}ms\n";
    echo "Memory usage: {$result['memory_usage']} bytes\n";
}

// Analyze query execution plans
$analyzer = new ExecutionPlanAnalyzer($connection);
$plan = $analyzer->analyze("SELECT * FROM users WHERE status = 'active'");
```

### Connection Pool Monitoring

```php
use Glueful\Database\ConnectionPoolManager;

// Get pool statistics
$poolManager = new ConnectionPoolManager();
$stats = $poolManager->getPoolStatistics();

echo "Active connections: {$stats['active_connections']}\n";
echo "Pool health: {$stats['health_status']}\n";
echo "Total queries: {$stats['total_queries']}\n";
```

## Database Logging and Monitoring

Glueful provides built-in database query logging:

```php
use Glueful\Database\QueryLogger;

// Enable query logging
$queryLogger = new QueryLogger();
$queryLogger->enableDebugMode();

// Later, check what queries were executed
$log = $queryLogger->getQueryLog();

// Get detailed query statistics
$stats = $queryLogger->getStatistics();
echo "Total queries: {$stats['total_queries']}\n";
echo "Average execution time: {$stats['avg_execution_time']}ms\n";
echo "Slowest query: {$stats['slowest_query_time']}ms\n";
```
