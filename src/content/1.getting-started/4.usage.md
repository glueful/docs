## Dependency Injection Container

Glueful's DI container is central to the framework architecture:

### Basic Usage

```php
// Accessing the global container
$container = container();

// Getting services
$userService = $container->get(UserService::class);
$database = $container->get(DatabaseInterface::class);
$cache = $container->get(CacheInterface::class);

// In controllers, services are injected automatically
class UserController extends BaseController
{
    public function __construct(
        private UserService $userService,
        private NotificationService $notificationService
    ) {}
}
```

### Service Providers

Register services using service providers:

```php
// api/DI/ServiceProviders/UserServiceProvider.php
class UserServiceProvider implements ServiceProviderInterface
{
    public function register(): void
    {
        $this->container->singleton(UserService::class, function($container) {
            return new UserService(
                $container->get(UserRepository::class),
                $container->get(CacheInterface::class)
            );
        });
    }
}

// Register in bootstrap.php
$providers = [
    \Glueful\DI\ServiceProviders\UserServiceProvider::class,
];
```

### Container Commands

```bash
# Validate container configuration
php glueful di:container:validate

# List registered services
php glueful di:container:services

# Debug container issues
php glueful di:container:debug
```

## Modern Routing System

Glueful's routing system supports PSR-15 middleware and OpenAPI documentation:

### Basic Routes with Authentication

```php
<?php
// routes/api.php

use Glueful\Core\Router;
use Glueful\Controllers\UserController;

// Public routes
Router::post('/auth/login', [AuthController::class, 'login']);
Router::post('/auth/register', [AuthController::class, 'register']);

// Protected routes
Router::get('/users', [UserController::class, 'index'], requiresAuth: true);
Router::post('/users', [UserController::class, 'store'], requiresAuth: true);
Router::get('/users/{uuid}', [UserController::class, 'show'], requiresAuth: true);
Router::put('/users/{uuid}', [UserController::class, 'update'], requiresAuth: true);
Router::delete('/users/{uuid}', [UserController::class, 'destroy'], requiresAuth: true);

// Admin-only routes
Router::group('/admin', function() {
    Router::get('/users', [AdminController::class, 'listUsers']);
    Router::post('/users', [AdminController::class, 'createUser']);
}, requiresAuth: true, requiresAdminAuth: true);
```

### OpenAPI Documentation

Use annotations for automatic API documentation:

```php
/**
 * @route GET /users
 * @summary List Users
 * @description Retrieve paginated list of users
 * @tag Users
 * @requiresAuth true
 * @param page query integer false "Page number"
 * @param limit query integer false "Items per page"
 * @response 200 application/json "Users retrieved successfully" {
 *   data:array="Array of user objects",
 *   pagination:object="Pagination metadata"
 * }
 * @response 401 "Unauthorized"
 */
public function index(Request $request): Response
{
    // Controller implementation
}
```

### Route Groups with Middleware

```php
// Routes with rate limiting
Router::group('/api/v1', function() {
    Router::get('/public-data', [PublicController::class, 'getData']);
}, middleware: ['rate-limit:60,1']);

// Routes with custom middleware
Router::group('/sensitive', function() {
    Router::get('/data', [SensitiveController::class, 'getData']);
}, middleware: ['auth', 'permission:admin', 'audit-log']);
```

## Session Management with TokenStorageService

Glueful uses dual-layer session storage (database + cache) for enterprise-grade session management:

### Basic Session Operations

```php
use Glueful\Auth\TokenStorageService;

$tokenStorage = container()->get(TokenStorageService::class);

// Store session with metadata
$sessionData = [
    'uuid' => $userUuid,
    'username' => $username,
    'email' => $email
];
$tokens = [
    'access_token' => $accessToken,
    'refresh_token' => $refreshToken
];
$success = $tokenStorage->storeSession($sessionData, $tokens);

// Retrieve and validate sessions
$session = $tokenStorage->getSessionByAccessToken($accessToken);
$isValid = $tokenStorage->isSessionValid($accessToken);

// Session management
$tokenStorage->revokeSession($accessToken);
$tokenStorage->revokeAllUserSessions($userUuid);
$cleanedCount = $tokenStorage->cleanupExpiredSessions();
```

### Advanced Session Features

```php
// Query builder for complex session queries
$queryBuilder = $tokenStorage->queryBuilder();
$activeSessions = $queryBuilder
    ->where(['user_uuid' => $userUuid])
    ->where(['is_active' => true])
    ->orderBy(['last_activity' => 'DESC'])
    ->get();

// Session analytics
$analytics = $tokenStorage->getSessionAnalytics($userUuid);
$securityMetrics = $tokenStorage->getSecurityMetrics();

// Bulk operations with transactions
$tokenStorage->setUseTransactions(true);
$result = $tokenStorage->bulkUpdateSessions($updates);
```

## Queue System

Process background jobs with the queue system:

### Dispatching Jobs

```php
use Glueful\Queue\QueueManager;

$queueManager = container()->get(QueueManager::class);

// Dispatch a job
$job = new SendEmailJob($userEmail, $emailData);
$queueManager->push($job);

// Dispatch with delay
$queueManager->later(300, $job); // 5 minutes delay

// Batch jobs
$jobs = [$job1, $job2, $job3];
$batchId = $queueManager->pushBatch($jobs);
```

### Queue Commands

```bash
# Process queue jobs
php glueful queue:work
php glueful queue:work --queue=high-priority

# Process batch jobs
php glueful queue:batch:process

# Monitor queue health
php glueful queue:health
php glueful queue:stats

# Handle failed jobs
php glueful queue:failed
php glueful queue:retry 123
php glueful queue:flush
```

## Making API Requests

Standard HTTP interactions with JWT authentication:

```bash
# Register user
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"john","email":"john@example.com","password":"secret123"}'

# Login to get JWT tokens
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{"username":"john","password":"secret123"}'

# Use access token for authenticated requests
curl -X GET http://localhost:8000/api/users \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"

# Create user with validation
curl -X POST http://localhost:8000/api/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -d '{"name":"John Doe","email":"john@example.com","role":"user"}'

# Refresh token when access token expires
curl -X POST http://localhost:8000/api/auth/refresh \
  -H "Authorization: Bearer YOUR_REFRESH_TOKEN"
```

## Admin Interface

The Glueful Admin Interface is available as an extension that you can install and enable:

```bash
# Install the Admin extension
php glueful extensions install Admin

# Enable the Admin extension
php glueful extensions enable Admin

# Configure the Admin extension (optional)
php glueful extensions configure Admin
```

After installation, you can customize the Admin Interface through the extension's configuration file located at `extensions/Admin/config.php`.

The Admin Interface provides:

- Dashboard analytics
- User management
- Extension management
- Configuration settings
- API exploration tools
- Logging and monitoring
- Scheduled task management
- Database management

Access the Admin Interface by navigating to `http://yourapp.com/admin` after installation and enabling the extension.
