This tutorial will guide you through creating your first modern API with Glueful. In just 15 minutes, you'll have a production-ready API with enterprise features.

## What We'll Build

We'll create a modern task management API featuring:

- JWT authentication with dual-layer session management
- CRUD operations using the repository pattern
- DI container integration
- Advanced input validation
- Automatic OpenAPI documentation
- Error handling with SecureErrorResponse
- Controller traits for reusable functionality

## Prerequisites

Before starting, ensure you have:

- PHP 8.2 or higher
- Composer
- MySQL or PostgreSQL
- A web server (Apache, Nginx, or PHP's built-in server)


## Step 4: Create Task Migration

```bash
# Create migration for tasks table
php glueful migrate:create CreateTasksTable
```

Edit the generated migration file in `database/migrations/`:

```php
<?php

use Glueful\Database\Migrations\MigrationInterface;
use Glueful\Database\Schema\Interfaces\SchemaBuilderInterface;

class CreateTasksTable implements MigrationInterface
{
    /**
     * Run the migration
     *
     * @param SchemaBuilderInterface $schema Database schema builder
     */
    public function up(SchemaBuilderInterface $schema): void
    {
        // Create tasks table with fluent interface
        $schema->createTable('tasks', function ($table) {
            // Primary key
            $table->bigInteger('id')->primary()->autoIncrement();
            
            // Core columns
            $table->string('uuid', 12)->unique();
            $table->string('user_uuid', 12);
            $table->string('title', 255);
            $table->text('description')->nullable();
            $table->enum('status', ['pending', 'in_progress', 'completed'])->default('pending');
            $table->enum('priority', ['low', 'medium', 'high'])->default('medium');
            $table->date('due_date')->nullable();
            $table->timestamp('completed_at')->nullable();
            
            // Timestamps
            $table->timestamp('created_at')->default('CURRENT_TIMESTAMP');
            $table->timestamp('updated_at')->nullable();
            
            // Indexes
            $table->index('user_uuid');
            $table->index('status');
            $table->index('due_date');
            $table->index('created_at');
        });

        // Add foreign key constraint
        $schema->table('tasks')
            ->foreign('user_uuid')
            ->references('uuid')
            ->on('users')
            ->onDelete('CASCADE');
    }

    /**
     * Reverse the migration
     *
     * @param SchemaBuilderInterface $schema Database schema builder
     */
    public function down(SchemaBuilderInterface $schema): void
    {
        // Drop table
        $schema->dropTable('tasks');
    }

    /**
     * Get migration description
     *
     * @return string Migration description
     */
    public function getDescription(): string
    {
        return 'Creates tasks table for user task management with priority and completion tracking';
    }
}
```

## Step 5: Create Task Repository and Service

First, create a repository for data access:

```php
// api/Repository/TaskRepository.php
<?php

declare(strict_types=1);

namespace Glueful\Repository;

use Glueful\Database\Connection;
use Glueful\Helpers\Utils;

class TaskRepository extends BaseRepository
{
    /**
     * Get the table name for this repository
     *
     * @return string The table name
     */
    public function getTableName(): string
    {
        return 'tasks';
    }

    /**
     * Find tasks by user UUID with optional filtering
     *
     * @param string $userUuid User UUID to find tasks for
     * @param array $filters Optional filters (status, priority)
     * @return array Array of task records
     */
    public function findByUserUuid(string $userUuid, array $filters = []): array
    {
        $query = $this->db->table($this->table)
            ->select($this->defaultFields)
            ->where(['user_uuid' => $userUuid]);
        
        if (isset($filters['status'])) {
            $query->where(['status' => $filters['status']]);
        }
        
        if (isset($filters['priority'])) {
            $query->where(['priority' => $filters['priority']]);
        }
        
        return $query->orderBy(['created_at' => 'DESC'])->get();
    }
    
    /**
     * Find task by UUID and user UUID
     *
     * @param string $uuid Task UUID
     * @param string $userUuid User UUID (for security)
     * @return array|null Task record or null if not found
     */
    public function findByUuidAndUser(string $uuid, string $userUuid): ?array
    {
        $results = $this->db->table($this->table)
            ->select($this->defaultFields)
            ->where([
                'uuid' => $uuid,
                'user_uuid' => $userUuid
            ])
            ->limit(1)
            ->get();
        
        return !empty($results) ? $results[0] : null;
    }
    
    /**
     * Create a new task
     *
     * @param array $data Task data
     * @return string Task UUID
     */
    public function createTask(array $data): string
    {
        // Set completion timestamp if status is completed
        if (isset($data['status']) && $data['status'] === 'completed' && !isset($data['completed_at'])) {
            $data['completed_at'] = $this->db->getDriver()->formatDateTime();
        }
        
        // Use parent create method which handles UUID generation and timestamps
        return $this->create($data);
    }
    
    /**
     * Update task by UUID and user UUID (for security)
     *
     * @param string $uuid Task UUID
     * @param string $userUuid User UUID (for security)
     * @param array $data Updated task data
     * @return bool Success status
     */
    public function updateByUuidAndUser(string $uuid, string $userUuid, array $data): bool
    {
        // Set completion timestamp if status is being set to completed
        if (isset($data['status']) && $data['status'] === 'completed' && !isset($data['completed_at'])) {
            $data['completed_at'] = $this->db->getDriver()->formatDateTime();
        }
        
        // First verify the task belongs to the user
        $existingTask = $this->findByUuidAndUser($uuid, $userUuid);
        if (!$existingTask) {
            return false;
        }
        
        // Use parent update method which handles updated_at timestamp
        return $this->update($uuid, $data);
    }

    /**
     * Delete task by UUID and user UUID (for security)
     *
     * @param string $uuid Task UUID
     * @param string $userUuid User UUID (for security)
     * @return bool Success status
     */
    public function deleteByUuidAndUser(string $uuid, string $userUuid): bool
    {
        // First verify the task belongs to the user
        $existingTask = $this->findByUuidAndUser($uuid, $userUuid);
        if (!$existingTask) {
            return false;
        }
        
        // Use parent delete method
        return $this->delete($uuid);
    }
}
```

Create a service for business logic:

```php
// api/Services/TaskService.php
<?php

namespace Glueful\Services;

use Glueful\Repository\TaskRepository;
use Glueful\Validation\ValidationHelper;
use Glueful\Exceptions\BusinessLogicException;
use Glueful\Http\ErrorCodes;

class TaskService
{
    public function __construct(
        private TaskRepository $taskRepository,
        private ValidationHelper $validator
    ) {}
    
    public function getUserTasks(string $userUuid, array $filters = []): array
    {
        return $this->taskRepository->findByUserUuid($userUuid, $filters);
    }
    
    public function getTask(string $uuid, string $userUuid): array
    {
        $task = $this->taskRepository->findByUuidAndUser($uuid, $userUuid);
        
        if (!$task) {
            throw new BusinessLogicException('Task not found', ErrorCodes::NOT_FOUND);
        }
        
        return $task;
    }
    
    public function createTask(array $data, string $userUuid): string
    {
        // Validate input
        $this->validator->validateRequired($data, ['title']);
        
        if (empty(trim($data['title']))) {
            throw new BusinessLogicException('Title cannot be empty', ErrorCodes::BAD_REQUEST);
        }
        
        // Prepare task data
        $taskData = [
            'user_uuid' => $userUuid,
            'title' => trim($data['title']),
            'description' => $data['description'] ?? null,
            'priority' => $data['priority'] ?? 'medium',
            'status' => 'pending',
            'due_date' => $data['due_date'] ?? null
        ];
        
        // Validate priority
        if (!in_array($taskData['priority'], ['low', 'medium', 'high'])) {
            throw new BusinessLogicException('Invalid priority value', ErrorCodes::BAD_REQUEST);
        }
        
        return $this->taskRepository->createTask($taskData);
    }
    
    public function updateTask(string $uuid, array $data, string $userUuid): array
    {
        // Verify task exists
        $task = $this->getTask($uuid, $userUuid);
        
        // Validate status if provided
        if (isset($data['status']) && !in_array($data['status'], ['pending', 'in_progress', 'completed'])) {
            throw new BusinessLogicException('Invalid status value', ErrorCodes::BAD_REQUEST);
        }
        
        // Update task
        $success = $this->taskRepository->updateByUuidAndUser($uuid, $userUuid, $data);
        
        if (!$success) {
            throw new BusinessLogicException('Failed to update task', ErrorCodes::INTERNAL_ERROR);
        }
        
        return $this->getTask($uuid, $userUuid);
    }
    
    public function deleteTask(string $uuid, string $userUuid): bool
    {
        // Verify task exists and delete it
        return $this->taskRepository->deleteByUuidAndUser($uuid, $userUuid);
    }
}
```

## Step 6: Create Modern Task Controller

Now create the controller using the DI container and service layer:

```php
<?php
// api/Controllers/TaskController.php

declare(strict_types=1);

namespace Glueful\Controllers;

use Glueful\Controllers\BaseController;
use Glueful\Http\Response;
use Glueful\Services\TaskService;
use Glueful\Exceptions\ValidationException;
use Symfony\Component\HttpFoundation\Request;

class TaskController extends BaseController
{
    public function __construct(
        private TaskService $taskService
    ) {
        parent::__construct();
    }

    /**
     * @route GET /tasks
     * @summary Get User Tasks
     * @description Retrieve all tasks for the authenticated user with optional filtering
     * @tag Tasks
     * @requiresAuth true
     * @param status query string false "Filter by status: pending, in_progress, completed"
     * @param priority query string false "Filter by priority: low, medium, high"
     * @response 200 application/json "Tasks retrieved successfully" {
     *   success:boolean="Success status",
     *   data:array="Array of task objects",
     *   message:string="Success message"
     * }
     * @response 401 "Authentication required"
     */
    public function index(Request $request): Response
    {
        try {
            // Authentication is handled automatically by BaseController
            if (!$this->currentUser) {
                return $this->unauthorized('Authentication required');
            }
            
            // Get pagination parameters
            $page = (int) $request->query->get('page', 1);
            $perPage = (int) $request->query->get('per_page', 25);
            
            // Get filter parameters from query string
            $filters = [];
            if ($status = $request->query->get('status')) {
                $filters['status'] = $status;
            }
            if ($priority = $request->query->get('priority')) {
                $filters['priority'] = $priority;
            }
            
            // Get paginated tasks using repository
            $taskRepository = $this->repositoryFactory->getRepository('tasks');
            $conditions = array_merge(['user_uuid' => $this->currentUser['uuid']], $filters);
            $orderBy = ['created_at' => 'DESC'];
            
            $paginatedResult = $taskRepository->paginate($page, $perPage, $conditions, $orderBy);
            
            // Extract data and metadata
            $data = $paginatedResult['data'] ?? [];
            $meta = $paginatedResult;
            unset($meta['data']); // Remove data from meta to avoid duplication
            
            return Response::successWithMeta($data, $meta, 'Tasks retrieved successfully');
            
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }

    /**
     * @route POST /tasks
     * @summary Create New Task
     * @description Create a new task for the authenticated user
     * @tag Tasks
     * @requiresAuth true
     * @param title body string true "Task title"
     * @param description body string false "Task description"
     * @param priority body string false "Task priority: low, medium, high"
     * @param due_date body string false "Due date (YYYY-MM-DD)"
     * @response 201 application/json "Task created successfully" {
     *   success:boolean="Success status",
     *   data:object="Created task object",
     *   message:string="Success message"
     * }
     * @response 400 "Validation error"
     * @response 401 "Authentication required"
     */
    public function store(Request $request): Response
    {
        try {
            if (!$this->currentUser) {
                return $this->unauthorized('Authentication required');
            }
            
            $data = $this->getRequestData();
            
            // Validate required fields
            $validationError = $this->validateRequest($data, [
                'title' => 'required|max:255'
            ]);
            if ($validationError) {
                return $validationError;
            }
            
            // Create task using service layer
            $taskUuid = $this->taskService->createTask($data, $this->currentUser['uuid']);
            
            // Get the created task
            $task = $this->taskService->getTask($taskUuid, $this->currentUser['uuid']);
            
            return $this->created([
                'data' => $task
            ], 'Task created successfully');
            
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }

    /**
     * @route GET /tasks/{uuid}
     * @summary Get Single Task
     * @description Get a specific task by UUID
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task found" {
     *   success:boolean="Success status",
     *   data:object="Task object",
     *   message:string="Success message"
     * }
     * @response 404 "Task not found"
     * @response 401 "Authentication required"
     */
    public function show(Request $request, string $uuid): Response
    {
        try {
            if (!$this->currentUser) {
                return $this->unauthorized('Authentication required');
            }
            
            $task = $this->taskService->getTask($uuid, $this->currentUser['uuid']);
            
            return $this->success($task, 'Task retrieved successfully');
            
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }

    /**
     * @route PUT /tasks/{uuid}
     * @summary Update Task
     * @description Update an existing task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @param title body string false "Task title"
     * @param description body string false "Task description"
     * @param status body string false "Task status: pending, in_progress, completed"
     * @param priority body string false "Task priority: low, medium, high"
     * @param due_date body string false "Due date (YYYY-MM-DD)"
     * @response 200 application/json "Task updated successfully" {
     *   success:boolean="Success status",
     *   data:object="Updated task object",
     *   message:string="Success message"
     * }
     * @response 400 "Validation error"
     * @response 404 "Task not found"
     * @response 401 "Authentication required"
     */
    public function update(Request $request, string $uuid): Response
    {
        try {
            if (!$this->currentUser) {
                return $this->unauthorized('Authentication required');
            }
            
            $data = $this->getPutData();
            
            // Update task using service layer
            $task = $this->taskService->updateTask($uuid, $data, $this->currentUser['uuid']);
            
            return $this->success($task, 'Task updated successfully');
            
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }

    /**
     * @route DELETE /tasks/{uuid}
     * @summary Delete Task
     * @description Delete a task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task deleted successfully" {
     *   success:boolean="Success status",
     *   message:string="Success message"
     * }
     * @response 404 "Task not found"
     * @response 401 "Authentication required"
     */
    public function delete(Request $request, string $uuid): Response
    {
        try {
            if (!$this->currentUser) {
                return $this->unauthorized('Authentication required');
            }
            
            $success = $this->taskService->deleteTask($uuid, $this->currentUser['uuid']);
            
            if (!$success) {
                return $this->serverError('Failed to delete task');
            }
            
            return $this->success(null, 'Task deleted successfully');
            
        } catch (\Exception $e) {
            return $this->handleException($e);
        }
    }
}
```

## Step 7: Register Services in DI Container

Create a service provider using Glueful's clean abstraction over the DI container:

```php
// api/DI/ServiceProviders/TaskServiceProvider.php
<?php

declare(strict_types=1);

namespace Glueful\DI\ServiceProviders;

use Glueful\DI\ServiceProviders\BaseServiceProvider;
use Glueful\Services\TaskService;
use Glueful\Repository\TaskRepository;
use Glueful\Controllers\TaskController;

/**
 * Task Service Provider
 *
 * Registers all task-related services using Glueful's clean DI abstraction.
 */
class TaskServiceProvider extends BaseServiceProvider
{
    protected function registerServices(): void
    {
        // Register TaskRepository as singleton
        $this->service(TaskRepository::class, TaskRepository::class, [
            $this->ref('database')
        ]);

        // Register TaskService as singleton  
        $this->service(TaskService::class, TaskService::class, [
            $this->ref(TaskRepository::class),
            $this->ref(\Glueful\Validation\ValidationHelper::class)
        ]);

        // Register TaskController
        $this->service(TaskController::class, TaskController::class, [
            $this->ref(TaskService::class)
        ]);

        // Add convenience aliases
        $this->alias('repository.task', TaskRepository::class);
        $this->alias('service.task', TaskService::class);
        $this->alias('controller.task', TaskController::class);
    }

    public function getName(): string
    {
        return 'task';
    }
}
```

**Key Benefits of This Approach:**
- **Clean API**: No direct Symfony DI exposure
- **Simple Methods**: `service()`, `singleton()`, `alias()`, `ref()`
- **Readable**: Clear dependency relationships
- **Maintainable**: Easier to understand and modify

The service provider is automatically loaded and registered through the DI system. All your services are now available throughout the application with automatic dependency injection.

## Step 8: Define Routes

Create a new route file for your task routes. Create `routes/tasks.php`:

```php
<?php

use Glueful\Http\Router;
use Glueful\Controllers\TaskController;
use Symfony\Component\HttpFoundation\Request;

// Get the container from the global app() helper
$container = app();

// Task routes (all require authentication)
Router::group('/tasks', function () use ($container) {
    /**
     * @route GET /tasks
     * @summary Get User Tasks
     * @description Retrieve all tasks for the authenticated user with optional filtering
     * @tag Tasks
     * @requiresAuth true
     * @param page query integer false "Page number for pagination"
     * @param per_page query integer false "Number of items per page"
     * @param status query string false "Filter by status: pending, in_progress, completed"
     * @param priority query string false "Filter by priority: low, medium, high"
     * @response 200 application/json "Tasks retrieved successfully"
     */
    Router::get('/', function (Request $request) use ($container) {
        $taskController = $container->get(TaskController::class);
        return $taskController->index($request);
    });

    /**
     * @route POST /tasks
     * @summary Create New Task
     * @description Create a new task for the authenticated user
     * @tag Tasks
     * @requiresAuth true
     * @requestBody title:string="Task title" description:string="Task description" priority:string="Task priority" due_date:string="Due date" {required=title}
     * @response 201 application/json "Task created successfully"
     */
    Router::post('/', function (Request $request) use ($container) {
        $taskController = $container->get(TaskController::class);
        return $taskController->store($request);
    });

    /**
     * @route GET /tasks/{uuid}
     * @summary Get Single Task
     * @description Get a specific task by UUID
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task found"
     */
    Router::get('/{uuid}', function (Request $request, string $uuid) use ($container) {
        $taskController = $container->get(TaskController::class);
        return $taskController->show($request, $uuid);
    });

    /**
     * @route PUT /tasks/{uuid}
     * @summary Update Task
     * @description Update an existing task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @requestBody title:string="Task title" description:string="Task description" status:string="Task status" priority:string="Task priority" due_date:string="Due date"
     * @response 200 application/json "Task updated successfully"
     */
    Router::put('/{uuid}', function (Request $request, string $uuid) use ($container) {
        $taskController = $container->get(TaskController::class);
        return $taskController->update($request, $uuid);
    });

    /**
     * @route DELETE /tasks/{uuid}
     * @summary Delete Task
     * @description Delete a task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task deleted successfully"
     */
    Router::delete('/{uuid}', function (Request $request, string $uuid) use ($container) {
        $taskController = $container->get(TaskController::class);
        return $taskController->delete($request, $uuid);
    });
});
```

**Key Features of This Routing Pattern:**
- **DI Container Integration**: Uses `app()` to get the container and resolve controllers
- **Closure-Based Routes**: Follows current Glueful patterns with closures instead of controller arrays
- **OpenAPI Documentation**: Includes comprehensive API documentation annotations
- **Request Injection**: Properly injects `Request` objects and route parameters
- **Authentication**: All routes are within an authenticated group
- **RESTful Design**: Clean REST API endpoints with proper HTTP methods

## Common Issues

### Database Connection Error

Ensure your database credentials in `.env` are correct and the database exists.

### Authentication Issues

Make sure you're including the `Authorization: Bearer {token}` header in requests to protected endpoints.

### Permission Denied

Check that your web server has write permissions to the `storage/` directory.

### Port Already in Use

If port 8000 is busy, try: `php -S localhost:8001 -t .`
