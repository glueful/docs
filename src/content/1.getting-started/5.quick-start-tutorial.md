This tutorial will guide you through creating your first API with Glueful. In just 15 minutes, you'll have a working API with authentication, database operations, and automatic documentation.

## What We'll Build

We'll create a simple task management API with:

- User authentication (JWT)
- CRUD operations for tasks
- User authorization
- Automatic API documentation
- Input validation

## Prerequisites

Before starting, ensure you have:

- PHP 8.2 or higher
- Composer
- MySQL or PostgreSQL
- A web server (Apache, Nginx, or PHP's built-in server)

## Step 1: Create a New Project

```bash
# Clone the Glueful starter project
git clone https://github.com/glueful/glueful.git my-task-api
cd my-task-api

# Install dependencies
composer install
```

## Step 2: Configure Environment

```bash
# Copy the environment template
cp .env.example .env
```

Edit your `.env` file with your database credentials:

```env
# Application
APP_NAME="Task API"
APP_ENV=development
APP_DEBUG=true

# Database
DB_DRIVER=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=task_api
DB_USERNAME=your_username
DB_PASSWORD=your_password

# JWT Security
JWT_KEY=your-super-secret-jwt-key-here
```

## Step 3: Set Up Database

Create your database:

```bash
# Create the database
mysql -u root -p -e "CREATE DATABASE task_api;"

# Run migrations to set up core tables
php glueful db:migrate
```

## Step 4: Create Our First Migration

```bash
# Generate a migration for tasks table
php glueful migrate:create create_tasks_table
```

Edit the generated migration file in `database/migrations/`:

```php
<?php

use Glueful\Database\Migrations\MigrationInterface;
use Glueful\Database\Schema\SchemaManager;

class CreateTasksTable implements MigrationInterface
{
    /**
     * Execute the migration
     *
     * @param SchemaManager $schema Database schema manager
     */
    public function up(SchemaManager $schema): void
    {
        $schema->createTable('tasks', [
            'id' => 'BIGINT PRIMARY KEY AUTO_INCREMENT',
            'uuid' => 'CHAR(12) NOT NULL',
            'user_uuid' => 'CHAR(12) NOT NULL',
            'title' => 'VARCHAR(255) NOT NULL',
            'description' => 'TEXT NULL',
            'status' => "ENUM('pending', 'in_progress', 'completed') DEFAULT 'pending'",
            'due_date' => 'DATE NULL',
            'created_at' => 'TIMESTAMP DEFAULT CURRENT_TIMESTAMP',
            'updated_at' => 'TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP'
        ])->addIndex([
            ['type' => 'UNIQUE', 'column' => 'uuid'],
            ['type' => 'INDEX', 'column' => 'user_uuid'],
            ['type' => 'INDEX', 'column' => 'status']
        ])->addForeignKey([
            [
                'column' => 'user_uuid',
                'references' => 'uuid',
                'on' => 'users',
                'onDelete' => 'CASCADE'
            ]
        ]);
    }

    /**
     * Reverse the migration
     *
     * @param SchemaManager $schema Database schema manager
     */
    public function down(SchemaManager $schema): void
    {
        $schema->dropTable('tasks');
    }

    /**
     * Get migration description
     *
     * @return string Migration description
     */
    public function getDescription(): string
    {
        return 'Creates tasks table for user task management';
    }
}
```

Run the migration:

```bash
php glueful db:migrate
```

## Step 5: Create the Task Controller

```bash
# Generate a controller
php glueful generate:controller TaskController
```

Edit `api/Controllers/TaskController.php`:

```php
<?php

namespace Glueful\Controllers;

use Glueful\Http\Controller;
use Glueful\Http\Response;
use Glueful\Database\QueryBuilder;
use Glueful\Auth\AuthBootstrap;
use Glueful\Helpers\Request;
use Glueful\Helpers\Utils;
use Glueful\Helpers\DatabaseConnectionTrait;
use Symfony\Component\HttpFoundation\Request as SymfonyRequest;

class TaskController extends Controller
{
    use DatabaseConnectionTrait;

    private QueryBuilder $db;

    public function __construct()
    {
        $this->db = $this->getQueryBuilder();
    }

    /**
     * @route GET /tasks
     * @summary Get User Tasks
     * @description Retrieve all tasks for the authenticated user
     * @tag Tasks
     * @requiresAuth true
     * @response 200 application/json "Tasks retrieved successfully"
     */
    public function index(SymfonyRequest $request)
    {
        // Authenticate user
        $user = AuthBootstrap::getManager()->authenticateWithProviders(['jwt', 'api_key']);

        if (!$user) {
            return Response::unauthorized(['message' => 'Authentication required'])->send();
        }

        // Get all tasks for this user using BaseRepository pattern
        $tasks = $this->db->select('tasks', ['*'], ['user_uuid' => $user['uuid']]);

        return Response::ok([
            'data' => $tasks,
            'message' => 'Tasks retrieved successfully'
        ])->send();
    }

    /**
     * @route POST /tasks
     * @summary Create New Task
     * @description Create a new task for the authenticated user
     * @tag Tasks
     * @requiresAuth true
     * @param title body string true "Task title"
     * @param description body string false "Task description"
     * @param due_date body string false "Due date (YYYY-MM-DD)"
     * @response 201 application/json "Task created successfully"
     */
    public function store(SymfonyRequest $request)
    {
        // Authenticate user
        $user = AuthBootstrap::getManager()->authenticateWithProviders(['jwt', 'api_key']);

        if (!$user) {
            return Response::unauthorized(['message' => 'Authentication required'])->send();
        }

        // Get request data
        $data = Request::getPostData();

        // Validate required fields
        if (!isset($data['title']) || empty(trim($data['title']))) {
            return Response::error('Title is required', Response::HTTP_BAD_REQUEST)->send();
        }

        // Create task data
        $taskData = [
            'uuid' => Utils::generateUuid(),
            'user_uuid' => $user['uuid'],
            'title' => trim($data['title']),
            'description' => $data['description'] ?? null,
            'status' => 'pending',
            'due_date' => $data['due_date'] ?? null,
            'created_at' => date('Y-m-d H:i:s'),
            'updated_at' => date('Y-m-d H:i:s')
        ];

        // Insert using BaseRepository pattern
        $this->db->insert('tasks', $taskData);

        return Response::created([
            'data' => $taskData,
            'message' => 'Task created successfully'
        ])->send();
    }

    /**
     * @route GET /tasks/{uuid}
     * @summary Get Single Task
     * @description Get a specific task by UUID
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task found"
     * @response 404 application/json "Task not found"
     */
    public function show(SymfonyRequest $request, $uuid)
    {
        // Authenticate user
        $user = AuthBootstrap::getManager()->authenticateWithProviders(['jwt', 'api_key']);

        if (!$user) {
            return Response::unauthorized(['message' => 'Authentication required'])->send();
        }

        // Find the task using BaseRepository pattern
        $tasks = $this->db->select('tasks', ['*'], [
            'uuid' => $uuid,
            'user_uuid' => $user['uuid']
        ]);

        if (empty($tasks)) {
            return Response::error('Task not found', Response::HTTP_NOT_FOUND)->send();
        }

        return Response::ok([
            'data' => $tasks[0],
            'message' => 'Task found'
        ])->send();
    }

    /**
     * @route PUT /tasks/{uuid}
     * @summary Update Task
     * @description Update an existing task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task updated successfully"
     */
    public function update(SymfonyRequest $request, $uuid)
    {
        // Authenticate user
        $user = AuthBootstrap::getManager()->authenticateWithProviders(['jwt', 'api_key']);

        if (!$user) {
            return Response::unauthorized(['message' => 'Authentication required'])->send();
        }

        // Get request data
        $data = Request::getPostData();

        // Check if task exists and belongs to user
        $tasks = $this->db->select('tasks', ['*'], [
            'uuid' => $uuid,
            'user_uuid' => $user['uuid']
        ]);

        if (empty($tasks)) {
            return Response::error('Task not found', Response::HTTP_NOT_FOUND)->send();
        }

        // Build update data
        $updateData = ['updated_at' => date('Y-m-d H:i:s')];

        if (isset($data['title'])) {
            $updateData['title'] = trim($data['title']);
        }

        if (isset($data['description'])) {
            $updateData['description'] = $data['description'];
        }

        if (isset($data['status'])) {
            $updateData['status'] = $data['status'];
        }

        if (isset($data['due_date'])) {
            $updateData['due_date'] = $data['due_date'];
        }

        // Update using BaseRepository pattern
        $this->db->update('tasks', $updateData, [
            'uuid' => $uuid,
            'user_uuid' => $user['uuid']
        ]);

        // Return updated task
        $updatedTasks = $this->db->select('tasks', ['*'], ['uuid' => $uuid]);

        return Response::ok([
            'data' => $updatedTasks[0],
            'message' => 'Task updated successfully'
        ])->send();
    }

    /**
     * @route DELETE /tasks/{uuid}
     * @summary Delete Task
     * @description Delete a task
     * @tag Tasks
     * @requiresAuth true
     * @param uuid path string true "Task UUID"
     * @response 200 application/json "Task deleted successfully"
     */
    public function delete(SymfonyRequest $request, $uuid)
    {
        // Authenticate user
        $user = AuthBootstrap::getManager()->authenticateWithProviders(['jwt', 'api_key']);

        if (!$user) {
            return Response::unauthorized(['message' => 'Authentication required'])->send();
        }

        // Check if task exists and belongs to user
        $tasks = $this->db->select('tasks', ['*'], [
            'uuid' => $uuid,
            'user_uuid' => $user['uuid']
        ]);

        if (empty($tasks)) {
            return Response::error('Task not found', Response::HTTP_NOT_FOUND)->send();
        }

        // Delete using BaseRepository pattern
        $this->db->delete('tasks', [
            'uuid' => $uuid,
            'user_uuid' => $user['uuid']
        ]);

        return Response::ok(['message' => 'Task deleted successfully'])->send();
    }
}
```

## Step 6: Define Routes

Edit `routes/api.php` to add our task routes:

```php
<?php

use Glueful\Http\Router;
use Glueful\Controllers\AuthController;
use Glueful\Controllers\TaskController;

$authController = new AuthController();
$taskController = new TaskController();

// Authentication routes
Router::group('/auth', function() use ($authController) {
    Router::post('/login', [$authController, 'login']);
    Router::post('/register', [$authController, 'register']);
    Router::post('/logout', [$authController, 'logout'], requiresAuth: true);
    Router::post('/refresh', [$authController, 'refresh'], requiresAuth: true);
});

// Task routes (all require authentication)
Router::group('/tasks', function() use ($taskController) {
    Router::get('/', [$taskController, 'index']);
    Router::post('/', [$taskController, 'store']);
    Router::get('/{uuid}', [$taskController, 'show']);
    Router::put('/{uuid}', [$taskController, 'update']);
    Router::delete('/{uuid}', [$taskController, 'delete']);
}, requiresAuth: true);
```

Your API is now running at `http://localhost:8000`!

## Step 8: Test Your API

### 1. Register a User

```bash
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "email": "test@example.com",
    "password": "password123"
  }'
```

### 2. Login to Get Token

```bash
curl -X POST http://localhost:8000/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "testuser",
    "password": "password123"
  }'
```

Save the `access_token` from the response.

### 3. Create a Task

```bash
curl -X POST http://localhost:8000/api/tasks \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -d '{
    "title": "Learn Glueful",
    "description": "Complete the quick start tutorial",
    "due_date": "2024-01-31"
  }'
```

Save the `uuid` from the response for the next steps.

### 4. Get All Tasks

```bash
curl -X GET http://localhost:8000/api/tasks \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### 5. Get a Specific Task

```bash
curl -X GET http://localhost:8000/api/tasks/TASK_UUID \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

### 6. Update a Task

```bash
curl -X PUT http://localhost:8000/api/tasks/TASK_UUID \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN" \
  -d '{
    "status": "completed"
  }'
```

### 7. Delete a Task

```bash
curl -X DELETE http://localhost:8000/api/tasks/TASK_UUID \
  -H "Authorization: Bearer YOUR_ACCESS_TOKEN"
```

## Common Issues

### Database Connection Error

Ensure your database credentials in `.env` are correct and the database exists.

### Authentication Issues

Make sure you're including the `Authorization: Bearer {token}` header in requests to protected endpoints.

### Permission Denied

Check that your web server has write permissions to the `storage/` directory.

### Port Already in Use

If port 8000 is busy, try: `php -S localhost:8001 -t .`
