Glueful is a modern, enterprise-grade PHP API framework designed for building secure, scalable, and high-performance applications. Built with PHP 8.2+ and leveraging cutting-edge development practices, Glueful provides a comprehensive toolkit for professional API development with minimal configuration overhead.

## Why Glueful

Glueful combines the best aspects of modern PHP development with enterprise-ready features that prioritize:

- **Developer productivity** - Interactive setup wizard and powerful CLI tools get you running in minutes
- **Enterprise-grade architecture** - Production-ready features including connection pooling, queue systems, and advanced caching
- **Security by default** - Multi-layered security with CSRF protection, adaptive rate limiting, and secure session management
- **Performance optimized** - Built-in memory management, query optimization, and performance profiling tools
- **API-first design** - Automatic OpenAPI/Swagger documentation with built-in API exploration tools
- **Extensibility** - High-performance Extension System v2.0 with 50x faster loading

## Core Features

Glueful offers a comprehensive set of enterprise-ready features:

### Foundation

- **Modern PHP 8.2+ architecture** with attributes, typed properties, enums, and constructor property promotion
- **Powerful Dependency Injection (DI) container** with service providers and automatic resolution
- **Advanced routing system** with PSR-15 middleware support and OpenAPI annotations
- **Request Context architecture** eliminating superglobal dependencies
- **Smart environment-aware configuration** with automatic production hardening

### API Development

- **RESTful API endpoints** with automatic OpenAPI/Swagger documentation generation
- **Multi-layer request validation** with centralized ValidationHelper
- **Standardized error handling** with SecureErrorResponse for production safety
- **Adaptive rate limiting** with behavior analysis and suspicious activity detection
- **Advanced CORS support** with environment-aware defaults
- **Controller traits system** for reusable functionality (authorization, caching, auditing)

### Database & Performance

- **Connection pooling** with health monitoring and automatic maintenance
- **Advanced QueryBuilder** with JSON support and bulk operations
- **Database-agnostic migrations** with rollback support
- **Repository pattern** with BaseRepository for consistent data access
- **N+1 query prevention** and automatic query optimization
- **ChunkedDatabaseProcessor** for memory-efficient bulk operations
- **Transaction management** with UnitOfWork pattern

### Security & Authentication

- **JWT-based authentication** with dual-layer session storage (database + cache)
- **TokenStorageService** for advanced session management with analytics
- **Role-based access control (RBAC)** with fine-grained permissions
- **CSRF protection middleware** with automatic token management
- **Security headers** with production-ready defaults
- **Audit logging** with async processing and category batching
- **Lockdown mode** for emergency security response

### Enterprise Systems

- **Queue system** with multiple drivers and batch processing
- **Multi-channel notification system** with templates and retry logic
- **Archive system** for data retention and compliance
- **Task scheduling** with cron-based job management
- **Performance monitoring** with MemoryManager and profiling tools
- **Health checks** and system diagnostics

### Developer Experience

- **Interactive installation wizard** with guided setup
- **Comprehensive CLI tools** for all system management tasks
- **Extension System v2.0** with hot-reloading and performance optimization
- **Built-in testing infrastructure** with unit and integration test support
- **Code quality tools** integration (PHPStan, PHPCS)
- **Production readiness tools** with security auditing

## Philosophy

Glueful is built on four core principles:

1. **Simplicity without compromise** - Powerful enterprise features with minimal configuration complexity
2. **Security-first design** - Every feature is built with security as the primary consideration
3. **Performance at scale** - Optimized for high-traffic production environments
4. **Developer happiness** - Intuitive APIs, comprehensive tooling, and excellent documentation

Whether you're building a startup MVP or an enterprise-scale application, Glueful provides battle-tested tools and patterns that grow with your needs.
