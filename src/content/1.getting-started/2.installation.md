This guide will help you install and set up your Glueful application.

## System Requirements

### Minimum Requirements

- **PHP**: 8.2 or higher
- **Memory**: 512MB RAM minimum, 1GB recommended
- **Disk Space**: 100MB for framework + your application data
- **Database**: MySQL 5.7+, PostgreSQL 12+, or SQLite 3.8+
- **Web Server**: Apache 2.4+, Nginx 1.18+, or PHP built-in server

### Required PHP Extensions

Glueful requires the following PHP extensions:

```bash
# Core extensions (usually included)
- json
- mbstring
- openssl
- PDO
- curl
- xml
- zip

# Database extensions (choose based on your database)
- pdo_mysql     # For MySQL/MariaDB
- pdo_pgsql     # For PostgreSQL
- pdo_sqlite    # For SQLite

# Optional but recommended
- redis         # For Redis caching
- memcached     # For Memcached caching
- bcmath        # For precise decimal calculations
- gd            # For image processing
- intl          # For internationalization
```

### Checking Your System

Verify your system meets the requirements:

```bash
# Check PHP version and extensions
php -v
php -m | grep -E "(json|mbstring|openssl|PDO|curl|xml|zip)"

# Check available memory
php -r "echo 'Memory Limit: ' . ini_get('memory_limit') . PHP_EOL;"

# Check if Composer is installed
composer --version
```

For a comprehensive system check after installation, use Glueful's built-in system check command:

```bash
# Run comprehensive system validation
php glueful system:check

# Detailed information with recommendations
php glueful system:check --verbose

# Check production readiness
php glueful system:check --production
```

## Installation Methods

### Method 1: Interactive Setup Wizard (Recommended)

Glueful provides an intelligent installation wizard that handles all setup tasks:

**Option A: Using Composer (Recommended)**
```bash
# Create a new Glueful project
composer create-project glueful/glueful my-project
cd my-project

# Run the interactive setup wizard
php glueful install
```

**Option B: Using Git Clone**
```bash
# Clone the Glueful repository
git clone https://github.com/glueful/glueful.git my-project
cd my-project

# Install dependencies
composer install

# Run the interactive setup wizard
php glueful install
```

The install wizard guides you through:

- Environment file creation with smart defaults
- Secure key generation (APP_KEY, JWT_KEY, TOKEN_SALT)
- Database connection setup and validation
- Database migrations and initial schema
- DI container initialization
- Cache warming and optimization
- API documentation generation
- Optional admin user creation
- Production readiness check

**Advanced install options:**

```bash
# Skip specific steps
php glueful install --skip-admin     # Skip admin user creation
php glueful install --skip-db        # Skip database setup
php glueful install --skip-keys      # Skip key generation
php glueful install --skip-cache     # Skip cache initialization

# Force reinstall or quiet mode
php glueful install --force          # Overwrite existing configurations
php glueful install --quiet          # Non-interactive mode using environment variables

# Quiet mode for CI/CD (set environment variables first)
export ADMIN_USERNAME="admin"
export ADMIN_EMAIL="admin@company.com" 
export ADMIN_PASSWORD="secure_password123"
php glueful install --quiet --skip-admin  # Skip admin if not needed
```

### Method 2: Web Setup Wizard (Browser-based)

For users who prefer a graphical interface, Glueful includes a web-based setup wizard:

**Step 1: Initial Setup**
```bash
# Create a new Glueful project
composer create-project glueful/glueful my-project
cd my-project

# Install dependencies
composer install

# Start the development server
php glueful serve
```

**Step 2: Access Web Setup**
```bash
# Navigate to the setup wizard in your browser
open http://localhost:8000/setup
# or
open http://localhost:8000/api/v1/setup
```

**Features of the Web Setup Wizard:**
- **System Requirements Check**: Automatically validates PHP version, extensions, and file permissions
- **Database Configuration**: Interactive form with connection testing
- **Admin User Creation**: Secure admin account setup with password validation
- **Real-time Validation**: Instant feedback on configuration errors
- **Progress Tracking**: Visual progress indicator through setup steps
- **Professional UI**: Clean, responsive interface matching Glueful branding

The web wizard provides the same functionality as the CLI installer but with:
- Visual system requirement validation
- Interactive database connection testing
- Form validation with helpful error messages
- Automatic data persistence between steps
- Mobile-responsive design for setup on any device

**When to use the Web Setup Wizard:**
- First-time Glueful users who prefer visual interfaces
- Teams who need guided setup instructions
- Environments where CLI access is limited
- Development setups requiring immediate visual feedback

::alert{type="info"}
**Note**: The web setup wizard is automatically disabled after successful installation for security. To re-enable it for troubleshooting, remove the `storage/setup.lock` file.
::

### Method 3: Manual Installation

**Option A: Using Composer (Recommended)**

## Troubleshooting Installation Issues

### Common PHP Extension Issues

**Missing Extensions Error:**

```bash
# Install missing extensions on Ubuntu/Debian
sudo apt-get install php8.2-mbstring php8.2-xml php8.2-curl php8.2-zip php8.2-mysql

# Install missing extensions on CentOS/RHEL
sudo yum install php-mbstring php-xml php-curl php-zip php-mysqlnd

# Install missing extensions on macOS with Homebrew
brew install php@8.2
brew link php@8.2 --force
```

**PDO Driver Issues:**

```bash
# For MySQL
sudo apt-get install php8.2-mysql  # Ubuntu/Debian
sudo yum install php-mysqlnd        # CentOS/RHEL

# For PostgreSQL
sudo apt-get install php8.2-pgsql  # Ubuntu/Debian
sudo yum install php-pgsql          # CentOS/RHEL
```

### Memory and Performance Issues

**Increase PHP memory limit:**

```ini
; In php.ini
memory_limit = 512M
max_execution_time = 300
max_input_vars = 3000
post_max_size = 50M
upload_max_filesize = 50M
```

**For development environments:**

```ini
; Additional development settings
display_errors = On
error_reporting = E_ALL
log_errors = On
```

### Database Connection Issues

**Test database connectivity with Glueful CLI:**

```bash
# Check database connection status and statistics
php glueful db:status

# Comprehensive system check including database
php glueful system:check --verbose
```

**Database Migration Issues:**

```bash
# Check pending migrations without running them
php glueful migrate:run --dry-run

# Run migrations with force flag if needed
php glueful migrate:run --force
```

**MySQL Connection Problems:**

```sql
-- Create database and user
CREATE DATABASE glueful CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'glueful_user'@'localhost' IDENTIFIED BY 'secure_password';
GRANT ALL PRIVILEGES ON glueful.* TO 'glueful_user'@'localhost';
FLUSH PRIVILEGES;

-- Test connection manually
mysql -u glueful_user -p glueful
```

**PostgreSQL Connection Problems:**

```sql
-- Create database and user
CREATE DATABASE glueful;
CREATE USER glueful_user WITH PASSWORD 'secure_password';
GRANT ALL PRIVILEGES ON DATABASE glueful TO glueful_user;

-- Test connection manually
psql -U glueful_user -d glueful -h localhost
```

### File Permission Issues

**Fix storage directory permissions:**

```bash
# Make storage directories writable
chmod -R 755 storage/
chmod -R 755 database/
chown -R www-data:www-data storage/  # For Apache
chown -R nginx:nginx storage/        # For Nginx

# For development (less secure but easier)
chmod -R 777 storage/
```

**Use system:check to identify and fix permission issues:**

```bash
# Check and attempt to fix permissions automatically
php glueful system:check --fix

# Detailed permission analysis
php glueful system:check --verbose
```

### Composer Issues

**Composer memory errors:**

```bash
# Increase Composer memory limit temporarily
php -d memory_limit=-1 /usr/local/bin/composer install

# Or set globally
echo 'memory_limit = -1' >> ~/.composer/config.json
```

**Composer timeout issues:**

```bash
# Increase timeout
composer config --global process-timeout 2000

# Use alternative package repository
composer config repo.packagist composer https://mirrors.cloud.tencent.com/composer/
```

### Environment Configuration Issues

**Common .env file issues:**

```env
# Ensure no spaces around = signs
DB_HOST=localhost
# NOT: DB_HOST = localhost

# Use quotes for values with spaces
APP_NAME="My API Application"

# Boolean values should be strings
APP_DEBUG=true
# NOT: APP_DEBUG=1

# Paths should use forward slashes, even on Windows
STORAGE_PATH=storage/app
```

**JWT Key Issues:**

```bash
# Generate secure keys automatically
php glueful generate:key

# Generate only JWT key
php glueful generate:key --jwt-only

# Overwrite existing keys
php glueful generate:key --force

# Manual generation if needed
php -r "echo bin2hex(random_bytes(32)) . PHP_EOL;"
```

The `generate:key` command is the recommended way to create secure keys as it:

- Generates cryptographically secure random keys
- Automatically updates your `.env` file
- Creates both APP_KEY and JWT_KEY
- Provides proper key length and format

### Development Server Issues

**Port already in use:**

```bash
# Check what's using the port
lsof -i :8000

# Use different port with serve command
php glueful serve --port=8080

# Or use PHP's built-in server directly
php -S localhost:8001 -t .

# Kill process using port (macOS/Linux)
kill -9 $(lsof -ti:8000)
```

**Development server not accessible:**

```bash
# Allow external access (development only!)
php glueful serve --host=0.0.0.0

# For local network access
php glueful serve --host=192.168.1.100
```

### Extension Installation Issues

**Extension directory permissions:**

```bash
# Fix extension directory permissions
chmod -R 755 extensions/
chown -R $(whoami):$(whoami) extensions/
```

**Extension loading errors:**

```bash
# Check extension status
php glueful extensions:info

# Enable specific extension
php glueful extensions:enable ExtensionName

# Validate extensions
php glueful extensions:validate
```

## Verification Steps

After installation, verify everything is working:

```bash
# 1. Run comprehensive system check
php glueful system:check

# 2. Check PHP and extensions (if system:check not available)
php --version
php -m | grep -E "(json|mbstring|openssl|PDO)"

# 3. Test database connection and status
php glueful db:status

# 4. Check file permissions
ls -la storage/

# 5. Test basic functionality
php glueful list
php glueful extensions:info

# 6. Start development server
php -S localhost:8000 -t .
```

**Using system:check command:**

The `system:check` command provides comprehensive validation:

```bash
# Basic system check
php glueful system:check

# Detailed output with explanations
php glueful system:check --verbose

# Production readiness check
php glueful system:check --production

# Attempt to fix common issues automatically
php glueful system:check --fix

# Check specific components
php glueful system:check --component=database
php glueful system:check --component=cache
php glueful system:check --component=permissions
php glueful system:check --component=extensions
```

**Additional System Validation Commands:**

```bash
# Database health checks
php glueful db:status                  # Connection status
php glueful migrate:status             # Migration status

# Cache validation
php glueful cache:status               # Cache statistics

# Security validation
php glueful security:scan              # Security vulnerability scan
php glueful security:check             # Security configuration check

# Performance checks
php glueful system:memory              # Memory monitoring and analysis
php glueful extensions:benchmark       # Extension performance benchmarks
```

**Testing Your Installation:**

Start the development server and test your installation:

```bash
# Start development server
php glueful serve

# Or with custom port and host
php glueful serve --port=8080
php glueful serve --host=0.0.0.0    # For external access

# Test API endpoints
curl http://localhost:8000/api/status
curl http://localhost:8000/api/health

# View API documentation
open http://localhost:8000/docs
```

**Quick Functionality Tests:**

```bash
# Test database connectivity
php glueful db:status

# Test cache functionality
php glueful cache:set test-key "Hello Glueful"
php glueful cache:get test-key

# Test queue system
php glueful queue:work --help

# Test notification system
php glueful notifications:process-retries --help

# Test extension system
php glueful extensions:info
```

**Production Deployment Preparation:**

Glueful provides comprehensive production deployment tools:

```bash
# Check production readiness
php glueful system:production --check

# Run comprehensive production audit
php glueful system:production --audit

# Additional production preparation
php glueful security:lockdown --help   # Emergency lockdown management
php glueful cache:clear                # Clear and prepare caches

```

**Production Checklist:**

```bash
# 1. Security hardening
php glueful security:scan

# 2. Performance optimization
composer install --optimize-autoloader --no-dev

# Manually update .env file:

# APP_DEBUG=false
# API_DOCS_ENABLED=false
```
