This section covers system configuration options for the Glueful framework.

## Configuration Files

Glueful uses PHP configuration files stored in the `config/` directory at the project root. These files contain arrays of configuration settings for different aspects of the application. The framework features smart environment-aware defaults that automatically adjust security and performance settings based on your deployment environment.

### app.php

Core application settings with intelligent environment detection:

- **Environment Management**: Automatic detection of development, staging, and production environments
- **Smart Debugging**: Debug mode automatically disabled in production for security
- **API Documentation**: Auto-disabled in production environments
- **Versioning Support**: Comprehensive API versioning with multiple strategies
- **Path Management**: Centralized path definitions for all application directories
- **Performance Settings**: Environment-specific optimization configurations

Key features include:

```php
// Smart environment-aware defaults
return [
    'env' => env('APP_ENV', 'development'),
    'debug' => (bool) env('APP_DEBUG', env('APP_ENV') !== 'production'),
    'api_docs_enabled' => env('API_DOCS_ENABLED', env('APP_ENV') !== 'production'),
    'force_https' => env('FORCE_HTTPS', env('APP_ENV') === 'production'),

    // API versioning support
    'versioning' => [
        'strategy' => env('API_VERSION_STRATEGY', 'url'), // url, header, both
        'current' => env('API_VERSION', 'v1'),
        'supported' => explode(',', env('API_SUPPORTED_VERSIONS', 'v1')),
        'default' => env('API_DEFAULT_VERSION', 'v1'),
    ],

    // Comprehensive path definitions
    'paths' => [
        'base' => dirname(__DIR__),
        'api_base_directory' => dirname(__DIR__) . '/api/',
        'cdn' => env('BASE_URL', 'http://localhost/glueful') . '/storage/cdn/',
        'uploads' => dirname(__DIR__) . '/storage/cdn/',
        'logs' => dirname(__DIR__) . '/storage/logs/',
        'cache' => dirname(__DIR__) . '/storage/cache/',
    ],
];
```

## Secure Key Management

Glueful provides robust key management tools to ensure your application's cryptographic security. The framework requires several secure keys for different purposes and provides automated tools to generate them safely.

### Required Security Keys

The framework requires three critical security keys:

1. **APP_KEY**: 32-character hex key for general application encryption
2. **JWT_KEY**: 64-character hex key for JWT token signing and verification
3. **TOKEN_SALT**: Secure salt for token generation and hashing

### Key Generation Command

The `php glueful key:generate` command provides secure key generation with multiple options:

#### Basic Usage

```bash
# Generate all required keys (APP_KEY and JWT_KEY)
php glueful key:generate

# Generate only JWT key
php glueful key:generate --jwt

# Force overwrite existing keys
php glueful key:generate --force

# Display generated keys (development only - insecure)
php glueful key:generate --show
```

#### Command Features

- **Cryptographically Secure**: Uses `RandomStringGenerator::generateHex()` for secure random generation
- **Environment Validation**: Checks for .env file existence before proceeding
- **Existing Key Protection**: Prevents accidental overwrite without `--force` flag
- **Automatic Integration**: Keys are directly written to your .env file

#### Security Warnings

::alert{type="danger"}
**Critical Security Notice**:

- Never use the `--show` flag in production environments
- Never commit generated keys to version control
- Keep your .env file secure and properly protected
- Regenerate keys immediately if compromised
  ::

### Manual Key Generation

If you prefer to generate keys manually or need to understand the process:

```php
// Example of manual key generation (for reference only)
$appKey = bin2hex(random_bytes(16));    // 32-character hex string
$jwtKey = bin2hex(random_bytes(32));    // 64-character hex string
$tokenSalt = bin2hex(random_bytes(32)); // 64-character hex string
```

### Key Management Best Practices

1. **Key Rotation**: Regularly rotate keys in production environments
2. **Environment Separation**: Use different keys for each environment (dev/staging/production)
3. **Secure Storage**: Store keys in secure environment variable management systems
4. **Access Control**: Limit access to .env files and key generation tools
5. **Backup Strategy**: Securely backup keys before rotation

### Production Key Security

For production deployments, consider these additional security measures:

```bash
# Set proper file permissions for .env file
chmod 600 .env

# Verify no keys are exposed in public files
php glueful security:audit

# Generate fresh keys for production
php glueful key:generate --force
```

### Troubleshooting Key Issues

Common issues and solutions:

- **"JWT_KEY already exists"**: Use `--force` flag to overwrite
- **".env file not found"**: Copy `.env.example` to `.env` first
- **Invalid key format**: Regenerate using the official command
- **Keys not working**: Ensure proper environment variable loading
