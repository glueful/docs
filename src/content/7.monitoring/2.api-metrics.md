# API Metrics & Analytics

Glueful provides enterprise-grade API metrics and analytics with real-time data collection, intelligent caching, and comprehensive dashboard integration to help you monitor performance, track usage patterns, and optimize your application.

## Overview

The metrics system automatically tracks:

- **Request volume** and traffic patterns
- **Response times** and performance metrics
- **Error rates** and failure analysis
- **Rate limiting** enforcement and violations
- **Endpoint popularity** and usage analytics
- **User activity** patterns and behavior
- **System performance** impact and optimization
- **Notification delivery** metrics and success rates

## Automatic Metrics Collection

### ApiMetricsService Implementation

The `ApiMetricsService` automatically collects and manages metrics with advanced features:

```php
use Glueful\Services\ApiMetricsService;

// Get service instance from container
$metricsService = container()->get(ApiMetricsService::class);

// Record API request (done automatically by middleware)
$metricsService->recordRequest([
    'endpoint' => '/api/users',
    'method' => 'GET',
    'response_time' => 145.2,
    'status_code' => 200,
    'ip_address' => '192.168.1.100',
    'user_id' => 'user123'
]);

// Get metrics for admin dashboard
$metrics = $metricsService->getMetricsForDashboard();
```

### Intelligent Caching and Storage

The metrics system uses a dual-layer approach:

1. **Cache Layer**: Fast writes during request processing
2. **Database Layer**: Persistent storage with automatic aggregation
3. **Batch Processing**: Automatic flushing at configurable thresholds

```php
// Configuration options
[
    'flush_threshold' => 50,        // Flush to DB after 50 cached entries
    'aggregation_interval' => 3600, // Hourly aggregation
    'retention_days' => 90,         // Keep raw data for 90 days
    'cache_ttl' => 300             // Cache results for 5 minutes
]
```

### Performance Impact Optimization

- **Async Recording**: Non-blocking metrics collection
- **Batch Operations**: Minimize database writes
- **Intelligent Aggregation**: Reduce storage while maintaining insights
- **Cache-First Reads**: Fast dashboard response times

## Custom Metrics

### Creating Custom Metrics

Define and track custom application metrics:

```php
use Glueful\Metrics\MetricsCollector;

// Define custom metric
MetricsCollector::define('business_operations', [
    'type' => 'counter',
    'description' => 'Number of business operations performed',
    'labels' => ['operation_type', 'result']
]);

// Track custom metric
MetricsCollector::increment('business_operations', [
    'operation_type' => 'order_processing',
    'result' => 'success'
]);

// Get custom metric data
$customStats = MetricsCollector::getMetric('business_operations', [
    'period' => '7d',
    'group_by' => 'operation_type'
]);
```

## Metrics Configuration

Configure metrics collection in your environment:

```env
# API metrics collection
API_METRICS_ENABLED=true
API_METRICS_FLUSH_THRESHOLD=50
API_METRICS_RETENTION_DAYS=90

# Performance tracking
TRACK_RESPONSE_TIMES=true
TRACK_USER_ACTIVITY=true
TRACK_RATE_LIMITING=true

# Notification metrics
NOTIFICATION_METRICS_ENABLED=true
TRACK_DELIVERY_TIMES=true

# Cache settings for metrics
METRICS_CACHE_TTL=300
METRICS_AGGREGATION_INTERVAL=3600

# Admin dashboard
ADMIN_METRICS_ENABLED=true
ADMIN_METRICS_CACHE_TTL=60
```

### ApiMetricsService Configuration

Configure the metrics service behavior:

```php
// In your DI container configuration
$container->singleton(ApiMetricsService::class, function($c) {
    return new ApiMetricsService(
        $c->get(DatabaseInterface::class),
        $c->get(CacheInterface::class),
        [
            'flush_threshold' => 50,
            'aggregation_interval' => 3600,
            'retention_days' => 90,
            'cache_ttl' => 300
        ]
    );
});
```

### Dashboard Data Access

Access metrics programmatically through the admin controller:

```php
use Glueful\Extensions\Admin\Controllers\AdminController;

class AdminController extends BaseController
{
    public function apiMetrics(Request $request): Response
    {
        // Get metrics from the service
        $metricsService = container()->get(ApiMetricsService::class);
        $metrics = $metricsService->getMetricsForDashboard();
        
        return $this->json($metrics);
    }
}
```

### Permission-Based Access

Metrics access is controlled by the RBAC system:
- **Admin users**: Full access to all metrics
- **Regular users**: Limited or no access based on permissions
- **Cache optimization**: Different cache TTLs for different user types

## Alerting and Notifications

### Metric-Based Alerts

Set up alerts based on metric thresholds:

```php
use Glueful\Metrics\AlertManager;

// Configure metric alerts
AlertManager::configure([
    'error_rate_threshold' => [
        'metric' => 'api.error_rate',
        'threshold' => 5.0, // 5% error rate
        'period' => '5m',
        'action' => 'email',
        'recipients' => ['admin@example.com']
    ],
    'response_time_threshold' => [
        'metric' => 'api.avg_response_time',
        'threshold' => 1000, // 1 second
        'period' => '5m',
        'action' => 'webhook',
        'webhook_url' => 'https://hooks.slack.com/...'
    ]
]);
```

### Database Schema

Metrics are stored in optimized database tables:

```sql
-- api_metrics table
CREATE TABLE api_metrics (
    id INT AUTO_INCREMENT PRIMARY KEY,
    endpoint VARCHAR(255) NOT NULL,
    method VARCHAR(10) NOT NULL,
    status_code INT NOT NULL,
    response_time DECIMAL(8,2) NOT NULL,
    ip_address VARCHAR(45),
    user_id VARCHAR(255),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    INDEX idx_endpoint_created (endpoint, created_at),
    INDEX idx_created_at (created_at)
);

-- aggregated_metrics table for performance
CREATE TABLE aggregated_metrics (
    id INT AUTO_INCREMENT PRIMARY KEY,
    endpoint VARCHAR(255) NOT NULL,
    method VARCHAR(10) NOT NULL,
    hour_bucket TIMESTAMP NOT NULL,
    request_count INT DEFAULT 0,
    avg_response_time DECIMAL(8,2),
    error_count INT DEFAULT 0,
    UNIQUE KEY unique_hour (endpoint, method, hour_bucket)
);
```
