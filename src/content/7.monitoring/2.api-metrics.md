# API Metrics & Analytics

Glueful provides comprehensive API metrics and analytics to help you monitor performance, track usage patterns, and optimize your application.

## Overview

The metrics system tracks:

- **Request volume** and patterns
- **Response times** and performance
- **Error rates** and failure patterns
- **Rate limiting** statistics
- **Endpoint usage** analytics
- **User behavior** patterns
- **Resource utilization** metrics

## Performance Metrics

### Response Time Analysis

Track and analyze API response times:

```php
use Glueful\Services\ApiMetricsService;

$metricsService = new ApiMetricsService();

// Get response time statistics
$responseStats = $metricsService->getResponseTimeStats([
    'period' => '24h',
    'endpoint' => '/api/v1/users',
    'percentiles' => [50, 95, 99]
]);

/*
Response:
[
    'avg' => 145.2,
    'min' => 12.5,
    'max' => 2340.1,
    'p50' => 98.3,
    'p95' => 450.1,
    'p99' => 1250.8,
    'total_requests' => 4250
]
*/
```

## Usage Analytics

### Request Volume Tracking

Monitor API usage patterns:

```php

$volumeStats = $metricsService->getRequestVolume([
    'period' => '30d',

    'period' => '7d',
```

## Custom Metrics

### Creating Custom Metrics

Define and track custom application metrics:

```php
use Glueful\Metrics\MetricsCollector;

// Define custom metric
MetricsCollector::define('business_operations', [
    'type' => 'counter',
    'description' => 'Number of business operations performed',
    'labels' => ['operation_type', 'result']
]);

// Track custom metric
MetricsCollector::increment('business_operations', [
    'operation_type' => 'order_processing',
    'result' => 'success'
]);

// Get custom metric data
$customStats = MetricsCollector::getMetric('business_operations', [
    'period' => '7d',
    'group_by' => 'operation_type'
]);
```

## Metrics Configuration

Configure metrics collection in your environment:

```env
# Metrics collection settings
METRICS_ENABLED=true
METRICS_COLLECTION_INTERVAL=60
METRICS_RETENTION_DAYS=90

# Performance metrics
METRICS_TRACK_RESPONSE_TIMES=true
METRICS_TRACK_MEMORY_USAGE=true
METRICS_TRACK_DATABASE_QUERIES=true

# Sampling for high-traffic applications
METRICS_SAMPLING_RATE=1.0
METRICS_HIGH_TRAFFIC_SAMPLING=0.1

# Storage settings
METRICS_STORAGE_DRIVER=database
METRICS_AGGREGATION_INTERVAL=300
```

## Alerting and Notifications

### Metric-Based Alerts

Set up alerts based on metric thresholds:

```php
use Glueful\Metrics\AlertManager;

// Configure metric alerts
AlertManager::configure([
    'error_rate_threshold' => [
        'metric' => 'api.error_rate',
        'threshold' => 5.0, // 5% error rate
        'period' => '5m',
        'action' => 'email',
        'recipients' => ['admin@example.com']
    ],
    'response_time_threshold' => [
        'metric' => 'api.avg_response_time',
        'threshold' => 1000, // 1 second
        'period' => '5m',
        'action' => 'webhook',
        'webhook_url' => 'https://hooks.slack.com/...'
    ]
]);
```

## Export and Integration

### Data Export

Export metrics data for external analysis:

```bash
# Export metrics to JSON
php glueful metrics:export --format=json --period=7d --output=metrics.json

# Export to CSV for spreadsheet analysis
php glueful metrics:export --format=csv --period=30d --output=metrics.csv

# Export Prometheus format
php glueful metrics:export --format=prometheus --output=metrics.prom
```

### Third-Party Integration

Integrate with monitoring tools:

```php
// Prometheus integration
use Glueful\Integrations\PrometheusExporter;

$exporter = new PrometheusExporter();
$exporter->exportMetrics([
    'namespace' => 'glueful_api',
    'include' => ['request_count', 'response_time', 'error_rate']
]);

// Grafana dashboard provisioning
$exporter->generateGrafanaDashboard([
    'datasource' => 'prometheus',
    'output' => 'grafana-dashboard.json'
]);
```

## CLI Commands

### Metrics Management

```bash
# View current metrics
php glueful metrics:view --period=24h

# Clear old metrics data
php glueful metrics:cleanup --older-than=90d

# Generate metrics report
php glueful metrics:report --format=html --output=report.html

# Real-time metrics monitoring
php glueful metrics:monitor --refresh=5
```

## Best Practices

1. **Sampling** - Use appropriate sampling rates for high-traffic applications
2. **Retention** - Configure suitable data retention periods
3. **Aggregation** - Use time-based aggregation for better performance
4. **Alerting** - Set up meaningful alerts based on business metrics
5. **Analysis** - Regularly analyze trends and patterns
6. **Performance** - Monitor the impact of metrics collection on performance
7. **Privacy** - Ensure metrics collection complies with privacy requirements
