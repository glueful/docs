# Health Monitoring

Glueful provides an enterprise-grade health monitoring system that tracks the status of your application's critical components, dependencies, and performance metrics in real-time.

## Overview

The health monitoring system provides comprehensive checks for:

- **Database connectivity** and query performance
- **Cache system** status with distributed monitoring
- **Memory usage** with threshold-based alerting  
- **PHP configuration** and required extensions
- **Extension system** health and performance
- **Connection pool** monitoring and optimization
- **Configuration validation** and security checks
- **Migration status** and schema integrity

## Programmatic Health Checks

Use the health service in your application code:

```php
use Glueful\Services\HealthService;

// Get comprehensive system health
$health = HealthService::performHealthCheck();

if ($health['status'] !== 'healthy') {
    // Handle unhealthy system
    error_log('System health check failed: ' . json_encode($health));
}

// Check specific components
$dbHealth = HealthService::checkDatabase();
$cacheHealth = HealthService::checkCache();
$configHealth = HealthService::checkConfiguration();
$extensionHealth = HealthService::checkExtensions();
$migrationHealth = HealthService::checkMigrations();

// Access health service directly
$healthService = container()->get(HealthService::class);
$result = $healthService->performHealthCheck();

// Check individual operations
$dbResult = $healthService->checkDatabase();
// Returns: ['status' => 'healthy', 'connection' => true, 'operations' => [...]]
```

## Memory Monitoring

Glueful includes sophisticated memory monitoring with automatic threshold-based alerting:

### Real-time Memory Monitoring

```bash
# Monitor memory usage in real-time
php glueful memory:monitor

# Monitor with CSV logging
php glueful memory:monitor --csv=memory.log --interval=5
```

### Memory Alert System

The framework automatically monitors memory usage and triggers alerts:

```php
use Glueful\Performance\MemoryManager;

$memoryManager = new MemoryManager($logger);

// Get current memory status
$usage = $memoryManager->monitor();
// Returns: ['current' => '128MB', 'limit' => '512MB', 'percentage' => 25.0]

// Check alert thresholds
if ($memoryManager->isMemoryWarning()) {
    // Memory usage above warning threshold (default 80%)
}

if ($memoryManager->isMemoryCritical()) {
    // Memory usage above critical threshold (default 90%)
    $memoryManager->forceGarbageCollection();
}
```

## Integration with Monitoring Tools

### Admin Dashboard Integration

The Admin extension provides real-time monitoring dashboards:

```http
# System health dashboard
GET /admin/system/health

# Database statistics
GET /admin/db/stats

# API metrics dashboard
GET /admin/system/api-metrics
```

### Health Check Automation

Set up automated health monitoring:

```bash
# Add to crontab for regular health checks
*/5 * * * * php /path/to/glueful health:check --alert-on-failure
```

### Alerting

Configure health-based alerting:

```php
use Glueful\Services\HealthService;
use Glueful\Notifications\HealthAlertNotification;

// Set up health monitoring with alerts
HealthService::monitor([
    'interval' => 300, // 5 minutes
    'alerts' => [
        'email' => 'admin@example.com',
        'webhook' => 'https://hooks.slack.com/...',
    ],
    'thresholds' => [
        'database_response_time' => 1000, // ms
        'memory_usage' => 80, // percentage
        'disk_usage' => 85, // percentage
    ]
]);
```

## Troubleshooting

### Common Health Issues

1. **Database connectivity problems**

   ```bash
   # Check database status and metrics
   php glueful db:status

   # Run comprehensive system check
   php glueful system:check

   # Check connection pool health
   php glueful db:pool:status
   ```

2. **Memory issues**

   ```bash
   # Monitor memory usage
   php glueful memory:monitor

   # Check system health for memory alerts
   php glueful system:check
   ```

3. **Cache system issues**

   ```bash
   # Check cache status
   php glueful cache status

   # Clear cache if needed
   php glueful cache clear

   # Test cache through health endpoint
   curl GET /health/cache
   ```

4. **Extension system issues**

   ```bash
   # Check extension health
   php glueful extensions debug

   # Validate extension configuration
   php glueful extensions validate-config

   # Run performance benchmarks
   php glueful extensions benchmark
   ```
