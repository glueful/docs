# Health Monitoring

Glueful provides a comprehensive health monitoring system that helps you track the status of your application's critical components and dependencies.

## Overview

The health monitoring system checks:

- **Database connectivity** and response times
- **Cache system** status and performance
- **File system** storage and permissions
- **PHP configuration** and extensions
- **Memory usage** and performance metrics
- **Extension status** and health
- **System load** and resource usage

## Health Check Configuration

Configure health monitoring in your environment:

```env
# Health monitoring settings
HEALTH_CHECK_ENABLED=true
HEALTH_CHECK_DATABASE_TIMEOUT=5
HEALTH_CHECK_CACHE_TIMEOUT=3
HEALTH_CHECK_FILESYSTEM_THRESHOLD=90

# Health check intervals (seconds)
HEALTH_CHECK_INTERVAL=60
HEALTH_CHECK_CACHE_TTL=30

# Alert thresholds
HEALTH_ALERT_MEMORY_THRESHOLD=80
HEALTH_ALERT_DISK_THRESHOLD=85
HEALTH_ALERT_RESPONSE_TIME_THRESHOLD=1000
```

## Programmatic Health Checks

Use the health service in your application code:

```php
use Glueful\Services\HealthService;

// Get overall system health
$health = HealthService::getOverallHealth();

if ($health['status'] === 'error') {
    // Handle unhealthy system
    error_log('System health check failed: ' . json_encode($health['issues']));
}

// Check specific components
$dbHealth = HealthService::checkDatabase();
$cacheHealth = HealthService::checkCache();
$fsHealth = HealthService::checkFileSystem();

// Custom health checks
HealthService::addCustomCheck('external_api', function() {
    // Your custom health check logic
    return [
        'status' => 'healthy',
        'response_time' => 250,
        'last_check' => time()
    ];
});
```

## Health Status Indicators

### Status Levels

- **`healthy`** - All systems operational
- **`degraded`** - Some issues detected but service is functional
- **`error`** - Critical issues affecting service operation

## Integration with Monitoring Tools

### Prometheus Metrics

Export health metrics for Prometheus:

```http
GET /api/v1/health/metrics
```

### Health Check Automation

Set up automated health monitoring:

```bash
# Add to crontab for regular health checks
*/5 * * * * php /path/to/glueful health:check --alert-on-failure
```

### Alerting

Configure health-based alerting:

```php
use Glueful\Services\HealthService;
use Glueful\Notifications\HealthAlertNotification;

// Set up health monitoring with alerts
HealthService::monitor([
    'interval' => 300, // 5 minutes
    'alerts' => [
        'email' => 'admin@example.com',
        'webhook' => 'https://hooks.slack.com/...',
    ],
    'thresholds' => [
        'database_response_time' => 1000, // ms
        'memory_usage' => 80, // percentage
        'disk_usage' => 85, // percentage
    ]
]);
```

## Troubleshooting

### Common Health Issues

1. **Database connectivity problems**

   ```bash
   # Check database status
   php glueful db:status

   # Test database connection
   php glueful health:check --component=database --verbose
   ```

2. **Cache system issues**

   ```bash
   # Check cache status
   php glueful cache status

   # Clear cache if needed
   php glueful cache clear
   ```

3. **File system issues**

   ```bash
   # Check disk usage
   php glueful health:check --component=filesystem --verbose

   # Clean up storage
   php glueful storage:cleanup
   ```

### Health Check CLI Commands

```bash
# Run comprehensive health check
php glueful health:check

# Check specific component
php glueful health:check --component=database

# Continuous monitoring
php glueful health:monitor --interval=60

# Export health report
php glueful health:report --format=json --output=health-report.json
```
